01率失真理论：允许出错能省多少

无损压缩的极限是 H(X)。但音频、图像、视频根本不需要无损——允许一点失真，能省下多少比特？

Concept 概念

设失真度量 d: 𝒳 × 𝒳̂ → ℝ⁺，序列失真取平均：d(xn, x̂n) = (1/n) Σ d(xi, x̂i)。

常用度量：汉明失真 d(x,x̂)=1{x≠x̂}（错误率）；平方误差 d(x,x̂)=(x−x̂)²（信号处理）。

率失真函数 R(D) = minp(x̂|x) : E[d(X,X̂)] ≤ D I(X; X̂)

注意与容量的对偶结构：容量是 max I（信道给定，选输入分布）；率失真是 min I（信源给定，选"测试信道" p(x̂|x)）。

Theorem 定理 · Shannon 第三定理（率失真定理，1959）
  • 可达性：∀ R > R(D)，存在码使平均失真 ≤ D。
  • 逆定理：∀ R < R(D)，任何码的平均失真 > D。

归属：Shannon, Coding Theorems for a Discrete Source With a Fidelity Criterion, IRE Nat. Conv. Rec., part 4, pp.142–163, 1959。

Theorem 定理 · R(D) 的性质
  1. 非增：D 越大，R(D) 越小（容忍度换比特）。
  2. 凸：R(D) 是 D 的凸函数 ⟹ 优化良态，且时间共享无法改进。
  3. 端点：R(0) = H(X)（退化为第一定理）；R(Dmax) = 0，其中 Dmax = minx̂ E[d(X,x̂)]。
  4. 连续于 (0, Dmax)。

凸性证明思路：设 (R₁,D₁)、(R₂,D₂) 对应测试信道 p₁、p₂。取 pλ=λp₁+(1−λ)p₂，失真线性混合，而 I(X;X̂) 关于 p(x̂|x) 是凸的，故 I(pλ) ≤ λI(p₁)+(1−λ)I(p₂)。∎

02R(D) 的两个闭式解

Example 例题 · 伯努利源 + 汉明失真

X ~ Bern(p)（设 p ≤ 1/2），汉明失真。则

R(D) = { H(p) − H(D) , 0 ≤ D < min(p, 1−p) { 0 , D ≥ min(p, 1−p)

逆定理方向的推导：

I(X;X̂) = H(X) − H(X|X̂) = H(p) − H(X ⊕ X̂ | X̂) 给定 X̂ 时 X 与 X⊕X̂ 一一对应 ≥ H(p) − H(X ⊕ X̂) 条件减少熵 ≥ H(p) − H(D) Pr{X≠X̂} ≤ D，H 在 [0,½] 递增

可达性：取测试信道为 BSC(D)，可验证取等。∎

数值：p=0.5、D=0.1 时 R = 1 − H(0.1) = 0.531 bit/符号。容许 10% 比特出错，就把 1 bit 压到 0.531 bit，省了近一半。

Example 例题 · 高斯源 + 平方误差

X ~ 𝒩(0, σ²)，d(x,x̂)=(x−x̂)²。则

R(D) = { ½ log₂(σ²/D) , 0 < D ≤ σ² { 0 , D > σ² 反解得失真—速率函数：D(R) = σ² · 2−2R

推导：I(X;X̂) = h(X) − h(X|X̂) = ½log(2πeσ²) − h(X−X̂|X̂) ≥ ½log(2πeσ²) − ½log(2πeD) = ½log(σ²/D)，取等当误差为独立高斯。∎

工程解读（"6 dB 法则"）：每增加 1 bit/样本，失真降为 1/4，信噪比提升 10·log₁₀4 = 6.02 dB/bit。
这是所有量化器设计的黄金法则：16 bit 音频（CD）理论 SNR 上限 ≈ 96 dB；8 bit 图像 ≈ 48 dB。

Corollary 推论 · 反向注水（并行高斯源）

对 m 个独立高斯分量（方差 σi²），总失真约束 Σ Di ≤ D，最优分配为

Di = min(λ, σi²), Ri = ½ log₂( σi² / Di ) 其中 λ 由 Σ min(λ, σi²) = D 确定

物理意义：方差小于水位 λ 的分量直接丢弃（Ri=0）；方差大的只压到水位。
这正是 JPEG / MP3 的数学原理：变换到频域后高频分量方差小，被整体丢弃。与信道编码的注水法方向相反，故称反向注水。

03Blahut–Arimoto：数值求解容量与 R(D)

Concept 概念

大多数信道没有闭式解。Blahut (1972) 与 Arimoto (1972) 独立提出的交替最大化算法可数值求解，且因问题是凸的而保证收敛到全局最优。

Formula 公式 · 容量的 BA 迭代
给定 p(y|x)，初始化 r⁽⁰⁾(x) 为均匀分布。重复： ① q⁽ᵏ⁾(x|y) = r⁽ᵏ⁾(x)p(y|x) / Σx' r⁽ᵏ⁾(x')p(y|x') ② r⁽ᵏ⁺¹⁾(x) = exp( Σy p(y|x) ln q⁽ᵏ⁾(x|y) ) / 归一化 直到收敛，输出 C = I(r; p)

原理：把 C = maxr maxq J(r,q) 写成双变量泛函的交替最大化。每步不减且有上界，故收敛。

Example 例题 · 参考实现 
import numpy as np

def blahut_arimoto(P, tol=1e-12, max_iter=5000):
    """P[x][y] = p(y|x)；返回容量(bit)与最优输入分布"""
    nx, ny = P.shape
    r = np.ones(nx) / nx
    for _ in range(max_iter):
        denom = r @ P                          # p(y)
        denom = np.where(denom > 0, denom, 1e-300)
        q = (r[:, None] * P) / denom           # q(x|y)
        with np.errstate(divide='ignore'):
            logq = np.where(q > 0, np.log(q), -np.inf)
        t = np.exp(np.sum(P * logq, axis=1))
        r_new = t / t.sum()
        if np.max(np.abs(r_new - r)) < tol:
            r = r_new; break
        r = r_new
    denom = r @ P
    C = sum(r[x] * P[x, y] * np.log2(P[x, y] / denom[y])
            for x in range(nx) for y in range(ny)
            if P[x, y] > 0 and r[x] > 0)
    return C, r

# 验证 BSC(0.1)：理论 C = 1 - H(0.1) = 0.531004
P = np.array([[0.9, 0.1],
              [0.1, 0.9]])
print(blahut_arimoto(P))
# (0.5310044064107189, array([0.5, 0.5]))  ✓

04大偏差理论：罕见事件有多罕见

大数定律说样本均值收敛到期望。大偏差理论说：偏离期望的概率以指数速度衰减，而指数率恰是 KL 散度。

Concept 概念 · 类型（type）方法

序列 xn 的类型 Pxn 即其经验分布。三条核心计数结果：

① 类型总数 ≤ (n+1)|𝒳| ← 多项式，关键！ ② |T(P)| ≐ 2nH(P) 类型类大小 ③ Qn(T(P)) ≐ 2−n D(P‖Q) 该类型出现概率

为什么"多项式个类型"是关键：指数级衰减 2−nD 碾压多项式级数量 (n+1)|𝒳|，故 union bound 后主导项由最小的 D 决定——这就是 Sanov 定理的全部内容。

Theorem 定理 · Sanov 定理 (1957)

设 X₁,…,Xn i.i.d. ~ Q，E 为分布集合。则

Qn( PXn ∈ E ) ≐ 2−n D(P* ‖ Q) 其中 P* = arg minP ∈ E D(P ‖ Q) 称为 I-投影

解读：罕见事件以"最省力的方式"发生——系统会选择离真实分布 KL 距离最近的那个"伪装分布"。此即大偏差的"最可能路径"原理，也称条件极限定理。

Example 例题

公平硬币抛 n 次，出现正面比例 ≥ 0.7 的概率？

Q = (0.5, 0.5)，E = { P : P(正) ≥ 0.7 } 最近分布 P* = (0.7, 0.3)（在边界上） D(P*‖Q) = 0.7·log₂(0.7/0.5) + 0.3·log₂(0.3/0.5) = 0.7(0.4854) + 0.3(−0.7370) = 0.3398 − 0.2211 = 0.1187 bit ⟹ Pr ≈ 2−0.1187n n=100 : 2−11.87 ≈ 2.7×10−4 n=1000: 2−118.7 ≈ 1.7×10−36

精确二项计算 n=100 时约 2.0×10⁻⁵，指数阶吻合（大偏差略去多项式前因子）。

05假设检验：Stein 引理与 Chernoff 指数

Theorem 定理 · Chernoff–Stein 引理

检验 H₀: X ~ P vs H₁: X ~ Q，n 个 i.i.d. 观测。约束第一类错误 αn ≤ ε，则第二类错误最优指数为

limn→∞ (1/n) log₂ βn* = − D(P ‖ Q)

即 βn ≐ 2−nD(P‖Q)，与 ε 无关（只要 0 < ε < 1）。

Corollary 推论 · KL 散度的第三重意义
视角D(P‖Q) 的含义
编码（L1）误用 Q 编码 P 的额外比特代价
几何分布空间中的（非对称）"距离"
统计（L3）区分 P 与 Q 的难度指数——D 越大越容易区分

这解释了 KL 为何无处不在：它就是"可区分性"的自然度量。

Theorem 定理 · Chernoff 信息（贝叶斯对称情形）
C*(P,Q) = − min0≤λ≤1 log₂ [ Σx P(x)λ Q(x)1−λ ]

此即 Chernoff 信息，对称，且 ≤ min{D(P‖Q), D(Q‖P)}。λ=1/2 时对应 Bhattacharyya 距离。

06错误指数：不仅"能不能"，还要"多快"

Concept 概念

第二定理只说 R < C 时 Pe → 0，但衰减多快？定义可靠性函数：

E(R) = lim supn→∞ − (1/n) log₂ Pe*(n, R) 即 Pe ≈ 2−n E(R)
Theorem 定理 · 随机编码指数（Gallager 1965）
Er(R) = max0≤ρ≤1 maxp(x) [ E₀(ρ, p) − ρR ] E₀(ρ,p) = − log₂ Σy [ Σx p(x) p(y|x)1/(1+ρ) ]1+ρ

性质：E(R) > 0 ⟺ R < C；E(R) 递减且凸；R → C 时 E(R) → 0。

Corollary 推论 · 三个区域与一个开放问题
  • R < Rcrit：球堆积界 Esp 与随机编码界 Er 重合，指数已知且紧。
  • Rcrit < R < C：Er 是下界、Esp 是上界，两者存在间隙——这是信息论至今未解决的经典开放问题。
  • 低速率区：expurgated bound（剔除坏码字）给出更好下界。

工程含义：错误率降低 10 倍需块长增加约 3.32/E(R)。E(R) 越小（越接近容量），代价增长越剧烈——这就是"逼近容量的最后 0.1 dB 极其昂贵"的理论根源。

07有限块长与信道色散：最重要的现代修正

这是 21 世纪信息论最重要的进展之一，也是本级的核心。

Concept 概念 · 问题

Shannon 的 C 是 n→∞ 的极限。但 5G URLLC 要求块长 n ≈ 100、时延 < 1 ms。此时 C 是严重乐观的估计。需要问：给定块长 n 与容许错误概率 ε，最大速率 R*(n,ε) 是多少？

Theorem 定理 · 正规逼近（Polyanskiy–Poor–Verdú 2010）
R*(n, ε) = C − √( V / n ) · Q−1(ε) + O( log n / n )
  • C = 信道容量（一阶项）
  • V = 信道色散，信息密度的方差：V = Var[ i(X;Y) ]，i(x;y) = log₂[p(y|x)/p(y)]
  • Q−1 = 标准正态上尾函数的反函数

归属：Y. Polyanskiy, H. V. Poor, S. Verdú, "Channel Coding Rate in the Finite Blocklength Regime", IEEE Trans. Inform. Theory, 56(5):2307–2359, 2010。这篇论文重新定义了现代编码理论的基准。

Formula 公式 · 常见信道的色散
BSC(ε): C = 1 − H(ε) V = ε(1−ε) · [ log₂((1−ε)/ε) ]² BEC(α): C = 1 − α V = α(1−α) AWGN: C = ½log₂(1+P/N) V = (P/N)(P/N+2) / (2(P/N+1)²) · (log₂e)²
Example 例题 · 有限块长的代价

BSC(0.11)，C ≈ 0.5，要求 ε = 10⁻³（Q⁻¹(10⁻³) ≈ 3.09）。

V = 0.11×0.89×[log₂(0.89/0.11)]² = 0.0979 × (3.0164)² = 0.8908 n=100 : R* ≈ 0.5 − √(0.8908/100)×3.09 = 0.5 − 0.2917 = 0.208 (42% of C) n=1000 : R* ≈ 0.5 − 0.0922 = 0.408 (82%) n=10000: R* ≈ 0.5 − 0.0292 = 0.471 (94%)

结论：块长 100 时实际可用速率只有容量的 42%。这就是短包通信（IoT、工业控制、车联网）必须用有限块长理论设计的原因。

08变分刻画：把信息量写成优化问题

Theorem 定理 · Donsker–Varadhan 变分公式 (1975)
D(P ‖ Q) = supf { EP[ f(X) ] − log EQ[ ef(X) ] }

上确界取遍所有使期望存在的 f，最优解 f* = log(dP/dQ) + const。

Frontier 前沿 · 为什么这个公式今天极其重要

DV 公式把 KL 变成可用神经网络逼近的优化问题：参数化 f 并做梯度上升，就能估计高维连续分布的 KL 与互信息。由此催生：

  • MINE（Belghazi et al. 2018）——直接用 DV 界估计 I(X;Y)
  • InfoNCE / CPC（van den Oord et al. 2018）——对比学习的理论基础，是 I(X;Y) 的下界
  • SimCLR / MoCo 等自监督学习——本质在最大化不同视图间的互信息
  • f-GAN——把 GAN 推广到任意 f-散度

但需警惕：McAllester & Stratos (2020) 证明，任何基于 N 个样本的下界，其估计值不能超过 log N。因此高维互信息的神经估计存在本质统计困难，实践中报告的"高互信息"常不可信。这是当前活跃的争议点。

Formula 公式 · 容量的几何刻画（信息半径）
C = minq(y) maxx D( p(y|x) ‖ q(y) )

找一个"中心分布" q*，使所有输入引起的输出分布到它的最大 KL 距离最小。这是 minimax / Chebyshev 中心问题，q* 称为容量达成输出分布，且它唯一（即使最优输入分布不唯一）。此视角为 MIT 6.441 所强调。

09网络信息论：多用户的世界

Shannon 解决了点对点。多发送方/接收方时，答案是容量区域（一个集合）而非单个数字，且许多情形至今未解。

Theorem 定理 · 多址接入信道 MAC（已完全解决）

两个发送方 X₁、X₂ 同时发给一个接收方 Y。容量区域为满足下式的 (R₁,R₂) 的凸包：

R₁ ≤ I(X₁ ; Y | X₂) R₂ ≤ I(X₂ ; Y | X₁) R₁ + R₂ ≤ I(X₁, X₂ ; Y)

归属：Ahlswede (1971), Liao (1972)。这是网络信息论少数被完全解决的问题之一。

MAC 容量区域的五边形

两个角点的操作意义：角点 A 对应"先译码用户 2、消去其贡献、再译码用户 1"的连续干扰消除 SIC；角点 B 反之。两点之间的边由时间共享连接。SIC 正是 NOMA（非正交多址）的核心技术。

Theorem 定理 · 退化广播信道 BC

一个发送方向两个接收方广播。若信道退化（X → Y₁ → Y₂ 成马氏链，Y₂ 比 Y₁ 差），容量区域为

R₂ ≤ I(U ; Y₂) R₁ ≤ I(X ; Y₁ | U) 其中 U → X → (Y₁,Y₂)，|𝒰| ≤ min{|𝒳|,|𝒴₁|,|𝒴₂|}+1

归属：Cover (1972) 提出叠加编码，Bergmans (1973) 证明。叠加编码：给差用户的信息放"粗粒度"层，好用户先解粗层再解精细层。

未解：一般（非退化）广播信道容量区域至今开放，已 50 余年；最好的已知内界是 Marton 界。

10Slepian–Wolf：分开编码，居然不损失

Theorem 定理 · Slepian–Wolf (1973)

两个相关信源 X、Y 由两个无法通信的编码器分别压缩，送到同一联合译码器。可达区域为

RX ≥ H(X | Y) RY ≥ H(Y | X) RX + RY ≥ H(X, Y)
Corollary 推论 · 惊人之处

总速率下界 H(X,Y) 与"两个编码器可自由通信"时完全相同！即分布式编码不损失任何效率（渐近意义下）。

直觉（随机分箱 random binning）：编码器 X 不知道 Y，但可把所有 xn 随机扔进 2nRX 个箱子，只发箱号。译码器收到箱号后，在该箱中找与 yn 联合典型的唯一序列。只要箱子够多（RX > H(X|Y)），碰撞概率趋于 0。

应用：无线传感器网络（相邻节点数据高度相关）；分布式视频编码（Wyner–Ziv，把复杂度从编码端转移到解码端，适合低功耗摄像头）。

Theorem 定理 · Berger–Tung（有失真版本）

Slepian–Wolf 的率失真推广。Berger (1977) 与 Tung (1978) 给出内界与外界，但一般情形的确切区域仍未确定。特例 Wyner–Ziv（译码端有边信息）已解决：RWZ(D) = min I(X;X̂|Y)。

注意：与无损情形不同，有失真时分布式编码通常严格劣于联合编码（存在率损失）。

11Gelfand–Pinsker：编码器知道干扰

Theorem 定理 · Gelfand–Pinsker (1980)

信道状态 S 在编码端非因果已知（译码端未知）。容量为

C = maxp(u|s), x=f(u,s) [ I(U ; Y) − I(U ; S) ]

U 为辅助随机变量；减去的 I(U;S) 是为"让译码器能识别"付出的代价。

Corollary 推论 · Costa 的"污纸编码"（Writing on Dirty Paper, 1983）

高斯情形：Y = X + S + Z，S ~ 𝒩(0,Q) 编码端已知，Z ~ 𝒩(0,N)，功率约束 P。则

C = ½ log₂( 1 + P/N ) 与干扰功率 Q 完全无关！

极其反直觉：只要发送方知道干扰，干扰就能被完全消除，容量与"根本没有干扰"时相同——且不需增加任何功率。

命名来源：在一张已经写满字的"脏纸"上写信息，只要你能看见那些脏迹，就能让收信人读出你写的内容。

应用：MIMO 广播信道的最优策略（脏纸编码 DPC 达到容量区域）、数字水印、预编码。这是 4G/5G 多用户 MIMO 的理论基石。

12现代编码：从存在性到可实现

Shannon 1948 证明好码存在，用了 61 年才找到可实用且可证明达到容量的构造。

年份编码提出者关键性质
1950Hamming 码Hamming首个纠错码，纠 1 位错，(7,4) 最经典
1955卷积码Elias可用 Viterbi (1967) 最大似然译码
1960Reed–SolomonReed, Solomon纠突发错，CD/DVD/QR 码/深空通信
1962LDPC 码Gallager稀疏校验矩阵；被遗忘 30 年，1996 由 MacKay 重新发现
1993Turbo 码Berrou et al.首次实用地逼近容量（距 Shannon 限 0.5 dB），引发编码革命
2009Polar 码Arıkan首个被严格证明达到容量、且编译码复杂度 O(n log n) 的构造
Concept 概念 · Polar 码的核心思想：信道极化

把 N 个相同信道通过递归的线性变换"重组"，得到 N 个虚拟信道。神奇之处：当 N → ∞ 时，这些虚拟信道两极分化——一部分趋于完美无噪（容量 → 1），另一部分趋于完全无用（容量 → 0），中间态的比例趋于 0。

极化后：约 N·C 个信道 → 完美　　约 N(1−C) 个信道 → 无用 策略：在完美信道上传信息比特 在无用信道上放"冻结比特"（固定为 0，收发双方已知） ⟹ 速率自然达到 C，且译码用简单的连续消除 SC 算法

为什么这是里程碑：它不是"构造一个好码"，而是"把坏信道变成好信道"，从根本上换了思路。Arıkan 因此获得 2019 年 IEEE 信息论学会 Shannon 奖之外的多项荣誉，Polar 码被 5G 标准采纳为控制信道编码（数据信道用 LDPC）。

Frontier 前沿

当前编码理论热点：短码设计（有限块长理论指导下的 URLLC 编码）、面向 6G 的编码（ITW 2025 三大重点之一）、量子纠错码（surface code、LDPC-CSS 码）、用机器学习设计/译码（神经 BP 译码器、learned codes）、分布式存储码（再生码、局部可修复码 LRC）。

  6. 污纸编码为什么能让容量与干扰功率无关？这与"编码器已知"这一条件有何关系？
  7. 列出三个至今开放的网络信息论问题。
参考答案

1. 容量 C = maxp(x) I(X;Y)：信道 p(y|x) 给定（自然施加的约束），我们能自由选择输入分布，目标是让通过的信息尽可能多。
率失真 R(D) = minp(x̂|x) I(X;X̂)：信源 p(x) 给定，我们设计"测试信道"（即压缩方案），目标是在满足失真约束下让需要传的信息尽可能少。
本质：一个是"资源利用最大化"，一个是"成本最小化"，二者构成 Lagrange 对偶关系。

2. R(D)=½log₂(σ²/D)，令 R = ½log₂(σ²/D) ⟹ 2R = log₂(σ²/D) ⟹ 22R = σ²/D ⟹ D = σ²2−2R。
每加 1 bit：D 变为 1/4，SNR = σ²/D 提升 4 倍 = 10log₁₀4 = 6.02 dB。
工程含义：ADC/量化器每增加 1 位精度，动态范围提升约 6 dB。16 bit CD 音频 ≈ 96 dB SNR。这是硬件设计的基本换算。

3. 因为要对"落入集合 E 的所有类型"做 union bound：Pr ≤ ΣP∈E 2−nD(P‖Q) ≤ (n+1)|𝒳| · 2−n min D}。
多项式因子 (n+1)|𝒳| 在取 (1/n)log 后趋于 0，完全不影响指数率。若类型数是指数级的，这个论证就会失效。这正是"类型方法"简洁有力的根源。

4. V = Var[i(X;Y)] 度量信息密度的随机波动。同一个信道，每次使用提供的信息量不是恒定的 C，而是围绕 C 涨落，V 就是涨落的方差。
是 √(V/n) 而非 V/n：因为 n 次使用的总信息密度是 n 个 i.i.d. 项之和，由 CLT 其标准差为 √(nV)，摊到每次使用即 √(nV)/n = √(V/n)。这是标准差（而非方差）的量纲。

5. 惊讶在于：两个编码器完全无法通信、彼此不知道对方数据，总速率却能达到 H(X,Y)——与它们能自由协商时一样好。
随机分箱有效的原因：编码器不需要知道"Y 具体是什么"，只需保证"同一箱内不会有两个都与 yn 联合典型的序列"。与 yn 联合典型的 xn 大约有 2nH(X|Y) 个，只要箱子数 2nRX > 这个数量，每箱平均不到 1 个，碰撞概率趋于 0。译码端的联合处理替代了编码端的协商。

6. 因为编码器知道 S，可以把码字"预先偏移"以适配 S——本质上是在 S 已知的前提下选择一个与之匹配的辅助变量 U。GP 公式 I(U;Y) − I(U;S) 中，第二项正是为此付出的代价，而高斯情形下 Costa 证明这个代价恰好被第一项的增益抵消。
关键在"编码器已知"：若是译码器已知 S，问题平凡（直接减去即可）；若两端都不知道，干扰就是纯粹的噪声，容量会降为 ½log(1+P/(N+Q))。信息的位置决定了它的价值。

7. ①一般（非退化）广播信道容量区域；②干扰信道容量区域（除强/极强干扰等特例）；③中继信道容量（Cover–El Gamal 1979 的内外界至今未闭合）。其他还有：多描述编码、两路信道（Shannon 1961）、一般网络的容量。
