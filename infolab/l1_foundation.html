00四性框架：本科信息论在解决什么

中文教学体系用"四性"组织整门课，这是一条比章节顺序更清晰的主线。

性质要解决的问题核心工具极限由什么决定
有效性怎样用最少的比特表示信息（压缩）信源编码 · Huffman · LZ熵 H(X)
可靠性怎样在有噪声时不出错地传输信道编码 · Hamming · LDPC · Polar信道容量 C
保密性怎样让窃听者得不到信息一次一密 · 保密容量互信息 I(M;Z)=0
认证性怎样确认消息来源真实未篡改认证码 · 哈希欺骗概率下界
一句话把四性串起来 先把水分挤干（有效性），再有意加回冗余（可靠性），加冗余的方式要让敌人看不懂（保密性）、也伪造不了（认证性）。
注意有效性与可靠性方向相反——一个去冗余，一个加冗余。Shannon 的分离定理证明了：分两步做，和联合优化一样好（在渐近意义下）。这是现代通信系统"压缩模块 + 纠错模块"分开设计的理论依据。
依据：UESTC《信息论》大纲；西电、南京工程学院本科大纲共识目标。

01熵：定义与性质

Concept 概念

设离散随机变量 X 取值于字母表 𝒳，概率质量函数 p(x)=Pr{X=x}。

H(X) = − Σx∈𝒳 p(x) log₂ p(x) [bit] 约定：0 log 0 = 0（由 lim_{t→0⁺} t log t = 0 保证连续性）

注意 H(X) 是 分布的泛函，不是 X 的函数——它不依赖 X 取什么值，只依赖取各值的概率。所以有时写 H(p) 更准确。

另一种写法揭示本质：H(X) = E[−log₂ p(X)] = E[I(X)]，即自信息的期望。

Theorem 定理 · 熵的基本性质
  1. 非负性：H(X) ≥ 0，等号成立当且仅当 X 是退化分布（某个 p(x)=1）。
  2. 极值性（最大熵）：H(X) ≤ log₂|𝒳|，等号成立当且仅当 X 均匀分布。
  3. 对称性：H 不随概率分量的重排而改变。
  4. 凹性：H(p) 是关于 p 的凹函数。
  5. 可加性：X,Y 独立 ⟹ H(X,Y) = H(X) + H(Y)。
Proof 证明 · 极值性（关键，必须会）

用 Jensen 不等式。设 |𝒳|=n，u(x)=1/n 为均匀分布。考察差值：

log₂n − H(X) = Σ p(x) log₂ n + Σ p(x) log₂ p(x) = Σ p(x) log₂ [ n·p(x) ] = Σ p(x) log₂ [ p(x) / (1/n) ] = D( p ‖ u ) ≥ 0

最后一步用了信息不等式 D(p‖q) ≥ 0（见 §03）。等号成立当且仅当 p = u，即均匀分布。∎

这个证明的价值：它把"熵的极值"化归为"KL 散度非负"，说明 D 才是更基本的量。这是理解 L2/L3 的关键视角。

Example 例题

例 1.1 四符号源 p = (1/2, 1/4, 1/8, 1/8)，求熵。

H = −[½log₂½ + ¼log₂¼ + ⅛log₂⅛ + ⅛log₂⅛] = ½(1) + ¼(2) + ⅛(3) + ⅛(3) = 0.5 + 0.5 + 0.375 + 0.375 = 1.75 bit/符号

对比：4 符号均匀分布时 H = log₂4 = 2 bit。所以这个源比均匀源少 0.25 bit/符号，可压缩性更好。
这个例子会在 §08 再出现——Huffman 码恰好达到 1.75 bit，正好等于熵（因为所有概率都是 2 的幂次）。

02联合熵与条件熵

Concept 概念
联合熵 H(X,Y) = − Σx,y p(x,y) log₂ p(x,y) 条件熵 H(Y|X) = Σx p(x) H(Y|X=x) = − Σx,y p(x,y) log₂ p(y|x)

条件熵读作："已经知道 X 之后，Y 还剩多少不确定性"。

⚠️ 注意 H(Y|X) 是对 x 取期望后的量，而非某个固定 x 的熵。个别 H(Y|X=x) 可能大于 H(Y)，但平均值 H(Y|X) 一定不超过 H(Y)。

Theorem 定理 · 链式法则
H(X,Y) = H(X) + H(Y|X) = H(Y) + H(X|Y) 一般地：H(X₁,…,Xn) = Σi=1n H(Xi | X₁,…,Xi−1)
Proof 证明

直接从 p(x,y) = p(x)p(y|x) 出发：

H(X,Y) = − Σ p(x,y) log₂ p(x,y) = − Σ p(x,y) log₂ [ p(x) p(y|x) ] = − Σ p(x,y) log₂ p(x) − Σ p(x,y) log₂ p(y|x) = − Σx p(x) log₂ p(x) + H(Y|X) = H(X) + H(Y|X) ∎

本质就是对概率乘法法则取对数取期望。链式法则由此归纳即得。

Theorem 定理 · 条件作用减少熵
H(Y|X) ≤ H(Y) 等号 ⟺ X 与 Y 独立

俗称 "Conditioning reduces entropy"——"知道得越多，不确定性越小（平均而言）"。

Corollary 推论 · 熵的次可加性
H(X,Y) ≤ H(X) + H(Y) 等号 ⟺ 独立 H(X₁,…,Xn) ≤ Σ H(Xi)

意义：相关性总是让联合系统的总不确定性小于各部分之和——这正是压缩的空间来源。视频能被高倍压缩，就是因为相邻帧高度相关。

03相对熵（KL 散度）：最基本的量

Concept 概念
D(p ‖ q) = Σx p(x) log₂ [ p(x) / q(x) ] [bit] 约定：0 log(0/q)=0；p log(p/0)=+∞（p>0 时）

操作性解释（最重要）：真实分布是 p，但你误以为是 q，并按 q 设计了最优编码。那么你每个符号平均多花的比特数就是 D(p‖q)。

按 q 编码的平均长度 = H(p) + D(p‖q) ↑真实最优 ↑因用错模型付出的代价
Theorem 定理 · 信息不等式（Gibbs 不等式）
D(p ‖ q) ≥ 0，等号成立 ⟺ p(x) = q(x) 对所有 x
Proof 证明 · 两行搞定

设 A = {x : p(x) > 0} 为 p 的支撑集。由 Jensen 不等式（log 是凹函数）：

−D(p‖q) = Σx∈A p(x) log₂ [ q(x)/p(x) ] ≤ log₂ [ Σx∈A p(x) · q(x)/p(x) ] ← Jensen = log₂ [ Σx∈A q(x) ] ≤ log₂ 1 = 0 ⟹ D(p‖q) ≥ 0 ∎

等号条件：Jensen 取等要求 q(x)/p(x) 为常数，结合两者都是概率分布，得 p=q。

KL 散度不是距离
  • 不对称：D(p‖q) ≠ D(q‖p)。这不是缺陷而是特性——机器学习里"前向 KL"导致模式覆盖（mean-seeking），"反向 KL"导致模式坍缩（mode-seeking），行为截然不同。
  • 不满足三角不等式。
  • 正确的名字是散度（divergence）。若要真正的度量，可用 Jensen–Shannon 散度的平方根，或全变差距离。
Example 例题

例 1.2 p=(0.5,0.5)，q=(0.9,0.1)，计算双向 KL。

D(p‖q) = 0.5·log₂(0.5/0.9) + 0.5·log₂(0.5/0.1) = 0.5(−0.8480) + 0.5(2.3219) = 0.7370 bit D(q‖p) = 0.9·log₂(0.9/0.5) + 0.1·log₂(0.1/0.5) = 0.9(0.8480) + 0.1(−2.3219) = 0.5310 bit

果然 0.7370 ≠ 0.5310，不对称性一目了然。

Frontier 前沿

KL 散度是现代 AI 的核心零件：变分推断的 ELBO、VAE 的正则项、RLHF/PPO 限制策略偏移的 KL 惩罚、DPO 的隐式 KL 约束、知识蒸馏的师生匹配——全部是在最小化某个 KL。→ L4 大模型

04互信息：共享了多少

Concept 概念
I(X;Y) = Σx,y p(x,y) log₂ [ p(x,y) / (p(x)p(y)) ] = D( p(x,y) ‖ p(x)p(y) )

互信息 = 联合分布与"假装独立"之间的 KL 散度，即衡量 X 与 Y 有多不独立。

Theorem 定理 · 互信息的等价形式
I(X;Y) = H(X) − H(X|Y) 观测 Y 后 X 的不确定性减少量 = H(Y) − H(Y|X) 对称 = H(X) + H(Y) − H(X,Y) 容斥 = I(Y;X) 对称性 ≥ 0 由 D ≥ 0

其中 I(X;Y) = 0 ⟺ X ⊥ Y（独立）。另有 I(X;X) = H(X)，故熵又称"自信息量"。

Example 例题 · 完整手算

例 1.3 二元对称信道 BSC，输入等概率 P(X=0)=P(X=1)=0.5，翻转概率 ε=0.1。求 I(X;Y)。

步骤1 · 联合分布：

p(0,0)=0.5×0.9=0.45 p(0,1)=0.5×0.1=0.05 p(1,0)=0.5×0.1=0.05 p(1,1)=0.5×0.9=0.45

步骤2 · 边缘：P(Y=0)=0.45+0.05=0.5，P(Y=1)=0.5。故 H(Y)=1 bit。

步骤3 · 条件熵：给定 X=0，Y 的分布是 (0.9, 0.1)，熵为 H(0.1)。给定 X=1 同理。

H(Y|X) = 0.5·H(0.1) + 0.5·H(0.1) = H(0.1) = −0.9log₂0.9 − 0.1log₂0.1 = 0.1368 + 0.3322 = 0.4690 bit

步骤4 · 互信息：

I(X;Y) = H(Y) − H(Y|X) = 1 − 0.4690 = 0.5310 bit

解读：每次使用这个信道，平均只能可靠传递 0.531 bit，而非 1 bit。噪声吃掉了 0.469 bit——恰好等于 H(ε)。这个结论直接给出 BSC 的容量公式（§10）。

Corollary 推论 · 条件互信息与链式法则
I(X;Y|Z) = H(X|Z) − H(X|Y,Z) I(X₁,…,Xn;Y) = Σi I(Xi;Y | X₁,…,Xi−1)

⚠️ 反直觉警告：I(X;Y|Z) 与 I(X;Y) 之间没有大小关系！条件可能增加也可能减少互信息。
经典反例：X,Y 独立同分布的公平硬币，Z = X⊕Y。则 I(X;Y)=0，但 I(X;Y|Z)=1 bit（知道异或值后，X 完全决定 Y）。这现象在因果推断中叫 collider bias / explaining away。

05恒等式全图：一张图记住所有关系

Formula 公式 · 全部恒等式
H(X,Y) = H(X) + H(Y|X) = H(Y) + H(X|Y) H(X,Y) = H(X) + H(Y) − I(X;Y) I(X;Y) = H(X) − H(X|Y) = H(Y) − H(Y|X) I(X;Y) = H(X) + H(Y) − H(X,Y) I(X;Y) = H(X,Y) − H(X|Y) − H(Y|X) I(X;X) = H(X) 0 ≤ I(X;Y) ≤ min{ H(X), H(Y) }
Venn 图的适用边界（严谨性提醒） 两变量时这张图完全正确。但推广到三个及以上变量时，"交互信息" I(X;Y;Z) = I(X;Y) − I(X;Y|Z) 可以为负，此时它不再对应任何真实集合的面积，Venn 图会误导。上面 XOR 的例子就给出 I(X;Y;Z) = 0 − 1 = −1 bit。
这是本科阶段最常见的隐性错误之一。严格处理需要 I-measure 理论（Yeung）。

06数据处理不等式：信息不会凭空增加

Theorem 定理 · 数据处理不等式 DPI

若 X → Y → Z 构成马尔可夫链（即给定 Y 时 X 与 Z 条件独立），则

I(X;Y) ≥ I(X;Z) 等号 ⟺ X → Z → Y 也是马氏链
Proof 证明

用互信息链式法则，把 I(X;Y,Z) 按两种顺序展开：

I(X;Y,Z) = I(X;Z) + I(X;Y|Z) I(X;Y,Z) = I(X;Y) + I(X;Z|Y) 马氏性 X→Y→Z ⟹ I(X;Z|Y) = 0 ⟹ I(X;Y) = I(X;Z) + I(X;Y|Z) ≥ I(X;Z) 因 I(X;Y|Z) ≥ 0 ∎
Corollary 推论
  • 任何确定性处理都不增加信息：取 Z=g(Y)，则 I(X;g(Y)) ≤ I(X;Y)。再精妙的算法也无法从数据中榨出原本不存在的信息。
  • 神经网络逐层信息不增：输入 X → 第1层 T₁ → 第2层 T₂ → …，则 I(X;T₁) ≥ I(X;T₂) ≥ …。这是信息瓶颈理论的出发点。
  • 充分统计量：T(Y) 是关于 X 的充分统计量 ⟺ DPI 取等，即 I(X;T(Y)) = I(X;Y)，压缩了数据却没丢信息。
DPI 是信息论最深刻的哲学陈述 它是"天下没有免费午餐"的精确数学版本。图像增强不能恢复真正丢失的细节；数据清洗不能创造新知识；无论多深的网络，对输入的信息量只会单调递减。
——但这不意味着处理无用：处理的价值在于把信息重排成更可用的形式（提高对下游任务的"可提取性"），而非增加总量。

07Kraft 不等式：什么样的码长可实现

Concept 概念

前缀码（prefix code）：任何码字都不是另一个码字的前缀。好处是即时可译——接收端读到就能立刻解码，无需回看。

例：{0, 10, 110, 111} 是前缀码；{0, 01, 011} 不是（0 是 01 的前缀）。

Theorem 定理 · Kraft–McMillan 不等式

(a) Kraft (1949)：存在码长为 ℓ₁,…,ℓm 的 D 元前缀码，当且仅当

Σi=1m D−ℓi ≤ 1

(b) McMillan (1956)：任何唯一可译码也必须满足同一不等式。

(b) 的意义极其重要：允许使用更一般的唯一可译码，并不能获得比前缀码更短的码长。所以只研究前缀码不损失任何一般性。

Proof 证明 · Kraft 必要性（二叉树论证）

把前缀码画成二叉树：码字 = 叶节点，码长 = 深度。设最长码长为 L。

深度为 L 的满二叉树共有 2L 个叶节点。一个深度为 ℓi 的码字，会"占用"其下方全部 2L−ℓi 个叶节点（前缀性质保证这些子树互不相交）。因此：

Σi 2L−ℓi ≤ 2L ⟹ Σi 2−ℓi ≤ 1 ∎
Theorem 定理 · 最优码长界

设 L* 为最优前缀码的期望长度，则

H(X) ≤ L* < H(X) + 1 [以 D=2 为例，单位 bit]

下界来自 Kraft + Gibbs 不等式；上界由取 ℓi = ⌈−log₂p(xi)⌉（Shannon 码）构造得到。

Corollary 推论 · 消灭那个 "+1"

对 n 个符号成块编码，则每符号平均长度满足：

H(X) ≤ L*n/n < H(X) + 1/n → 当 n→∞ 时收敛到 H(X)

这正是 Shannon 第一定理的雏形。→ L2 严格版

08Huffman 码：可证最优的构造

Concept 概念 · 算法（Huffman 1952）
  1. 把所有符号按概率排成一列；
  2. 取出概率最小的两个，合并成一个新节点，概率相加；
  3. 把新节点放回队列，重复直到只剩一个节点（根）；
  4. 从根到叶，左枝标 0、右枝标 1，路径即码字。
Example 例题 · 完整构造

仍用 例 1.1 的源：a:0.5, b:0.25, c:0.125, d:0.125

步骤1: 最小两个 c(.125) + d(.125) → cd(.25)
       队列: a(.5)  b(.25)  cd(.25)

步骤2: 最小两个 b(.25) + cd(.25) → bcd(.5)
       队列: a(.5)  bcd(.5)

步骤3: a(.5) + bcd(.5) → 根(1.0)

码树:              [1.0]
                 0/      \1
              a(.5)     [bcd .5]
                        0/      \1
                     b(.25)   [cd .25]
                              0/     \1
                            c(.125) d(.125)

码字: a=0   b=10   c=110   d=111

平均码长：

L = 0.5(1) + 0.25(2) + 0.125(3) + 0.125(3) = 0.5 + 0.5 + 0.375 + 0.375 = 1.75 bit/符号 而 H(X) = 1.75 bit ⟹ L = H，达到理论极限！

为什么恰好相等？因为所有概率都是 2 的负整数次幂（1/2, 1/4, 1/8, 1/8），此时 −log₂p(x) 恰为整数，Kraft 不等式取等。这类分布称为 D-adic 分布。

验证 Kraft：2⁻¹ + 2⁻² + 2⁻³ + 2⁻³ = 0.5+0.25+0.125+0.125 = 1 ✓

Theorem 定理 · Huffman 最优性

Huffman 码在所有逐符号唯一可译码中期望长度最小。

证明骨架（交换论证）：①最优码中，概率越小码长必不越短（否则交换可改进）；②最优码树中最深的两个叶节点必可安排为兄弟；③故概率最小的两符号可取为兄弟——这正是 Huffman 的贪心步；④对合并后的 m−1 符号问题归纳。∎

Huffman 的三个局限（本科常考）
  1. 至少 1 比特/符号。若某符号概率 0.99（H≈0.08 bit），Huffman 仍需 1 bit，效率仅 8%。解法：算术编码可逼近熵到任意精度。
  2. 需要预知概率分布。解法：自适应 Huffman 或 LZ 系列通用压缩（无需先验分布仍渐近最优）。
  3. 只利用单符号统计，不利用上下文相关性。解法：先做上下文建模（如 PPM）或用块编码。

09信道模型：噪声的数学化

Concept 概念

离散无记忆信道 DMC 由三元组 (𝒳, p(y|x), 𝒴) 完全刻画：输入字母表、转移概率矩阵、输出字母表。

"无记忆"指：p(yn|xn) = Πi p(yi|xi)，即每次使用信道时噪声独立，不受历史影响。这是一个关键前提，L3 会讨论有记忆信道。

二元对称信道 BSC(ε)

比特以概率 ε 被翻转。最经典的信道模型。

C = 1 − H(ε)

二元擦除信道 BEC(α)

比特以概率 α 被"擦除"（收到 ?），但绝不翻转——错误位置已知。

C = 1 − α
BSC 与 BEC 的关键差异 同样"损坏率" 0.1 时：BSC 容量 = 1−H(0.1) = 0.531，BEC 容量 = 1−0.1 = 0.9。
差距巨大，原因是 BEC 知道哪里错了，BSC 不知道。"知道错在哪"本身就是巨大的信息。这解释了为什么互联网丢包（≈擦除）比误码更容易处理。

11高斯信道与 Shannon 公式

Concept 概念

加性白高斯噪声信道 AWGN：Y = X + Z，其中 Z ~ 𝒩(0, N)，且输入受功率约束 E[X²] ≤ P。

连续变量需用微分熵：h(X) = −∫ f(x) log₂ f(x) dx。关键事实：在给定方差下，高斯分布微分熵最大，h(𝒩(0,σ²)) = ½log₂(2πeσ²)。

Proof 证明 · 推导容量
I(X;Y) = h(Y) − h(Y|X) = h(Y) − h(X+Z|X) = h(Y) − h(Z) h(Z) = ½ log₂(2πeN) 固定 Var(Y) = Var(X)+Var(Z) ≤ P+N h(Y) ≤ ½ log₂(2πe(P+N)) 高斯最大化微分熵 取等 ⟺ Y 高斯 ⟺ X ~ 𝒩(0,P) ⟹ C = ½log₂(2πe(P+N)) − ½log₂(2πeN) = ½ log₂( (P+N)/N ) = ½ log₂(1 + P/N) [bit/信道使用] ∎
Theorem 定理 · Shannon–Hartley 公式

对带宽 B（Hz）、信号功率 S、噪声功率谱密度对应总噪声 N 的连续时间信道（每秒可用 2B 次）：

C = B · log₂( 1 + S/N ) [bit/秒]

这是全部工程通信的根本上限。5G、Wi-Fi、光纤、深空通信的设计都在逼近这条线。

Example 例题

例 1.4 电话线：B = 3400 Hz，信噪比 30 dB。求理论最大速率。

30 dB ⟹ S/N = 10^(30/10) = 1000 C = 3400 × log₂(1 + 1000) = 3400 × log₂(1001) = 3400 × 9.9672 ≈ 33 888 bit/s ≈ 33.9 kbps

历史印证：这正是 1990 年代拨号调制解调器停在 33.6 kbps 的原因——不是技术不行，而是撞上了 Shannon 极限。后来的 56k 调制解调器之所以能突破，是因为下行链路的一端是全数字的，绕开了一次模数转换，等效于换了个信道模型。

Corollary 推论 · 带宽与功率的权衡
  • 功率受限区（低 SNR）：C ≈ 1.4427 · S/N₀（与带宽几乎无关）。深空通信处于此区——加带宽没用，只能加功率或提高天线增益。
  • 带宽受限区（高 SNR）：C ≈ B·log₂(S/N)，此时加带宽是线性收益，而加功率只有对数收益。宽带比大功率划算——这是 5G 走向毫米波大带宽的根本原因。
  • 最小比特能量：令 B→∞，可得每比特所需能量的绝对下界
    Eb/N₀ ≥ ln 2 = 0.693 ≈ −1.59 dB
    低于此值，无论用什么编码、多低的速率，都无法可靠通信。这被称为 Shannon 极限，是通信工程的"绝对零度"。

12自检与作业

Level 1 自检 · 通过后进 L2
  1. 证明 H(X|Y) ≤ H(X)，并说明什么时候取等。为什么这不意味着 H(X|Y=y) ≤ H(X) 对每个 y 成立？
  2. 为什么 KL 散度不对称？举一个 D(p‖q) 有限但 D(q‖p) = ∞ 的例子。
  3. 设 X,Y 独立公平硬币，Z = X ⊕ Y。计算 I(X;Y)、I(X;Y|Z)、I(X;Z)。这违反数据处理不等式吗？
  4. 某源 p = (0.6, 0.2, 0.1, 0.1)。求熵、构造 Huffman 码、计算平均码长与效率。
  5. BSC(0.11) 的容量是多少？若要以 0.4 bit/使用的速率传输，理论上可行吗？
  6. 为什么 BEC(0.5) 的容量（0.5）远大于 BSC(0.5) 的容量（0）？
参考答案

1. H(X) − H(X|Y) = I(X;Y) = D(p(x,y)‖p(x)p(y)) ≥ 0。取等 ⟺ X ⊥ Y。
单个 y 不成立的原因：H(X|Y) 是对 y 求期望后的量。某个特定观测可能让你更迷惑（如观测到一个极罕见的值），但平均而言信息总是有帮助的。例：X 均匀于 {1,2,3,4}，Y 是某种指示器，某个 y 值可能使 X 的后验更接近均匀从而 H(X|Y=y) > H(X)，但加权平均后必然不超过。

2. 因为 D(p‖q) = Ep[log(p/q)]，期望是按 p 取的，角色天然不对称。
例：p=(0.5,0.5,0)，q=(⅓,⅓,⅓)。则 D(p‖q) = log₂(1.5) = 0.585 有限；而 D(q‖p) 中出现 ⅓·log₂(⅓/0) = ∞。规律：分母为 0 而分子非 0 时发散，即 q 必须"覆盖" p 的支撑集。

3. I(X;Y) = 0（独立）。I(X;Z) = 0（X 与 XOR 结果也独立！）。I(X;Y|Z) = H(X|Z) − H(X|Y,Z) = 1 − 0 = 1 bit。
不违反 DPI，因为 X→Y→Z 不构成马尔可夫链（Z 直接依赖 X，给定 Y 时 X 与 Z 并不条件独立）。DPI 的前提不满足，自然不适用。这是最经典的"条件增加互信息"反例。

4. H = −[0.6log₂0.6 + 0.2log₂0.2 + 0.1log₂0.1 ×2] = 0.4422+0.4644+0.3322+0.3322 = 1.571 bit。
Huffman：合并 0.1+0.1=0.2 → 队列 (0.6, 0.2, 0.2)；合并 0.2+0.2=0.4 → (0.6, 0.4)；合并成根。
码字：a=0（长1），b=10（长2）或视分支，c=110，d=111。
L = 0.6(1)+0.2(2)+0.1(3)+0.1(3) = 0.6+0.4+0.3+0.3 = 1.6 bit。
效率 = H/L = 1.571/1.6 = 98.2%。冗余 0.029 bit/符号（因概率非 2 的幂次）。

5. H(0.11) = −0.11log₂0.11 − 0.89log₂0.89 = 0.3503 + 0.1498 = 0.5001。C = 1 − 0.5001 = 0.4999 ≈ 0.5。
要求速率 0.4 < C = 0.5，理论上可行：由信道编码定理，存在码使错误概率任意小。（这个 ε=0.11 是著名的例子，因为它使 C 恰好 ≈ 1/2。）

6. BSC(0.5)：输出与输入统计独立，I(X;Y)=0，完全无法通信。BEC(0.5)：一半比特完好无损地到达，且接收方确切知道哪些丢了，故可靠传输一半的比特，C=0.5。
核心差异：BEC 的错误位置是已知的（擦除），BSC 的错误位置未知（翻转伪装成正确数据）。定位错误本身耗费信息。
