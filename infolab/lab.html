01自信息与惊奇度

一切的起点：I(x) = −log₂ p(x)。概率越小，发生时越"惊奇"，携带的信息越多。

▶ 实验：概率 → 信息量
0.125
该看什么
  • p = 1 时 I = 0：必然事件不含任何信息。这是整个理论的锚点。
  • p → 0 时 I → ∞：越不可能的事发生，信息量越大，且发散没有上界。
  • 曲线是凸的：把 p 从 0.5 减到 0.25，信息只增加 1 bit；但从 0.02 减到 0.01，也只增加 1 bit。每次概率减半，信息恰好 +1 bit——这正是"以 2 为底"的含义。
  • 为什么必须是对数？因为要求独立事件信息可加：I(x,y) = I(x)+I(y) 而 p(x,y)=p(x)p(y)，能把乘法变加法的连续函数只有对数（Cauchy 函数方程）。

→ 理论出处：L0 §02 · L1 §02

02二元熵函数 H₂(p)

信息论里出现频率最高的一条曲线。几乎所有二元问题的答案里都有它。

▶ 实验：H₂(p) = −p log₂p − (1−p) log₂(1−p)
0.300
该看什么
  • 对称性：H₂(p) = H₂(1−p)。熵只关心"分布多不均匀"，不关心哪个结果被叫做"正面"。
  • 唯一最大值在 p=0.5，H=1 bit：均匀分布熵最大——这是最大熵原理（L4 §03）最简单的实例。
  • 顶部极平坦：p 从 0.5 变到 0.4，熵只从 1.000 掉到 0.971，损失不到 3%。轻度偏斜的硬币几乎和公平硬币一样难猜——这解释了为什么检测微弱偏差需要海量样本。
  • 两端极陡：p 从 0.01 到 0.02，熵从 0.081 跳到 0.141，翻了近一倍。在接近确定的区域，一点点不确定性的增加代价巨大——这是低错误率通信为何昂贵的根源。
  • 严格凹：这保证了 Jensen 不等式可用，是 L1 中"条件化不增熵"等一系列证明的基础。

→ 理论出处：L1 §03

03三元分布的熵：越均匀越大

把二元推广到三元，可以直接看到"熵 = 分布的均匀程度"这个几何直觉。

▶ 实验：三元分布 (p₁, p₂, p₃)
0.50
0.50
该看什么
  • 上界 log₂3 = 1.585 bit，只在 (1/3,1/3,1/3) 处取到。任何偏离都严格降低熵。
  • 把两个概率合并会降熵：让 p₃→0，熵就趋近于二元熵 H₂(p₁)，上界降到 1 bit。字母表变小 ⟹ 熵上界变小。
  • "归组"的代价：这个实验直接展示了 L1 中的分组公理（Shannon 熵三条公理之一）：把两个符号合并成一个，损失的熵恰好是"组内选择"的期望熵。
  • 与压缩的联系：熵值 = 每符号平均最少比特数。当前分布下 Huffman 码长应落在 [H, H+1) 内，可以到实验 08 验证。

→ 理论出处：L1 §03

04KL 散度：为什么它不是距离

D(p‖q) 度量"用 q 编码来自 p 的数据，每符号多花几个比特"。它非负、非对称、不满足三角不等式。

▶ 实验：两个伯努利分布之间的 KL
0.70
0.30
该看什么
  • D ≥ 0，等号仅当 p = q：Gibbs 不等式。这是信息论中被使用次数最多的一条不等式——最大熵定理、互信息非负、Fano 不等式的证明都靠它。
  • 严重不对称：试试 p=0.9, q=0.5 与 p=0.5, q=0.9，两个值差很多。所以"KL 距离"是错误说法，正确叫法是"KL 散度"。
  • q 趋近 0 或 1 时 D 爆炸：如果模型断言某事件不可能（q≈0）而它实际会发生（p>0），惩罚趋于无穷。这就是机器学习中"永远不要输出概率 0"的信息论理由，也是 label smoothing、加性平滑存在的原因。
  • 交叉熵分解：读数中的 H(p,q) = H(p) + D(p‖q)。训练神经网络最小化 H(p,q)，而 H(p) 固定，所以实际在最小化 KL。见 L4 §05。
  • 局部近似：当 q 靠近 p 时 D ≈ (p−q)²/(2·ln2·q(1−q))，是二次的——这就是 Fisher 信息与统计流形几何的起点。

→ 理论出处：L1 §05

05BSC 的互信息与容量

固定信道翻转率 ε，改变输入分布 p，看互信息 I(X;Y) 如何变化。容量就是这条曲线的最高点。

▶ 实验：I(X;Y) 随输入分布 p 的变化（BSC）
0.110
0.500
该看什么
  • 最优输入永远是 p = 0.5：无论 ε 取什么值，曲线顶点都在正中间。这是 BSC 的对称性带来的，容量 C = 1 − H₂(ε)。
  • ε = 0.5 时容量为 0：信道完全随机，输出与输入独立，一个比特都传不了。此时曲线被压成一条贴地的直线。
  • ε = 0 和 ε = 1 时容量都是 1！这是最反直觉的一点："总是翻转"和"从不翻转"一样好，因为接收方只要把结果取反即可。信息论关心的是可恢复性，不是"看起来对不对"。
  • C 关于 ε 对称：C(ε) = C(1−ε)，所以"噪声"的坏处在 ε=0.5 处最大。
  • 数值感：ε=0.11 时 C ≈ 0.5，即每 2 个信道使用只能传 1 比特有效信息——这恰好是许多编码理论论文的基准工作点。

→ 理论出处：L1 §08–09 · 定理 L2 第二定理

06三种信道的容量对比

同一个"噪声参数"下，BSC（翻转）、BEC（擦除）、Z 信道（单向错）的容量差多少？这个对比能建立很强的直觉。

▶ 实验：容量 vs 噪声参数
0.300
该看什么
  • BEC 永远最好：C = 1 − δ，是一条直线。因为擦除是"知道自己不知道"——接收方明确知道哪些位丢了，可以直接请求重传或用擦除码恢复。
  • BSC 最差：C = 1 − H₂(δ)。翻转是"不知道自己不知道"，接收方无法定位错误，必须付出更大代价。
  • 关键对比：δ=0.5 时 BEC 还有 0.5 bit 容量，而 BSC 已经归零。同样"一半出问题"，知道位置与不知道位置，差别是有与无。这是信息论最实用的一条工程洞见——设计系统时应尽量把"错误"转化为"擦除"（这正是 CRC 校验 + 丢包重传的思路）。
  • Z 信道居中：只有 1→0 会错，0 永远正确。它不对称，最优输入分布也不是 0.5（读数中给出）。这提醒我们："均匀输入最优"只是对称信道的特权。
  • δ→1 时 Z 信道容量趋于 0 但衰减很慢：因为总还有"发 0"这条完全可靠的通道。

→ 理论出处：L1 §08

07Shannon–Hartley 与带宽—功率权衡

连续信道的容量公式 C = B log₂(1 + S/N)，是全部无线通信工程的定价表。

▶ 实验：容量 vs 带宽（功率固定）
20.0
20.0
该看什么
  • 带宽是线性的，功率是对数的：带宽翻倍，容量翻倍；功率翻倍（+3dB），高 SNR 下容量只加 B 比特。这就是为什么 5G 疯狂抢频谱（毫米波），而不是简单加大发射功率——买带宽的性价比高得多。
  • 高 SNR 近似 C ≈ B·SNRdB/3.01：每 3 dB 增益换 1 bit/s/Hz。工程师的心算公式。
  • 低 SNR 近似 C ≈ 1.44·B·(S/N)：此时容量与功率成正比，与带宽无关（因为 S/N 中 N=N₀B 随 B 增长）。
  • 带宽无限时的极限：C∞ = S/(N₀ ln2)。即使带宽无穷，容量仍有限——由功率决定。对应的最小能量效率是 Eb/N₀ = ln2 = −1.59 dB，这就是著名的 Shannon 极限，是所有编码方案的终极靶心。
  • 误区提醒：这条公式只对 AWGN 成立。真实无线信道有衰落、干扰、多径，容量分析要用 L3 的网络信息论工具。

→ 理论出处：L1 §10

08Huffman 编码：亲手验证 H ≤ L < H+1

修改符号概率，实时重建 Huffman 树，对比平均码长与熵下界。Shannon 第一定理的实证版。

▶ 实验：6 符号 Huffman 编码
0.60
6

该看什么
  • 永远满足 H ≤ L < H + 1：无论怎么拖，读数中的"冗余 L−H"总在 [0,1) 内。这是 Shannon 第一定理的可达性部分，Huffman 达到了最优前缀码。
  • 偏斜度 = 0 时（均匀分布）：所有码字等长，L = H = log₂n（当 n 是 2 的幂时严格相等，冗余为 0）。均匀分布下压缩毫无用武之地。
  • 偏斜度大时压缩收益明显：高概率符号得到 1–2 比特的短码，L 显著低于 log₂n。这就是压缩的全部秘密——用短码换高频。
  • 冗余何时最大？试着让某个概率接近但不等于 2 的负幂（如 p=0.3）。因为码长必须是整数，而理想码长 −log₂0.3 = 1.74，只能取 2，浪费了 0.26 比特。整数约束是 Huffman 唯一的损失来源。
  • 怎么消除这最后 1 比特？对 n 个符号联合编码，冗余摊薄为 1/n；或者用算术编码 / ANS 直接逼近熵。见 L2 §08。

→ 理论出处：L1 §07 · L2 第一定理

09典型集：概率如何坍缩到一小撮序列上

AEP 说：当 n 很大，几乎所有概率质量都集中在约 2nH 条"典型序列"上，而它们只占全部 2n 条序列的极小比例。这个实验让你看到坍缩过程。

▶ 实验：n 增大时典型集的两个极限
0.25
60
该看什么
  • 两条曲线朝相反方向跑：蓝线是典型集的概率（→ 1），橙线是典型集占全部序列的比例（→ 0）。这就是 AEP 的全部内容：一个可忽略比例的子集，装下了几乎全部概率。
  • 数量级的震撼：p=0.25、n=200 时，全部序列有 2²⁰⁰ ≈ 10⁶⁰ 条，典型集约 2^(200×0.811) ≈ 10⁴⁸ 条——典型集只占十亿亿亿亿分之一，却承载 99% 以上的概率。
  • 这就是压缩的原理：既然只有 2nH 条序列真正会出现，给它们编号只需 nH 比特，而不是 n 比特。压缩率 H < 1 的来源就在这里，没有别的魔法。
  • p → 0.5 时典型集比例趋于 1：均匀信源下每条序列都同样典型，无法压缩。拖动 p 到 0.5 验证这一点。
  • n 小的时候 AEP 不成立：n=10 时两条曲线都还在中间地带。AEP 是渐近定理，有限 n 下的偏差正是 L3 有限块长理论要处理的问题。

→ 理论出处：L2 §02–03 · 有限 n 修正见 L3 §07

10率失真曲线：允许出错能省多少比特

Shannon 第三定理。无损压缩的下界是 H；如果允许失真 D，下界降到 R(D)。这条曲线是 JPEG、MP3、模型量化的共同理论基础。

▶ 实验：伯努利源与高斯源的 R(D)
0.50
0.100
该看什么
  • D = 0 时 R = H：无损情形回到 Shannon 第一定理，两个定理在这里对接。
  • 曲线是凸递减的：一开始"放宽一点点失真"就能省掉大量比特（曲线陡），之后收益递减。这解释了为什么有损压缩的第一步收益最大——JPEG 质量从 100 降到 90，文件小一半而肉眼几乎无差；从 50 降到 40 就明显掉画质了。
  • 伯努利源：R(D) = H₂(p) − H₂(D)，D ≥ min(p,1−p) 时 R = 0。后半句意思是：失真容忍度一旦超过"直接猜多数类"的错误率，就完全不需要传任何信息。拖动 D 越过 p 看曲线触底。
  • 高斯源：R(D) = ½ log₂(σ²/D)，每减半失真需要 +0.5 bit。等价说法：每增加 1 bit，信噪比提升 6.02 dB——这是量化器设计的黄金法则（"6 dB per bit"）。
  • 与 LLM 量化的联系：把权重从 FP16 压到 INT4，就是在这条曲线上取一个工作点。R(D) 告诉你理论上能省多少，实际方法（GPTQ / AWQ）离这个界还有多远。

→ 理论出处：L3 §01–02
