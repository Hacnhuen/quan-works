00统一证明模板：先看骨架再看肉

三大定理的证明都是同一个套路。先记住这张表，后面每个证明都在往里填空。

第一定理（信源）第二定理（信道）第三定理（率失真）
问题最少多少比特能无损表示最多多快能可靠传输容许失真 D 时最少多少比特
答案R > H(X)R < C = max I(X;Y)R > R(D) = min I(X;X̂)
可达性工具典型集只有 2nH 个随机编码 + 联合典型译码随机码本 + 失真典型性
逆定理工具非典型集概率 → 0Fano + DPIFano + DPI + 凸性
归属Shannon 1948Shannon 1948Shannon 1959
可达性 vs 逆定理：一个定理的两半 每个 Shannon 定理都是夹逼：
  • 可达性（achievability）：构造一个方案，证明 R 能做到 ⟹ 给出上界的可实现性。手法通常是"随机地造，然后证明平均表现好，故必存在一个好的"。
  • 逆定理（converse）：证明超过这个界一定失败 ⟹ 给出不可能性。手法几乎总是 Fano + 数据处理不等式。
两半合起来才说明这个界是紧的（tight），即恰好是极限而非某个宽松估计。

01AEP 与典型集：信息论的钥匙

Theorem 定理 · 渐近均分性 AEP

设 X₁, X₂, …, Xn 独立同分布 ~ p(x)，则

− (1/n) log₂ p(X₁, X₂, …, Xn) → H(X) 依概率收敛

归属：Shannon (1948) 弱形式；McMillan (1953) L¹ 收敛；Breiman (1957) 几乎处处收敛（合称 Shannon–McMillan–Breiman 定理，适用于遍历信源）。

Proof 证明 · 弱 AEP 只需一行大数定律
由独立性：p(X₁,…,Xn) = Πi p(Xi) 取对数：− (1/n) log₂ p(X₁,…,Xn) = − (1/n) Σi log₂ p(Xi) 这是 i.i.d. 随机变量 {−log₂ p(Xi)} 的样本均值。 由弱大数定律，它依概率收敛到期望： E[ −log₂ p(X) ] = H(X) ∎

关键洞察：AEP 就是大数定律作用在"自信息"这个随机变量上。看穿这一点，AEP 就不再神秘。

Concept 概念 · 典型集
Aε(n) = { xn ∈ 𝒳n : | −(1/n) log₂ p(xn) − H(X) | ≤ ε } 等价写法： 2−n(H+ε) ≤ p(xn) ≤ 2−n(H−ε)

即：典型序列就是概率"差不多等于" 2−nH 的那些序列——它们彼此概率近似相等，故名"均分"。

Theorem 定理 · 典型集的三条性质

对充分大的 n：

  1. 几乎必然落入：Pr{ Xn ∈ Aε(n) } > 1 − ε
  2. 大小上界：| Aε(n) | ≤ 2n(H+ε)
  3. 大小下界：| Aε(n) | ≥ (1−ε) 2n(H−ε)
Proof 证明 · 性质 2（最常用）
1 = Σxn∈𝒳n p(xn) ≥ Σxn∈Aε p(xn) ≥ Σxn∈Aε 2−n(H+ε) ← 典型集定义的下界 = |Aε(n)| · 2−n(H+ε) ⟹ |Aε(n)| ≤ 2n(H+ε) ∎
AEP 的震撼含义：只有极少数序列"存在" 抛一枚 p=0.9 的偏币 n 次。总共有 2n 种可能序列，但熵只有 H(0.9)=0.469 bit，所以典型序列只有约 20.469n 个。
当 n=100：总序列数 2¹⁰⁰ ≈ 1.27×10³⁰，典型序列约 2⁴⁶·⁹ ≈ 1.3×10¹⁴。
典型集只占全部序列的 10⁻¹⁶，却承载了几乎全部概率。

这就是压缩的全部秘密：只给典型序列编号，需要 log₂(2nH) = nH 比特；剩下那些序列几乎不会出现，即使出错也无所谓。

02联合典型性：第二定理的钥匙

Concept 概念

序列对 (xn, yn) 称为联合典型，若三个条件同时成立：

| −(1/n)log₂ p(xn) − H(X) | ≤ ε | −(1/n)log₂ p(yn) − H(Y) | ≤ ε | −(1/n)log₂ p(xn,yn) − H(X,Y) | ≤ ε

即：各自典型，且作为一对也典型。第三条是关键——它要求两者的"配对关系"符合真实联合分布。

Theorem 定理 · 联合 AEP（核心引理）

设 (Xn, Yn) ~ Π p(xi, yi)。若 (X̃n, Ỹn) 是独立抽取的、边缘分布相同的序列对（即"随机配对"），则

Pr{ (X̃n, Ỹn) ∈ Aε(n) } ≈ 2−n I(X;Y)
Proof 证明 · 数出来
联合典型对的数量 ≈ 2nH(X,Y) 独立配对的总数 ≈ 2nH(X) × 2nH(Y) Pr ≈ 2nH(X,Y) / ( 2nH(X) · 2nH(Y) ) = 2−n[ H(X)+H(Y)−H(X,Y) ] = 2−n I(X;Y) ∎

解读：随便抓一个 xn 和一个 yn 凑成对，它们"看起来像是真的经由信道产生的"的概率，指数地小，指数率恰好是 I(X;Y)。

这个引理为什么值 2nI 个码字 译码器收到 yn 后，在码本里找唯一与之联合典型的码字。
每个错误码字碰巧联合典型的概率 ≈ 2−nI。若码本有 M 个码字，则误判概率 ≈ (M−1)·2−nI。
要它趋于 0，需要 M < 2nI，即速率 R = (log M)/n < I(X;Y)。
第二定理的可达性到此已经讲完了——剩下的只是把它写严格。

03第一定理：无失真信源编码

Theorem 定理 · Shannon 第一定理 (1948)

设 {Xi} 为 i.i.d. 信源，熵 H(X)。

  • 可达性：∀ R > H(X)，存在速率为 R 的编码方案，使错误概率 Pe(n) → 0。
  • 逆定理：∀ R < H(X)，任何速率为 R 的方案都有 Pe(n) → 1。

故 H(X) 是无失真压缩的确切极限，不多一比特，不少一比特。

Proof 证明 · 可达性（典型集编码）

构造：

  1. 取 ε > 0 使 H+ε < R。划分 𝒳n 为典型集 Aε(n) 与其补集。
  2. 典型序列：因 |Aε(n)| ≤ 2n(H+ε)，可用 n(H+ε)+1 比特给它们逐一编号，首位标 0。
  3. 非典型序列：用 n log|𝒳| + 1 比特暴力编号，首位标 1。

分析平均码长：

E[ℓ(Xn)]/n ≤ (1−ε)·(H+ε+1/n) + ε·(log|𝒳|+1/n) ≤ H + ε + ε·log|𝒳| + 1/n = H + ε' ε' 可任意小

取 n 足够大、ε 足够小，即得平均速率 < R，且错误概率为 0（这是无损编码）。∎

Proof 证明 · 逆定理

若 R < H，则码本最多能索引 2nR 个序列。但每个典型序列概率 ≈ 2−nH，故被覆盖的总概率至多

2nR × 2−n(H−ε) = 2−n(H−R−ε) → 0 当 R < H−ε

即：能被正确表示的序列，其总概率指数地趋于 0，故 Pe → 1。∎

Corollary 推论
  • 对有记忆信源（平稳遍历），极限是熵率 H(𝒳) = lim H(Xn|X₁…Xn−1)，而非单符号熵。英文文本熵率 ≈1.3 bit/字母 ≪ 单字母熵 4.14 bit。
  • 与 L1 的 Kraft 界一致：L1 给出 H ≤ L < H+1（单符号），本定理通过成块把 "+1" 摊薄为 "+1/n" → 0。
  • 这解释了 ZIP/gzip 为何对文本效果好（高冗余）而对已压缩文件无效（已接近熵）。

04Fano 不等式：所有逆定理的引擎

Theorem 定理 · Fano 不等式 (Fano, 1952)

设想从 Y 估计 X，估计量 X̂ = g(Y)，错误概率 Pe = Pr{X̂ ≠ X}。则

H(Pe) + Pe · log₂(|𝒳| − 1) ≥ H(X | Y) 常用弱化形式： 1 + Pe · log₂|𝒳| ≥ H(X|Y) 解出： Pe ≥ [ H(X|Y) − 1 ] / log₂|𝒳|
Proof 证明

定义指示变量 E = 1{X̂ ≠ X}。用两种顺序展开 H(E, X | Y)：

H(E,X|Y) = H(X|Y) + H(E|X,Y) = H(X|Y) + 0 ← E 由 X 和 X̂=g(Y) 完全决定 H(E,X|Y) = H(E|Y) + H(X|E,Y) ≤ H(E) + H(X|E,Y) ← 条件减少熵 = H(Pe) + H(X|E,Y) 其中 H(X|E,Y) = Pr{E=0}·H(X|Y,E=0) + Pr{E=1}·H(X|Y,E=1) = (1−Pe)·0 + Pe·H(X|Y,E=1) ≤ Pe · log₂(|𝒳|−1) （E=0 时 X=X̂ 已知，熵为 0；E=1 时 X 只剩 |𝒳|−1 种可能） 合并：H(X|Y) ≤ H(Pe) + Pe·log₂(|𝒳|−1) ∎
Fano 在说什么（费曼版） "如果看完 Y 之后你对 X 还很不确定（H(X|Y) 大），那你就一定经常猜错（Pe 大）。"
这个"废话"一旦量化，就成了证明一切不可能性的标准工具：想证明某速率做不到，就证明它导致 H(X|Y) 大，再由 Fano 推出 Pe 无法趋于 0。

Fano 不等式也是统计学 minimax 下界的主力工具（Le Cam 方法、Assouad 引理与之并列），在现代机器学习理论中被大量使用。

05第二定理：有噪信道编码

Theorem 定理 · Shannon 第二定理 (1948)

对离散无记忆信道，容量 C = maxp(x) I(X;Y)。

  • 可达性：∀ R < C，存在 (2nR, n) 码序列使最大错误概率 λ(n) → 0。
  • 逆定理：任何使 Pe(n) → 0 的码序列必满足 R ≤ C。

这是整个通信工程最重要的定理：它宣布"有噪声"并不意味着"必然出错"。

Proof 证明 · 可达性（随机编码，五步）

① 随机生成码本。固定达到容量的输入分布 p(x)。独立地按 Π p(xi) 随机抽取 2nR 个长度为 n 的码字，排成码本 𝒞。码本对收发双方均已知。

② 编码。要发送消息 w ∈ {1,…,2nR}，就发送第 w 个码字 xn(w)。

③ 译码（联合典型性译码）。收到 yn 后，寻找唯一的 ŵ 使 (xn(ŵ), yn) 联合典型。若不存在或不唯一，报错。

④ 分析错误概率。由对称性，设发送 w=1。两类错误：

E₀：真码字不典型 Pr{E₀} → 0 由联合 AEP 性质 1 Ej：某个错码字 j≠1 碰巧与 yn 联合典型 Pr{Ej} ≤ 2−n(I(X;Y)−3ε) 由联合 AEP 引理 union bound: Pe ≤ Pr{E₀} + Σj=22nR Pr{Ej} ≤ ε + (2nR − 1) · 2−n(I−3ε) ≤ ε + 2−n(I − R − 3ε) 若 R < I(X;Y) − 3ε，则指数为负 ⟹ Pe → 0 ✓

⑤ 去随机化（关键的最后一步）。上面算的是所有随机码本的平均错误概率。既然平均值 < ε，那么至少存在一个具体码本 𝒞* 其错误概率 < ε。

再补一步：从 𝒞* 中扔掉错误概率最大的一半码字，剩下的码字最大错误概率 < 2ε，而速率仅从 R 降到 R − 1/n（可忽略）。这样把"平均错误概率"升级为"最大错误概率"。∎

Shannon 证明的革命性与代价 革命性：他没有构造任何具体的码，而是证明"随机地造码，平均表现就已足够好，故好码必然存在"。这是概率方法（probabilistic method）在工程中最早也最辉煌的应用之一。

代价：这是非构造性的。定理说好码存在，却不告诉你是哪个。随机码本身无法使用——它需要 2nR 个长度 n 的码字，存储和译码复杂度都是指数级。

后续 60 年的历史，就是"找出可实用的好码"：Hamming (1950) → 卷积码 → Reed–Solomon (1960) → LDPC (Gallager 1962，被遗忘 30 年后于 1996 复兴) → Turbo 码 (1993) → Polar 码 (Arıkan 2009，首个被证明可达容量且复杂度可行的构造)。5G 标准同时采用了 LDPC（数据信道）与 Polar（控制信道）。

06逆定理：为什么不能超过 C

Proof 证明 · 弱逆定理（Fano + DPI 标准流程）

设消息 W 均匀分布于 {1,…,2nR}，则 H(W) = nR。链路为 W → Xn → Yn → Ŵ。

nR = H(W) = H(W|Yn) + I(W;Yn) ≤ [1 + Pe(n)·nR] + I(W;Yn) ← Fano 不等式 ≤ 1 + Pe(n)·nR + I(Xn;Yn) ← 数据处理不等式 ≤ 1 + Pe(n)·nR + nC ← 无记忆性（下面单独证） 两边除以 n： R ≤ 1/n + Pe(n)·R + C 令 n→∞ 且 Pe(n)→0： R ≤ C ∎

补证 I(Xn;Yn) ≤ nC：

I(Xn;Yn) = H(Yn) − H(Yn|Xn) = H(Yn) − Σi H(Yi|Xi) ← 无记忆性 ≤ Σi H(Yi) − Σi H(Yi|Xi) ← 次可加性 = Σi I(Xi;Yi) ≤ nC ∎
Corollary 推论 · 强逆定理（Wolfowitz 1957）

弱逆只说"Pe 不能趋于 0"，强逆说得更狠：

若 R > C，则 Pe(n) → 1（指数速度）

即：超过容量不是"错误率略高"，而是几乎必然全错。容量 C 是一道悬崖而非缓坡。这个"全或无"的相变现象是信息论最优美的结论之一。→ 精细刻画见 L3 有限块长

07随机编码的哲学：为什么"乱造"反而最优

Concept 概念

直觉上，好码应该精心设计——码字之间距离尽量远。但 Shannon 证明随机码就已渐近最优。为什么？

几何图像：在 n 维空间中，每个码字周围有一个"噪声球"，半径由噪声功率决定。可靠通信要求这些球不重叠。

  • 空间总"体积" ≈ 2nH(Y)
  • 每个噪声球"体积" ≈ 2nH(Y|X)
  • 最多能塞下的球数 ≈ 2nH(Y) / 2nH(Y|X) = 2nI(X;Y)

这就是容量的球堆积（sphere packing）解释。而在高维空间中，随机放置的点几乎必然彼此远离——这是高维几何的"测度集中"现象。维度越高，随机越接近最优。

高维空间的反直觉 在 2 维平面上随机撒点，很容易撞在一起。但在 1000 维空间中，随机撒的点几乎总是近似正交、彼此等距。
Shannon 的证明本质上是在说：不要试图在高维空间里手工设计，随机就是最好的设计。
同样的现象支撑着现代机器学习——高维随机初始化、随机投影（Johnson–Lindenstrauss 引理）、dropout 都在利用测度集中。

08分离定理：为什么系统可以分模块设计

Theorem 定理 · 信源—信道分离定理

对平稳遍历信源（熵率 H）与 DMC（容量 C）：

  • 若 H < C，则存在方案使传输错误概率 → 0；
  • 若 H > C，则不可能可靠传输。

而且，先信源编码（压到 H）再信道编码（保护到 C）这种两段式设计，与任何联合设计一样好（渐近意义下）。

Corollary 推论 · 工程意义与边界

意义：这是现代通信系统架构的理论许可证。JPEG（信源编码）与 LTE 纠错（信道编码）可以由不同团队、不同标准独立开发，组合起来仍是最优的。分层协议栈因此成为可能。

但分离定理会失效，当：

  • 有时延约束（有限块长）——见 L3，实时视频通话就属此类；
  • 多用户场景——如多址接入信道传输相关信源，联合设计严格优于分离；
  • 信道状态未知或时变；
  • 网络中有中继/广播。

这正是联合信源信道编码 JSCC 与近年 Deep JSCC（用神经网络端到端学习）成为研究热点的原因。

09通用压缩：不知道分布也能最优

Concept 概念

Huffman 与典型集编码都需要预先知道 p(x)。现实中往往不知道。通用（universal）压缩要求：不知道分布，仍渐近达到熵率。

Theorem 定理 · Lempel–Ziv 最优性

对任何平稳遍历信源，LZ78（及 LZ77）算法的压缩率几乎必然收敛到熵率：

limn→∞ (1/n) ℓLZ(X₁,…,Xn) = H(𝒳) a.s.

归属：Ziv & Lempel 1977 (LZ77) / 1978 (LZ78)；最优性证明见 Cover & Thomas §13.5。

Example 例题 · LZ78 手工演练

压缩串 ABABABA：

输入: A B A B A B A

短语1: A        → 字典 {1:A}      输出 (0, A)
短语2: B        → 字典 {2:B}      输出 (0, B)
短语3: AB       → 字典 {3:AB}     输出 (1, B)   [引用短语1 + B]
短语4: ABA      → 字典 {4:ABA}    输出 (3, A)   [引用短语3 + A]

编码结果: (0,A)(0,B)(1,B)(3,A)

序列越长，字典中可复用的长短语越多，压缩率越高。这正是 gzip、PNG、ZIP、GIF 的核心机制（LZ77/LZ78 系列变体）。

Frontier 前沿

"通用压缩"的现代版本是大语言模型：LLM 不需要预设分布，通过学习获得极强的下一 token 预测能力，配合算术编码可实现超越所有传统压缩器的压缩率。DeepMind 2023 年的工作 "Language Modeling Is Compression" 表明，Chinchilla 70B 在无损压缩图像与音频上甚至优于 PNG 与 FLAC 这些专用压缩器。
这反过来支持一个观点：压缩即智能——这正是 Solomonoff 归纳与 Kolmogorov 复杂度所预示的。→ L4 算法信息论

  2. 为什么典型集只占全部序列的极小比例，却承载几乎全部概率？举 n=100、p=0.9 的数字说明。
  3. 写出第二定理逆定理的完整链条，指出每一步用了哪个不等式。
  4. 随机编码证明中，第 ⑤ 步"去随机化"为什么必不可少？如果没有这一步，结论有什么问题？
  5. 什么情况下信源—信道分离定理失效？举两个实际例子。
  6. 强逆定理与弱逆定理的区别是什么？为什么强逆更"可怕"？
参考答案

1. AEP 就是把大数定律用在随机变量 −log₂p(Xi) 上：其样本均值收敛到期望 H(X)。
"概率差不多"是因为 −(1/n)log p(xn) ≈ H 意味着 p(xn) ≈ 2−nH——所有典型序列的概率都被夹在 2−n(H±ε) 之间，故近似均分。

2. n=100、p=0.9：总序列 2¹⁰⁰ ≈ 1.27×10³⁰；H(0.9)=0.469，典型序列约 2⁴⁶·⁹ ≈ 1.3×10¹⁴。占比 ≈ 10⁻¹⁶。
不矛盾的原因：非典型序列虽然数量极多，但每个的概率极低。例如全是 1 的序列（概率 0.1¹⁰⁰）数量只有 1 个但概率可忽略；而"约 90 个 0、10 个 1"的序列虽然只占极小比例，每个概率约 2⁻⁴⁶·⁹，数量乘概率 ≈ 1。

3. nR = H(W) = H(W|Yn) + I(W;Yn) ≤ [1+PenR]（Fano）+ I(Xn;Yn)（DPI，因 W→Xn→Yn）≤ 1+PenR+nC（无记忆性 + 熵的次可加性）。除以 n 取极限得 R ≤ C。

4. 因为前面计算的是码本随机时的平均错误概率 E𝒞[Pe(𝒞)]。这只说明"平均而言好"，但实际通信必须用某个确定的码本。
去随机化用的是初等但关键的论证：若平均值 < ε，则至少存在一个个体 < ε。没有这一步，结论只是"随机码平均不错"，而非"存在好码"——后者才是定理要断言的。
进一步，扔掉最差一半码字是为了把"平均错误概率"提升为"最大错误概率"（对每个消息都可靠，而非平均可靠）。

5. 失效条件：有限块长/时延约束、多用户网络、时变或未知信道、有中继的网络。
例1：实时视频通话——时延不允许长块编码，联合信源信道编码（如 Deep JSCC）优于分离设计，且能实现"优雅降级"而非悬崖式断连。
例2：多个传感器向同一基站传相关数据（如温度阵列）——分布式联合设计（Slepian–Wolf 类）严格优于各自压缩后独立传输。

6. 弱逆：R > C ⟹ Pe 不趋于 0（可能停在某个较小的常数）。强逆：R > C ⟹ Pe → 1，且指数速度。
更"可怕"是因为它排除了"稍微超速换取略高错误率"的工程折中幻想。容量是悬崖：超一点点，通信就彻底失效，几乎每个码字都译错。这使 C 成为真正的硬边界。
