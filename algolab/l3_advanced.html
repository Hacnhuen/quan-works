01摊还分析：把"贵操作"摊薄

概念 · 三种方法

聚合分析：总代价 / 操作数。记账法：给操作预收"信用"，贵操作花信用。势能法：定义势函数 Φ，摊还代价 = 实际 + ΔΦ，使坏状态的高代价被之前积累的势抵消。

示例 · 动态表（加倍）

数组满时倍增容量。插入 n 个元素：第 k 次加倍复制 2^{k-1} 个元素，总复制 ≤ 2n，故 n 次插入总 O(2n)，摊还 O(1)/次——尽管某次插入是 O(n)。势函数法：令 Φ = 2·(已用 − 容量/2)，可严格证得每次摊还 ≤ 3。

推论

斐波那契堆借助摊还，使 Dijkstra 在稠密图上降到 O(E + V log V)；并查集的路径压缩也靠摊还（见下节）。

02字符串：KMP 与失配函数

公式 · 失配函数与匹配
π[i] = max{ k < i : P[0..k-1] = P[i-k+1..i] } （最长真前缀=后缀） 匹配时文本指针 i 失配于 j+1：令 j = π[j]，重复直到匹配或 j=0
定理 · KMP 线性匹配（A10）

用模式 P（长 m）在文本 T（长 n）中匹配，预处理失配函数 π（π[i]=P[0..i] 的最长真前缀同时也是后缀的长度），使匹配过程 O(n+m)，无需回退文本指针。

证明骨架

当 T[i]≠P[j+1]，由 π 直接把模式右移 j+1−π[j] 位，跳过已隐含匹配的部分；每步文本指针只进不退，故总比较 O(n+m)。π 自身在 O(m) 内自匹配算出。■

示例

P="ABABAC"。π=[0,0,1,2,3,0]。文本 "ABABABAC" 中，第 6 位失配时由 π[4]=3 右移，避免回溯。后缀数组（L3/L4）是 KMP 在"全后缀排序"上的推广。

03高级数据结构：并查集的近乎常数

定理 · 并查集摊还 O(α(n))（A5）

对 n 个元素做"路径压缩 + 按秩合并"的并查集，m 次操作（含 find/union）总复杂度 O(m·α(n))，其中 α 是逆阿克曼函数——增长极慢，宇宙级 n 也 < 5。

证明骨架

按秩合并保证树高 O(log n)；路径压缩进一步压平。Tarjan 用"秩分层 + 势能"证明单次摊还不超 O(α(n))。α(n) = min{k : A_k(1) ≥ n}，A 为阿克曼函数。■

概念 · 其它高级结构

跳表：用随机多层链表实现有序集合，期望 O(log n) 查找/插入。持久化结构：保留所有历史版本（函数式编程/版本控制）。二项/斐波那契堆：摊还最优优先队列。

实践提醒 跳表因实现简单、并发友好，在 Redis 等系统中比红黑树更受青睐；理论复杂度和红黑树同阶，但常数与工程性更优。

04随机算法：让概率替你想

概念 · 复杂度类

RP：错误只在"否"时，多项式时间可重复降至任意小。ZPP：期望多项式时间的 Las Vegas（一定对）。BPP：双向错误概率小。

定理 · 快速选择期望线性

选第 k 小元素，随机选主元划分，期望比较次数 Θ(n)（比排序快，因为只排一侧）。最坏仍 O(n²)，但随机化使最坏概率可忽略。

示例 · Miller-Rabin

素数判定：确定性对大数慢，Miller-Rabin 随机取底做费马式测试，错判合数概率每轮 ≤ 1/4，重复 40 轮后 < 2⁻⁸⁰——密码学（RSA 密钥生成）基石。

前沿

随机化贯穿 L4：流式草图（AMS/Count-Min）、局部敏感哈希（LSH）、以及"随机化在 P=NP 之外能否分离复杂度类"的理论问题。

05近似算法：NPC 面前的体面退场

概念 · 近似比

对最小化问题，若算法输出值 ALG ≤ ρ·OPT，则称 ρ-近似（ρ≥1）。APX = 存在常数近似比的问题类；PTAS = 对任意 ε 有 (1+ε)-近似（但时间可能随 1/ε 爆炸）；FPTAS = PTAS 且时间多项式于 1/ε。

定理 · 顶点覆盖 2-近似（A7）

贪心取边两端：每取一条未覆盖边 (u,v)，其代价 ≤ u、v 在任一最优解中的贡献之和，故 2·ALG ≥ OPT，即 2-近似。

推论 · 集覆盖

贪心每轮选"覆盖最多未覆盖元素"的集合，得 H(n)-近似 ≈ ln n；这是对数近似的典型。而若 UGC 成立，集覆盖不能比 (1−o(1))ln n 更好（L4 PCP 硬度的后果）。

示例 · 度量 TSP

欧氏/三角不等式下：MST → 走两遍得 2-近似；再 shortcut 仍 ≤ 2·OPT。Arora 给出几何 TSP 的 PTAS（L4）。

06FFT：把多项式乘法从 O(n²) 拽到 O(n log n)

定理 · Cooley–Tukey（A6）

在 O(n log n) 内把 n 点 DFT（及多项式乘法）算出。多项式乘法：点值表示下乘法是 O(n)，故"系数→点值（FFT）→乘→系数（逆 FFT）"整体 O(n log n)，优于朴素 O(n²)。

示例

大整数乘法（Karatsuba O(n^{1.585}) 之上，FFT 实现 O(n log n)）、卷积、信号处理、乃至 L4 分布式矩阵乘的基础。Strassen 矩阵乘 O(n^{2.81}) 是另一支"分治降次"。

07计算几何选萃

概念 · 扫描线

平面问题（线段相交、最近点对、凸包）常用"扫描线 + 平衡 BST"在 O(n log n) 内解决。Graham 扫描求凸包 O(n log n)。

示例 · 最近点对

分治：按 x 中线分左右，递归得 d，再只查中线 ±d 带内按 y 排序的点对，O(n log n)。这正是 L1 提到的分治实例的严格版。

前沿

高维近似最近邻（ANN）用 LSH（见随机节）在亚线性时间近似求解，是向量检索/大模型检索的底层支撑（L4 学习）。

08自检

QUIZ
  1. 动态表插入为什么摊还是 O(1)？三种摊还方法各叫什么？
  2. KMP 的 π 数组是什么？匹配复杂度为什么是 O(n+m)？
  3. 并查集路径压缩 + 按秩合并的单次代价是什么量级？α(n) 是什么？
  4. 顶点覆盖的 2-近似怎么证？集覆盖的近似比是多少？
  5. FFT 把多项式乘法从什么复杂度降到什么？
答案

1. 加倍复制总代价 ≤ 2n，摊均 O(1)。三法：聚合 / 记账 / 势能。

2. π[i]=P[0..i] 最长"真前缀=后缀"长。文本指针不回退 ⇒ O(n+m)。

3. 摊还 O(α(n))，α 是逆阿克曼函数（增长极慢）。

4. 每取边两端代价 ≤ 其在 OPT 的贡献和 ⇒ 2·ALG≥OPT。集覆盖 H(n)≈ln n 近似。

5. 从 O(n²) 降到 O(n log n)。
