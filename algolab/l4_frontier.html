01参数化算法：把难度关进小盒子里

公式 · 参数化复杂度
FPT：T(n,k) = f(k) · n^{O(1)} （k 小 ⇒ 实际可解） 核化：实例 (x,k) → (x',k')，|x'| ≤ g(k)，且可解当且仅当原可解
概念 · FPT

许多 NPC 问题在"参数 k 很小"时实际可解。若问题可在 f(k)·n^{O(1)} 内求解，则称固定参数可处理（FPT）。核心是核化（kernelization）：在多项式时间内把实例化简为大小仅依赖 k 的等价核。

定理 · 顶点覆盖核（A·参数化）

顶点覆盖有大小 ≤ 2k 的核：反复取度为 ≥ 3 的边的两端（贪心），否则图是"几乎匹配"，规模已被 k 约束。于是顶点覆盖可在 O(2ᵏ·n) 内求解（分支算法）。

示例

k=10 时 2¹⁰=1024，对百万级图也瞬间完成——尽管未参数化时是 NPC。这是"实际可解"研究的典范。

前沿

W-层级（W[1]⊆W[2]⊆…）刻画"多参数下仍难"的问题；k-路径、聚类等是否 FPT 仍是活跃问题。与机器学习结合的"可学习参数化"是新兴交叉。

02在线算法：看不见未来怎么决策

概念 · 竞争比

在线算法逐请求决策，看不到未来。其性能用竞争比衡量：ALG(I)/OPT(I) 的最坏上界（对最小化）。若 ≤ c 则称 c-竞争。

定理 · 秘书问题最优停止（A14）

从 n 个依次到达、随机排序的候选中选"最佳"，最优策略是：先观察前 ⌊n/e⌋ 个不选（建立基准），之后第一个优于所有已见者即选。成功概率恰趋近 1/e ≈ 0.368。

推论 · Paging

缓存淘汰：LRU 与 FIFO 是 k-竞争的（k=缓存大小）；任何确定性在线算法至少 k-竞争（边界由对手构造）。Random 标记算法也是 k-竞争。k-server 问题（广义 paging）的竞争比仍是开放难题（k-server 猜想：存在 k-竞争算法）。

示例

实验室 07 演示 paging 命中率 vs 离线最优；实验室 08 演示秘书问题阈值滑块与选中概率曲线。

03流式与亚线性：扫一遍就够

概念 · 数据流模型

数据以流到达，只允许多遍扫描受限、内存 O(log n) 级。目标：用亚线性空间估计频数、基数、分位数。

定理 · Count-Min 草图

用 w×d 计数矩阵（d 个独立哈希），点查询频数估计 ≤ true + ε·‖f‖₁ 且误差概率 ≤ δ，宽度 w=O(1/ε)、深度 d=O(log 1/δ)。空间 O((1/ε) log(1/δ))。

示例 · Flajolet–Martin 基数

估计流中不同元素数：用哈希后"最低位连续 0 的个数"的极大值 R，估计 2^R。合并多个估计得误差约 1.04·√m 的近似。是 HyperLogLog 的祖先。

前沿

亚线性"性质测试"（如测试数组是否近似排序）只需 O(1) 样本；与差分隐私结合（私有流式）是隐私+算法的热点。

04分布式与并行算法

概念 · 模型

PRAM：共享内存多核；CONGEST/BSP：通信受限的分布式网络（每轮每条边传 O(log n) 位）；MapReduce：大规模批处理。

定理 · 分布式 MST 下界

在 CONGEST 模型中，即使无故障，计算 MST 的轮数下界为 Ω(√V + D)（D=直径），存在 O(√V + D) 上界算法——上下界匹配（上下界均为 Ω(√V+D) 量级，可达紧）。

前沿

现代 GPU/TPU 上的并行算法（矩阵乘、图神经网络聚合）与"通信复杂度"理论交叉；联邦学习把"分布式优化"与隐私绑在一起（见下节）。

05PCP 定理：近似难度的数学核武器

定理 · PCP 定理（A12）

NP = PCP(log n, 1)：每个 NP 语言可由随机读取 O(log n) 个比特、允许常数错误概率的"概率可检验证明"系统验证。它是连接"证明复杂性"与"近似硬度"的桥。

证明骨架（思路）

通过"并行重复"与"长码测试"等工具，把 NP 证明编码成可被随机少量查询检验的形式；Feige–Lovász–Tetali 等把 PCP 归约成"标签覆盖（Label Cover）"的近似硬度。

推论 · 近似硬度

由 PCP + 归约：最大独立集无近似到 n^{1−ε}（除非 P=NP）；在 UGC（唯一博弈猜想）下，最大可满足(Max-2SAT) 的 0.94 近似比是最优的，顶点覆盖不能改进到 2−ε（呼应 L3 A7）。

前沿

UGC 是否成立是近似算法领域最大悬案之一；近年"二维通信复杂度"等工作把更多问题的近似阈值钉死，也出现了突破（如特定几何聚类）。

06平滑分析：为什么单纯形"实践很快"

定理 · Spielman–Teng（A15）

单纯形法在最坏输入下是指数级，但对"任意输入加极小随机扰动（σ-平滑）"的期望运行时间是多项式的：O(n^{O(1)} · φ(n,σ))。这解释了它几十年实践中的高效。

示例

现实中数据几乎不会是"精心构造的最坏例"，而是带噪声的——平滑分析把"最坏"换成"最坏+微扰"，预言了实际表现。这是"理论最坏 ≠ 实践平均"的经典统一。

前沿

平滑分析被推广到局部搜索、聚类（k-means 平滑下多项式时间）、乃至深度学习损失景观——连接了 L7 的"学习"。

07算法 + 学习：当算法遇见 AI

概念 · 三层交叉

① 算法为学习服务：SGD/Adam 优化、加速方法（Nesterov）、泛化差距的算法视角（stability → generalization, Bousquet–Elisseeff）。

② 学习为算法服务：用神经网络学启发式（如路网最短路、SAT 求解、调度）——"Learned Index"（Kraska et al.）用模型替 B-Tree。

③ 信息论桥梁：交叉熵损失 = KL 散度（信息论馆 L1），困惑度 = 2^{交叉熵}——大模型训练本质是极小化信息的"惊喜度"。

示例 · 泛化差距上界

算法稳定性（平均稳定性 β）给出泛化差距 O(β + 1/√n) 的高概率界。这是"算法性质 → 学习保证"的直接通道，也是信息论中"互信息 → 泛化"（Xu–Raginsky）的近亲。

前沿

子模优化（贪心与机器学习特征选择）、在线学习（Regret 最小化，对标本节 02 在线算法）、以及"可证明加速的优化器"是算法与 AI 最热的接口。

08开放问题与可检验预测

问题现状可检验预测 / 信号
k-server 猜想是否存在 k-竞争确定性算法？仅知随机 k-竞争（含指数空间）若被证伪，应出现 O(k) 确定性算法；若证实，需构造下界
UGC（唯一博弈猜想）若成立，许多近似比达到最优可在具体问题上检验近似阈值是否被逼近（如 Max-2SAT 0.94）
3SUM 猜想能否在 o(n²) 内解 3SUM？多数认为不能若存在 o(n²) 算法，将推翻一串下界；目前最强 ~n²/(log n)^{...}
矩阵乘指数 ω已知 2 ≤ ω < 2.371339（2024 进展）预测 ω 持续下探但 >2；若达 2 将是地震级结果
参数化内核下界顶点覆盖核 2k 已知；更多问题核大小?可用核化下界（OR 组合技术）检验某问题是否无多项式核
学习为算法服务Learned Index 已实用，缺统一理论预测"误分布偏移"下的稳定性可被算法稳定性界刻画
给研究者的建议 这些开放问题都"可被代码检验"：例如复现 3SUM 各变体的当前最优界、验证 UGC 推导出的近似阈值、或跑一遍 matrix-multiplication exponent 的最新算法。本馆 verify/ 流水线已对其中若干常数（如 1/e、2-近似比、α(n) 行为、矩阵乘指数区间）做了独立复算。

09自检

QUIZ
  1. 什么是 FPT？顶点覆盖核的大小是多少？
  2. 在线算法的"竞争比"定义？秘书问题最优停止阈值的成功概率是多少？
  3. Count-Min 草图用多少空间估计频数？误差界形式？
  4. PCP 定理说什么？它和近似硬度有什么关系？
  5. 平滑分析解释了什么"反直觉"现象？
  6. 算法与学习的三个交叉方向各举一例。
答案

1. f(k)·n^{O(1)} 求解；顶点覆盖核 ≤ 2k。

2. ALG/OPT 最坏上界；秘书问题成功概率→ 1/e ≈ 0.368。

3. O((1/ε)log(1/δ))；估计 ≤ true + ε·‖f‖₁，误差概率 ≤ δ。

4. NP=PCP(log n,1)；它是近似硬度的来源（如顶点覆盖 2−ε 不可改进，若 UGC）。

5. 单纯形法最坏指数但实践很快——因为现实输入是"最坏+微扰"。

6. ①算法为学习：SGD 优化；②学习为算法：Learned Index；③信息桥：交叉熵=KL。
