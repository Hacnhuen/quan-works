01六步学习循环：把"看懂"变"会造"

框架 · LEARN 循环
① L ocate 定位：在五层阶梯里找你当前坐标（L0–L4） ② E xamine 细读：按七元素模板读概念/定理/证明/推论/公式/示例/前沿 ③ A pply 应用：进实验室动手调参，让数字与证明对拍 ④ R ecast 复述：用费曼卡把概念讲给"外行"+手算例子 ⑤ N eglect? 测验：做每页 <details> 自检，错哪补哪 ⑥ L ink 连接：连到相邻概念（知识图谱箭头），向外扩展到前沿
关键 不要停在 ②。算法的本质是"做对且快"，只有 ③ 和 ⑤ 能暴露你其实没懂。每完成一轮，回到 ① 看是否升了一层。

02费曼卡：每个概念一张

模板

正面：概念名 + 一句话比喻。背面：① 一句严格定义；② 一个 10 秒内可手算的小例子；③ 一个"什么时候会错/失效"的反例。做不到背面 ② → 没真懂。

范例卡 · 贪心

比喻：每步拿眼前最好的。反例：面额{1,3,4}凑6，贪心3枚 vs 最优2枚。何时对：贪心选择性质 + 最优子结构（活动选择、MST）。

AI-费曼 接口 verify.html 的"费曼报告"就是把每张卡喂给可解释性代理，要求它用白话+手算例子复述。能过 = 可解释达标。

04深 / 广化螺旋：不断加深加宽

两个方向

深化：同一概念沿 L0→L4 反复回来。例："二分"——L0 猜数字 → L1 O(log n) → L2 决策树证明 → L3 分治 → L4 在参数化里再出现。

广化：从一个节点沿知识图谱箭头走到相邻域。例："最大流最小割" → 对偶（线性规划）→ 信息论最大互信息 → 学习泛化界。

前沿连接

每一层的"前沿"块都是一扇门：L2 的 NP 完全 → L4 的 PCP/近似硬度；L3 的随机 → L4 的流式/在线；L1 的哈希 → L4 的 LSH/检索。把"学过的"当跳板，而不是终点。

05假设拆解法：看懂证明的关键

方法

每个定理都挂在假设上。读证明前先列假设，再问"哪个假设去掉会怎样"：

Dijkstra：假设"边权非负" → 去掉 ⇒ 需 Bellman-Ford 主定理：假设"a,b 常数" → 不常数 ⇒ Akra–Bazzi 顶点覆盖 2-近似：假设"可任意选边" → 若 online ⇒ 竞争比下界

把假设当"开关"，你就从"背结论"变成"懂边界"。这是研究生以上做研究的起步训练。

06间隔重复排程：对抗遗忘

排程表（基于间隔效应）
第 0 天：读完 + 费曼卡 第 1 天：重做自检（测验效应） 第 3 天：重做 + 连一个相邻概念 第 7 天：重做 + 进实验室调一次参 第 16 天：重做 + 写一张"假设拆解"卡 第 30 天：回到本层，尝试升一层
为什么有效 测验（主动回忆）比重读强得多（Roediger & Karpicke 2006）；间隔比集中突击留存更久（Cepeda 2006）。本馆每页自检即"可嵌入的测验点"。

08反模式清单：别这样做

踩坑预警
✗ 只背模板不写证明 → 遇到变体即崩 ✗ 只跑代码不手算小例子 → 错在边界也发现不了 ✗ 把 O 当 Θ 用 → 掩盖了期望/最坏的差异 ✗ 忽略假设 → 把 Dijkstra 用在负权图 ✗ 一次性突击 → 间隔重复才是留存关键 ✗ 只看不动 → 实验室不调参，直觉长不出来
给研究者的最后一句话 算法的审美是"正确 + 紧界 + 优雅"。当你能为一个算法写下"假设—证明—边界—反例—前沿"五段，你就已经在做研究，而不只是学算法。
