01猜数字：二分是怎么省力的

想象我在 1–100 里想了一个数，你每次只能问"比 x 大吗？"。怎么问最省次数？

概念 · 二分搜索

每次都猜中间那个数。无论答案如何，都能砍掉一半可能。100 个数，每问一次减半：100 → 50 → 25 → 13 → 7 → 4 → 2 → 1，最多 7 次。

为什么是 7？因为 2⁷ = 128 > 100。推广：在 n 个数里找 1 个，最多需要 ⌈log₂ n⌉ 次。

示例 · 手算到底

目标 = 73。问 50（太大？否，>50）→ 区间 [51,100]；问 75（>75？否）→ [51,75]；问 63（>63？是）→ [64,75]；问 69（是）→ [70,75]；问 72（是）→ [73,75]；问 74（否）→ 73。共 6 次。最坏才是 7 次（⌈log₂100⌉=7）。

直觉要点 "每次砍一半"是算法里最强大的想法之一。它在 L2 的最短路、L3 的分治、甚至信息论里反复出现——把不确定性减半。

02排序：最少要比几次？

把一叠乱序的牌排好，至少要比较多少次？这引出了算法里第一个"下界"。

概念 · 比较排序下界

3 张牌，可能的顺序有 3! = 6 种。每比一次最多排除一半可能。要分清 6 种，至少需要 ⌈log₂ 6⌉ = 3 次比较——但这只是信息论下界，实际排序往往要更多。n 张牌需要至少 ⌈log₂(n!)⌉ 次比较，约等于 n log₂ n。

示例 · 3 张牌

牌 a,b,c。先比 a:b，再比小的与 c……最差 3 次能排好。数很大时（如 100 张），下界约 ⌈log₂(100!)⌉ ≈ 525 次，而归并排序用约 100·log₂100 ≈ 665 次——很接近下界。

通往大师 这个"下界"在 L1 会变成严格的 Ω(n log n) 证明（决策树高度），在 L3 会与信息论（熵）打通。先记住感觉：排序不可能比 n log n 更快。

03贪心第一感：每一步都选"当下最好"

贪心 = 每一步做局部最优选择，希望最后全局也最优。有时对，有时错——关键是知道什么时候对。

概念 · 贪心

对的例子（换硬币）：用 25/10/5/1 分的硬币凑 67 分。每次拿能拿的最大面额：25+25+10+5+1+1=67，6 枚，确实最少。因为当硬币体系是"规范"的（canonical），贪心最优。

错的例子：若面额是 {1, 3, 4}，要凑 6 分。贪心拿 4，剩 2 只能 1+1 → 4+1+1 = 3 枚；但最优是 3+3 = 2 枚。贪心在这里翻车。

核心教训 贪心好不好，不能凭感觉，要证明（L2 的贪心选择性质 + 最优子结构）。这正是算法思维：把"感觉对"变成"能证明对"。

04状态与步骤：算法到底是什么

剥离所有术语，算法的本质就三件事。

概念 · 算法三要素
① 输入：明确的数据（一张图、一个数组、一个数） ② 步骤：有限、确定、可机械执行的操作序列 ③ 输出：对输入给出正确结果，且保证在有限步内停下

更进一步，评价一个算法看两件事：对不对（正确性）和快不快（效率/复杂度）。后面四层都在把这两件事做到极致。

07自检 · 你真的懂了吗

QUIZ · 试着不看上文答出来
  1. 在 1–1000 里猜一个数，用二分最多要几次？为什么？
  2. 为什么"换硬币"有时贪心会失败（举一个面额集合）？
  3. 排序的下界大约是多少（用 n 表示）？它和"信息"有什么关系？
  4. 算法除了"对不对"，还要看什么？
答案

1. ⌈log₂ 1000⌉ = 10 次（2¹⁰=1024>1000）。每次减半不确定性。

2. 面额 {1,3,4} 凑 6：贪心 4+1+1=3 枚，最优 3+3=2 枚。说明局部最优≠全局最优。

3. 约 n log₂ n（严格 Ω(n log n)）。因为要分辨 n! 种顺序，每比较减半信息，最少 ⌈log₂(n!)⌉ ≈ n log₂ n 次。

4. 还看"快不快"——即时间/空间复杂度（L1 正式定义）。
