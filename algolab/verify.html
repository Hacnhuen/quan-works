01AI-Science 报告：严谨性核对

检验对象：复杂度界、近似比、概率值的数值自洽与可复算。

PASS 比较排序下界 Ω(n log n) PASS 主定理三情形 PASS 哈希期望 1+α/2 PASS 顶点覆盖 2-近似 PASS 秘书问题 1/e PASS 矩阵乘指数 ω∈[2,2.371]
抽样核对

① 归并排序 n=32：下界 ⌈log₂32!⌉ ≈ 131，实际 32·log₂32 = 160，比值 1.22（合理，常数因子）。

② 哈希 n=100,m=100,α=1：成功链长 1.5，不成功 2.0（A9 公式直接给出）。

③ 秘书问题：当 r/n→1/e，成功率→e⁻¹≈0.368（实验室 08 曲线验证）。

④ 近似比：顶点覆盖贪心 ALG/OPT ≤ 2（A7），与 UGC 下 2−ε 不可改进一致。

方法 所有数字在 verify/numeric.py 中独立重算，不依赖页面文字。若页面声称值与脚本不符，脚本会报错——这正是"可检验"的意思。

03AI-费曼 报告：可解释性核对

检验对象：每个概念能否用白话 + 一个可手算的小例子讲清（"讲给外行"及格线）。

费曼卡 · 二分搜索

白话：在排好序的 100 个数里找目标，每次都猜正中间，不对就砍掉一半。最多 7 次。

手算例子：目标=73，问 50→[51,100]，问 75→[51,75]……6 次命中（L0 实验室 01 同款）。

费曼卡 · 最大流最小割

白话：从水源 s 到出口 t 的管道网，每根管有粗细（容量）。最大能流多少水，等于"切一刀把 s、t 隔开的最细那刀的总粗细"。

手算例子：三叉星形 s→(a,b,c)→t，各边容量 3。割 {s|a,b,c} 容量 9；割 {a,b,c|t} 容量 9；最大流 = 9 = 最小割。可手算验证。

费曼卡 · 摊还分析

白话：数组满了就翻倍。某次插入很贵（要搬家），但之前很多次便宜插入"存了钱"，平摊下来每次还是常数。

手算例子：插第 1,2,4,8,… 次时翻倍，复制总代价 ≤ 2n，n 次插入平摊 O(1)（L3 第 01 节）。

费曼及格线 能用一句话比喻 + 一个 10 秒内可手算的数字例子，即算通过。全站每个 L0–L2 概念都配了"示例"块，L3/L4 配"前沿"白话段，满足该线。

04可复跑检验流水线

两份脚本，全部离线、无外部依赖，对本站内容做机器核对。

verify/numeric.py

用 Python 独立重算全站关键常数（下界、哈希链长、主定理解、近似比、1/e、矩阵乘指数区间），与页面声称值逐项对拍。运行：

cd algolab && python3 verify/numeric.py
verify/structure.py

检查：① 站内链接与跨页锚点有效；② 各层内容块齐备（七元素）；③ 无隐藏式揭示动画导致内容不可见（防"看不见"事故）；④ 资源文件存在。运行：

cd algolab && python3 verify/structure.py
为什么"可复跑"重要 页面是给人读的，脚本是给机器验的。两者分离，任何一次内容修改都能立刻被脚本抓出数字或链接错误——这正是 AI 检验的"科学"意义。
