01复杂度记号：怎么"说快慢"

概念 · 渐近记号

设 f(n), g(n) 为输入规模 n 的正函数：

O(g)：存在 c,N，使对所有 n≥N 有 f(n) ≤ c·g(n) （上界，最坏不超） Ω(g)：存在 c,N，使对所有 n≥N 有 f(n) ≥ c·g(n) （下界，至少这么慢） Θ(g)：O(g) 且 Ω(g)，即同阶 （紧界） o / ω：严格小于 / 严格大于（极限意义上）

还有平均与摊还分析：前者对所有输入取期望，后者把偶尔的"贵操作"摊到一系列便宜操作上（L3 详述）。

示例

线性扫描是 Θ(n)；二分搜索是 Θ(log n)；朴素矩阵乘是 Θ(n³)。说"快排是 O(n²)"没错但宽松——它的期望是 Θ(n log n)，最坏才是 O(n²)。表述要区分最坏/期望。

02排序：三种范式的练兵场

定理 · 比较排序下界（A1）

任何只基于"两两比较"的排序算法，最坏情况至少 Ω(n log n) 次比较。证明用决策树：n! 种排列需深度 ≥ ⌈log₂(n!)⌉ = Ω(n log n) 的二叉树。

证明骨架

决策树每个叶子对应一种排列（共 n! 个），二叉树高度 h 满足 2ʰ ≥ n!，故 h ≥ log₂(n!) = n log₂n − O(n) = Ω(n log n)。■

示例 · 归并排序

递归 T(n)=2T(n/2)+Θ(n)，由主定理（L2）得 Θ(n log n)，且最坏也是 n log n——达到下界。快排期望 Θ(n log n) 但最坏 O(n²)。堆排 Θ(n log n) 且原地。

非比较排序 计数/基数/桶排序可突破 Ω(n log n) 下界，因为它们不只用比较，而利用"键的取值范围"信息——这说明下界是有条件的（A1 的"比较排序"前提）。

03图搜索：DFS 与 BFS

概念 · 两种遍历

BFS（广度优先）：用队列，逐层扩展，首次到达即最短路（边权=1）。复杂度 O(V+E)。

DFS（深度优先）：用栈/递归，一条路走到底再回溯。用于拓扑排序、强连通分量、环检测。复杂度 O(V+E)。

定理

在无权图（边权均为 1）上，BFS 从源点首次访问某顶点时的距离，恰为该顶点的最短距离。DFS 可在 O(V+E) 内判定有向图是否存在环并给出拓扑序（当且仅当无环时可拓扑排序）。

示例

社交网络"六度分隔"可用 BFS 求两人最短关系链；编译器的依赖分析中，环检测与拓扑序用 DFS 更自然。两者都在实验室 03 可拖拽演示。

04堆与优先队列

概念 · 二叉堆

数组实现的完全二叉树，满足"父 ≤ 子"（最小堆）。支持：插入 O(log n)、取最小 O(log n)、建堆 O(n)（自底向上下沉）。

定理 · 建堆 O(n)

自底向上对每个非叶节点 sink，总代价 Σ_{h} (层数 h 的节点数 × h) = O(n)，而非 naïve 的 O(n log n)。

推论

堆排序 = 建堆 O(n) + n 次取最小 O(log n) = O(n log n) 原地排序。Dijkstra（L2）依赖优先队列，堆实现为 O((V+E) log V)。

05哈希：O(1) 查找的魔法

概念 · 哈希表

用哈希函数 h(key) 把键映射到桶。理想下每个键独立均匀落桶，查找期望 O(1)。冲突用链地址法或开放寻址处理。

定理 · 链地址法期望查找（A9）

设负载因子 α = n/m（元素数/桶数）。一次成功查找的期望比较次数为 1 + α/2，不成功查找为 1 + α。故平均 O(1+α)；α 有界时即 O(1)。

示例 · 生日与碰撞

哈希值 64 位，≈1.8×10¹⁹ 个桶。由生日悖论，约 √(2·2⁶⁴)≈2³²≈43 亿次插入后碰撞概率显著上升——这正是"生日攻击"对哈希安全的来源（L4 学习/安全交叉）。

最坏不是 O(1) 若对手刻意制造碰撞（同桶），链地址法退化到 O(n)。好的哈希需"抗碰撞"或随机化（L3 随机哈希）。

06分治：把问题劈成两半

概念 · 分治三步
① 分：把规模 n 的问题拆成 a 个 n/b 的子问题 ② 治：递归解决子问题 ③ 合：用 O(nᵏ) 的代价合并结果
示例 · 归并排序

a=2, b=2, 合并 O(n) ⇒ T(n)=2T(n/2)+Θ(n) ⇒ Θ(n log n)。最大子数组（Kadane 是线性 DP，但分治版也是经典）、最近点对（平面分治 O(n log n)）同属此类。FFT（L3）是分治登峰造极之作。

07贪心：何时"只顾眼前"是 safely 最优

概念 · 贪心正确性两性质

贪心算法全局最优，当且仅当问题同时满足：(1) 贪心选择性质（局部最优选择可纳入某全局最优解）+ (2) 最优子结构（子问题最优⇒整体最优）。

示例 · 活动选择

n 个活动各有起止时间，选最多互不重叠的活动。按"结束时间最早"贪心，每次取与已选不冲突且最早结束的——可证最优。霍夫曼编码（信息论馆 L1）也是贪心。

前沿

矩阵乘法的"最优加括号"看似贪心，其实是 DP（L3 链乘）；而"规范硬币体系"的判定本身是个有趣的小问题。何时贪心成立，至今仍有新的结构刻画研究。

08动态规划：用空间换"不重复算"

概念 · DP 两要素

重叠子问题 + 最优子结构。用表格存子问题答案，自底向上或记忆化自顶向下，避免指数级重复。

公式 · 经典递推
LIS： dp[i] = 1 + max{ dp[j] | j
示例 · 0/1 背包手算

容量 W=4，物品 (v,c)=(2,3),(3,4),(1,1)。DP 表填出 dp=4（取物品2+3：价值 3+1=4 占 4+1=5? 错→应取物品1+3：2+1=3占 3+1=4）。正确最优 = 3（物品1+3）。实验室 04 可视化逐格填充。

DP vs 分治 分治的子问题不重叠（各算各的），DP 的子问题大量重叠，所以才需要表格记忆。识别"重叠子结构"是选范式的第一信号。

10自检

QUIZ
  1. O(n log n) 与 Θ(n log n) 的区别？说"快排是 O(n²)"严谨吗？
  2. 比较排序最坏下界是多少？为什么基数排序能突破它？
  3. BFS 与 DFS 各适合解决什么类型的问题？复杂度？
  4. 贪心要满足哪两个性质才保证全局最优？举一个贪心失败的例子。
  5. DP 与分治的根本区别是什么？
答案

1. O 是上界（不超），Θ 是紧界（同阶）。说快排 O(n²) 严谨但宽松；应为"期望 Θ(n log n)，最坏 O(n²)"。

2. Ω(n log n)（决策树）。基数排序非"纯比较"，利用键的位结构，故可 O(nk) 突破。

3. BFS：无权最短路/层次遍历（队列），O(V+E)；DFS：拓扑/环检测/连通分量（栈），O(V+E)。

4. 贪心选择性质 + 最优子结构。失败例：面额{1,3,4}凑6，贪心3枚 vs 最优2枚。

5. DP 子问题重叠需制表记忆；分治子问题不重叠。
