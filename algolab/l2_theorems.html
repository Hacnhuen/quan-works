01主定理：分治复杂度的"自动求解器"

定理 · 主定理（A2）

对递归 T(n) = a·T(n/b) + f(n)，a≥1, b>1 常数，令 n^(log_b a) = n^{ε}（ε=log_b a）：

情形1：若 f(n) = O(n^{ε−δ})（δ>0，即 f 多项式小于），则 T(n) = Θ(n^{ε}) 情形2：若 f(n) = Θ(n^{ε} logᵏn)，则 T(n) = Θ(n^{ε} log^{k+1} n) 情形3：若 f(n) = Ω(n^{ε+δ}) 且 a·f(n/b) ≤ c·f(n)（正则条件，c<1），则 T(n) = Θ(f(n))
示例三连

① 归并排序 a=2,b=2,f=Θ(n) → ε=1，情形2(k=0) ⇒ Θ(n log n)。

② 二分查找 a=1,b=2,f=Θ(1) → ε=0，情形2 ⇒ Θ(log n)。

③ 斯特拉森式 a=7,b=2 ⇒ ε=log₂7≈2.81，f=Θ(n²) 多项式小于 ⇒ Θ(n^{2.81})。

前沿 · 主定理之外

主定理不覆盖 a 非整数、f 为 n^{ε}·log^? 之外的形式（如 Akra–Bazzi generalization 处理非均匀分割）。L3 的 FFT 用不同的分治结构。

02单源最短路：Dijkstra 与 Bellman-Ford

定理 · Dijkstra 正确性（A3）

在所有边权非负的图中，Dijkstra 每次从"未定"集合取出距离最小的顶点 u，则 dist[u] 已是最终最短距离，此后不再更新。由此归纳得全局正确。复杂度（二叉堆）O((V+E) log V)。

证明骨架

假设首次出错：取出 u 时 dist[u] 非最终。设真正最短路先经某未定顶点 v，则 dist[v] ≤ dist[u]（否则 u 不会先被取），与"u 是当前最小"矛盾——且非负权保证绕路不会更短。■

概念 · Bellman-Ford

允许负权，复杂度 O(VE)。松弛 V−1 轮；第 V 轮仍能更新则说明存在负环。是差分约束、货币套利检测的基础。

示例

实验室 03 给出 6 节点图逐步松弛过程，可看到 Dijkstra 距离表逐轮收敛、且一旦取出即锁定。

03最小生成树：Kruskal 与 Prim

定理 · MST 贪心正确性

对图 G 的边按权排序，Kruskal 依次加入不形成环的最小边（并查集判定，L3），得到的必是 MST。等价于"切割性质"：横跨某切割的最小权边必在某 MST 中。

推论

Prim（从一点出发，优先队列取最小跨边）同样得 MST。Kruskal O(E log E)，Prim+堆 O((V+E) log V)。两者都是贪心 + 最优子结构 + 贪心选择性质的实例。

示例

通信基站布线：用最少的线总长连通所有站点 ⇒ MST。若有"必经中继"约束则变 Steiner 树（NP 难，L4）。

04最大流与最小割：图论的皇冠

定理 · 最大流最小割（A4）

在有向图（容量 c(e)≥0）中，从源 s 到汇 t 的最大流量等于最小 s-t 割的容量。即 max flow = min cut。

证明骨架（弱对偶 + 增广路）

(1) 任意流 ≤ 任意割（割容量 ≥ 跨割正向流 − 反向流 ≥ 净流 = |f|）。(2) Ford–Fulkerson：当残量网络无增广路时，令 S=可从 s 到达的点，T=其余；割 (S,T) 上正向边满流、反向边零流，故割容量 = |f|。于是 |f| = 割容量 = 最大流 = 最小割。■

概念 · Edmonds-Karp

每次用 BFS 找最短增广路，复杂度 O(VE²)。是网络流的标准实现。整数容量下 FF 必终止。

推论 · 婚姻定理与二分匹配

最大二分匹配 = 最小顶点覆盖（König）。最大流可解二部图匹配、任务分配、最大权匹配（费用流）。

通往大师 最大流最小割是"对偶性"的第一个强例子，与线性规划对偶（本节 06）、信息论中的最大互信息（信息论馆）同构。L4 还会看到它推广到多商品流（NP 难）。

05NP 完全性：效率疆界的地图

概念 · 复杂度类
P ：多项式时间可解的决策问题 NP ：多项式时间可"验证"解的问题（非"非多项式"！） NPC ：属 NP 且任何 NP 问题都可归约到它（最难的一类 NP 问题） NP-hard：至少和 NPC 一样难，未必在 NP 中
定理 · Cook–Levin

布尔可满足性 SAT 是 NP 完全的（1971）。由此 Karp 给出 21 个经典 NPC 问题归约链：SAT → 3-SAT → 独立集 → 顶点覆盖 → 团 → 哈密顿回路 → 旅行商(TSP) → …

证明骨架

将任意 NP 图灵机的计算过程编码为布尔公式（单元格状态 + 转移约束 + 接受条件），使"存在接受计算"⇔"公式可满足"。从而 SAT 捕获了所有 NP 问题。

示例 · 归约链

证明"顶点覆盖是 NPC"：已知 3-SAT NPC；把每个子句变三角形、每个变量变一条边，可构造图使"3-SAT 可满足 ⇔ 图有大小 k 的顶点覆盖"。归约是证明 NPC 的核心手艺。

前沿

P vs NP 是千禧年七大难题之一（未解）。一旦某 NPC 问题被证明在 P 中，则 P=NP。L4 的近似算法正是在"承认可能无精确多项式解"的前提下求近似。

06线性规划与对偶

概念 · LP

在线性约束下最大化/最小化线性目标。标准型：max cᵀx s.t. Ax ≤ b, x ≥ 0。可用单纯形法（实践快）或内点法（多项式）求解。

定理 · 强对偶

若原问题（P）有最优解，则其对偶（D）也有，且最优值相等：max cᵀx = min bᵀy。对偶变量 y 可解释为"约束的影子价格"。

推论

最大流最小割是 LP 强对偶的特例（流–割对偶）。网络流、二部匹配、许多近似算法都借 LP 松弛 + 取整来设计（L3/L4）。

08自检

QUIZ
  1. 主定理三种情形分别对应 T(n) 的什么渐近界？
  2. Dijkstra 为什么要求"非负权"？负权下会发生什么？
  3. 用一句话说明最大流最小割定理，并给出一个它"对偶"的其它领域例子。
  4. NP 是"非多项式"的意思吗？举一个 NPC 问题的归约链片段。
  5. LP 强对偶说的是什么？
答案

1. 情形1 Θ(n^{log_b a})；情形2 Θ(n^{log_b a} log^{k+1}n)；情形3 Θ(f(n))。

2. 非负权保证"先取最小即锁定"（绕路不会更短）。负权可能使已锁定节点的距离被后续更短路径推翻，结果错误；需用 Bellman-Ford。

3. max flow = min cut。对偶例：LP 强对偶、信息论 max I(X;Y)（信道容量）。

4. 不是，"Nondeterministic Polynomial"=可多项式验证。链：SAT→3-SAT→独立集→顶点覆盖。

5. 原问题与对偶最优值相等：max cᵀx = min bᵀy。
