01五层学习阶梯（J 轴）

从日常直觉到初高衔接，逐级加厚"物理观念 / 科学思维 / 科学探究 / 科学态度与责任"四大核心素养。

J0

启蒙 · 直觉的觉醒

用日常见闻唤醒物理直觉：为什么镜中会有人？为什么石头比羽毛落得快？建立"速度 / 力 / 能量"的朴素图景。

对应：六七年级前导心智：直觉
J1

基础 · 建模与定量

八上核心：机械运动、声现象、物态变化、光现象、凸透镜成像、质量与密度。学会把现象抽象成"模型 + 公式"。

对应：八年级上心智：建模
J2

完备 · 统一与综合

八下核心：力、运动和力、压强、浮力、功和机械能。把分立知识织成"受力—运动—能量"的统一网络。

对应：八年级下心智：统一
J3

专业 · 工具与方法

九上/九下核心：电路、欧姆定律、电功率、电与磁、内能与热机。获得处理"电与能"的定量方法。

对应：九年级心智：方法
J4

前沿 · 边界与衔接

新能源、量子与相对论浅介，以及和高中 L0/L1 的衔接入口。看到初中物理之上是仍向未知敞开的科研疆域。

对应：九年级拓展心智：衔接

03与高中馆的衔接

J1 → L1

速度 v=s/t 升级为加速度 a、匀变速公式；光现象升级为几何光学+波动光学。

J2 → L1

二力平衡/牛顿第一定律升级为牛顿第二定律 F=ma、受力分析体系。

J3 → L2

欧姆定律/电功率升级为静电场、电路分析；电与磁升级为电磁感应。

J4 → L3

能量守恒/新能源浅介升级为守恒量体系与热力学定律。
