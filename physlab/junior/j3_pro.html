J3 · 专业层（九年级）

电与能的定量方法

本层处理"电与能"：电路、欧姆定律、电功率、电与磁、内能与热机，形成初中能量主干。

方法定量对应九年级

J3·1电路基础

概念 · 串并联 串联：电流一条路，分压；并联：多支路，分流、各支路电压相等。是分析一切电路的地基。

J3·2欧姆定律

公式 · 欧姆定律
I = U / R （电阻 R = U / I，是导体属性）
定理 · 串并联电阻 串联 R总=R₁+R₂；并联 1/R总=1/R₁+1/R₂。

J3·3电功率

公式 · 电功与功率
W = UIt P = UI = I²R = U²/R （焦耳定律 Q = I²Rt）

J3·4电与磁

概念 · 磁生电 奥斯特：电生磁；法拉第：磁生电（电磁感应）。电动机与发电机的原理分野。

J3·5内能与热机

公式 · 比热容
Q = cmΔt （热机效率 η = W有用 / Q放）
定理 · 能量守恒 能量既不会凭空产生也不会消失，只会转化或转移，总量不变——初中能量观的顶峰（高中 L2 升级为守恒量体系）。
