01五层学习阶梯

从日常直觉到科研边界，逐级加厚"物理观念 / 科学思维 / 科学探究 / 科学态度与责任"四大核心素养。

L0

启蒙 · 直觉的觉醒

用日常见闻唤醒物理直觉：为什么车急刹人前倾？为什么石头比羽毛落得快？建立"速度 / 力 / 能量"的朴素图景。

对应：义务教育前导心智：直觉
L1

基础 · 建模与定量

必修 1–3 核心：运动学公式、牛顿三定律、匀强场、欧姆定律、功与能。学会把世界抽象成"模型 + 方程"。

对应：必修 1/2/3心智：建模
L2

完备 · 统一与综合

选必核心：动量守恒、机械能守恒、电磁感应、气体定律、几何光学。把分立知识织成守恒量的统一网络。

对应：选必 1/2/3心智：统一
L3

专业 · 工具与方法

大学先修视角：守恒量体系、相图、振动波叠加、相对论入门、量子入门。获得"像物理学者一样思考"的方法。

对应：选必深化 + 先修心智：方法
L4

前沿 · 边界与开放

引力波、量子计算、拓扑物态、暗物质、精密测量。看到高中物理之上是仍向未知敞开的科研疆域。

对应：选修 + 科研前沿心智：边界
