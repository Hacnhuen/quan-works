01LEARN 六步学习循环

L · Look（看现象）

先在实验室或生活中看见现象：抛体轨迹、弹簧振荡、电路分压。不急于公式。

E · Express（建模）

把现象抽象成模型与方程：受力分析、能量图、场线。对应 L1 的"写方程"。

A · Analyze（分析）

用守恒量（动量/能量/电荷）与对称性化简问题。对应 L2/L3 的"统一网络"。

R · Relate（连接）

把新知识挂到图谱节点上：它属于哪域、哪层、与谁相邻。对应首页知识图谱。

N · Negotiate（费曼讲解）

假装讲给高中生听，讲不通处即漏洞。用下方费曼卡模板自查。

↻ · Revisit（间隔重复）

按遗忘曲线回看，逐步拉长间隔。对应下方排程表。

02费曼卡模板

一张好卡的标准

  • 概念：用一句话说清它是什么（如"动量是质量乘速度"）。
  • 为何：它从哪条更基本的原理来（如"动量守恒来自空间平移对称"）。
  • 图式：画一个能唤起直觉的图像（v–t 图面积=位移）。
  • 反例：什么情况下不成立（如"F=ma 在 v≈c 时不精确"）。

03五类可视化图式

运动图

x–t / v–t / a–t 三类图像，面积与斜率的物理意义。

受力图

隔离体 + 矢量合成，是动力学解题第一步。

场线图

电场线/磁感线疏密表强弱、方向表作用。

能流图

势能↔动能↔内能的转换箭头。

相图

p–T 坐标下固液气三相与相变线。

04三条深广化螺旋

深 · 从现象到原理 直觉 → 方程 → 守恒律 → 对称性（诺特定理）→ 公理化。每螺旋一圈都更深一层。
广 · 跨域连接 力学-能量 ↔ 电磁-场 ↔ 热-统计 ↔ 光-波 ↔ 原子-量子。找共同结构（守恒、叠加、对称）。
前沿 · 走向未知 从高中物理出发：相对论（L3）→ 引力波/量子计算（L4）。螺旋不闭合，通向科研。

05假设拆解法

面对难题：列出隐藏假设

例："为什么羽毛落得慢？"——隐藏假设是"有空气"。拆掉它（真空管）结论翻转。物理进步常来自质疑默认假设：绝对时间（相对论）、能量连续（量子）、空间平直（宇宙学）。

06间隔重复排程

公式 · 遗忘曲线近似
R = e^(−t/S) R 记忆保持率，S 稳定性，t 间隔 复习间隔建议：1d → 3d → 7d → 16d → 35d（每次回忆成功 S×2.5）

07反模式清单

✗ 背公式不画图

没有图式支撑的记忆 3 天就忘。先画受力/运动图。

✗ 套题型不析守恒

死记"这是什么模型"不如先问"什么守恒"。

✗ 忽视单位与量级

算完不估量级（g≈10、c≈3×10⁸）极易错十倍。

✗ 跳过实验直接算

没在实验室看过现象，公式只是符号。先看 lab.html。
