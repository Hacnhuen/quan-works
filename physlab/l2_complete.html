L2·1动量守恒

公式 · 动量
p = m·v 系统合外力为零：Σp_初 = Σp_末 （动量守恒）
定理 · 动量定理 合外力冲量等于动量变化：I = FΔt = Δp。碰撞、反冲、火箭均由其分析。
示例 · 一维弹性碰撞 等质量两球对心弹性碰撞交换速度；非弹性碰撞有动能损失但动量仍守恒。

L2·2机械能守恒

定理 · 机械能守恒 只有重力或弹力做功时，系统动能与势能之和不变：E_k1+E_p1 = E_k2+E_p2。
证明 · 由动能定理 由 W_G = −ΔE_p 与动能定理 W_G = ΔE_k，相加得 ΔE_k + ΔE_p = 0，即机械能不变。
推论 · 竖直上抛 最高点 v=0，由 ½mv₀² = mgh 得 h = v₀²/(2g)。

L2·3磁场

公式 · 磁场力
安培力：F = BIL·sinθ 洛伦兹力：f = qvB·sinθ （方向：左手定则） 圆周运动半径：r = mv/(qB)
概念 · 磁感线 磁感线闭合、无源无汇（不像电场线起讫于电荷）。电流产生磁场方向由安培定则判定。
示例 · 质谱仪 带电粒子垂直入匀强磁场做匀速圆周运动，r=mv/qB，可分离不同比荷的粒子。

L2·4电磁感应

定理 · 法拉第电磁感应 回路磁通量变化产生感应电动势：ε = −dΦ/dt，Φ = BS cosθ。负号表楞次定律（阻碍变化）。
公式 · 动生电动势
导体棒切割磁感线：ε = BLv （B⊥v） 互感/自感：ε = −L·dI/dt
前沿 · 连接 电磁感应是发电机、变压器、无线充电的物理基础；也是现代电力社会的根基。

L2·5气体定律

公式 · 理想气体
pV = nRT = Nk_B T R ≈ 8.314 J/(mol·K)，k_B ≈ 1.381×10⁻²³ J/K 玻意耳：pV=const（T 定）；查理：p∝T（V 定）
推论 · 标况体积 1 mol 气体在 STP（0℃, 1 atm）体积 V = RT/p ≈ 22.4 L。

L2·6热力学定律

定理 · 热力学第一定律 ΔU = Q + W（对系统做功 W，吸热 Q）。能量守恒在热现象中的表述。
概念 · 第二定律 热量不能自发从低温传到高温（克劳修斯表述）；宏观过程有方向性（熵增）。

L2·7几何光学

公式 · 反射与折射
反射：θ_i = θ_r 折射（斯涅尔）：n₁sinθ₁ = n₂sinθ₂ 透镜：1/f = 1/u + 1/v 全反射临界角：sinC = 1/n （光密→光疏）
示例 · 视深 水中物体视深 d' = d/n，n 为水折射率（≈1.33）。

L2·8原子结构

概念 · 核式结构 卢瑟福 α 散射实验表明：原子中心有微小带正电的核，电子绕核运动。玻尔模型给出定态轨道。
公式 · 玻尔模型
轨道半径：rₙ = n²·a₀ ，a₀ ≈ 0.529 Å（玻尔半径） 能级：Eₙ = −13.6 / n² eV （基态 E₁ = −13.6 eV）
示例 · 氢原子发光 从 n=3 跃迁到 n=2 放出光子能量 ΔE = E₃−E₂ = −1.51−(−3.40) = 1.89 eV，对应巴耳末系红光。
