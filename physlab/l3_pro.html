L3·1守恒量：物理的第一性原理

概念 · 框架 物理学者解题先问："什么守恒？"——动量、角动量、能量、电荷。对称性（诺特定理）与守恒律一一对应：时间平移对称 ⇒ 能量守恒；空间平移对称 ⇒ 动量守恒。
推论 · 解题策略 遇到复杂过程，优先列守恒方程而非逐段动力学，往往一键化简。

L3·2振动与简谐运动

公式 · 简谐运动
x = A·cos(ωt + φ) 弹簧振子：ω = √(k/m)，T = 2π√(m/k) 单摆（小角）：T = 2π√(L/g) 能量：E = ½kA² = ½mω²A²
定理 · 简谐判据 回复力与位移成正比反向（F = −kx）即简谐运动，其解为正弦/余弦。

L3·3波动光学

公式 · 干涉与衍射
双缝干涉明纹：d·sinθ = kλ (k=0,±1,±2…) 薄膜干涉：2nd = kλ （相长） 单缝衍射暗纹：a·sinθ = kλ (k=±1,±2…)
概念 · 波粒二象性 光既表现波动性（干涉衍射）又表现粒子性（光电效应）。这是连接 L2 原子与 L4 量子的桥梁。
示例 · 双缝 波长 λ=600 nm、缝距 d=0.2 mm，中央明纹到一级明纹角 θ≈λ/d=3×10⁻³ rad。

L3·4相图：物态的全景

概念 · 相图 以压强—温度为坐标，划分固/液/气三相与相变曲线。熔点线、沸点线、三相点、临界点构成物质的"地图"。
公式 · 克拉珀龙
dp/dT = L / (T·ΔV) L 相变潜热
示例 · 水的反常 冰熔点随压强增大而降低（水密度大于冰），这与多数物质相反。

L3·5相对论入门

公式 · 狭义相对论
洛伦兹因子：γ = 1/√(1 − v²/c²) 时间膨胀：Δt = γ·Δt₀ 长度收缩：L = L₀/γ 质能方程：E = mc²
定理 · 光速不变 所有惯性系中真空光速 c 相同。由此推出同时的相对性与上述效应。
推论 · 速度极限 当 v→c，γ→∞，所需能量发散，故任何物质速度无法达到 c。

L3·6量子入门

公式 · 量子关系
光子能量：E = hν = hc/λ 光子动量：p = h/λ 爱因斯坦光电效应：hν = W + ½mv²_max
概念 · 离散与概率 微观量取离散值（量子化）；粒子状态由波函数描述，其模方给出概率分布。
前沿 · 连接 量子力学是 L4 量子计算、拓扑物态的理论地基。
