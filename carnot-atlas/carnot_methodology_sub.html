01

家族一 · 可逆循环分析

Family 1 · Reversible Cycle Analysis

卡诺循环由四个可逆过程组成：等温膨胀（Th 吸热 Qh）→ 绝热膨胀（Th→Tc）→ 等温压缩（Tc 放热 |Qc|）→ 绝热压缩（回到 Th），工质循环一周恢复初态（ΔU=0）。 效率 η = 1 − Tc/Th 仅由两热源绝对温度决定， 与工质无关（卡诺定理）。本家族 6 种方法（①–④⑫⑭）分别负责：算上限、画 T-S、画 p-V、证无关、数值复证定理与矩形面积。

①

卡诺效率计算器

m01_carnot_efficiency.py 家族 1 · 可逆循环分析 · 效率上限
定位

任何热机分析的第一步：给定两热源绝对温度，直接给出效率天花板与废热下限。内置绝对温标强制校验，拒绝摄氏温标误用。

核心公式
η = 1 − Tc/Th = (Th − Tc)/Th = W_net/Qh （仅对开尔文绝对温标成立）
数值示例
Th = 600 K，Tc = 300 K → η = 1 − 300/600 = 50.0%；
100℃ / 0℃ → η ≈ 1 − 273.15/373.15 = 26.8% ≈ 27%，至少 73% 吸热以废热排出——不是工程不够好，是物理不允许。
适用边界
  • 仅适用于可逆循环上限；真实机必低于此。
  • 热源需近似为无限大恒温热库（有限热容热库需用积分口径）。
  • 同界限逆卡诺 COP 一并给出（衔接方法 ⑩）。
常见错误
  • 把摄氏温标直接代入公式（100℃/0℃ 会得到荒谬的 100%）。
  • 把卡诺效率当成实际效率——它只是标尺。

T-S 图绘制（matplotlib）

      m02_carnot_ts.py
      家族 1 · 可逆循环分析 · 循环可视化
    

    

      

        
定位

        
可逆卡诺循环在 T-S 图上就是一个矩形：两条等温水平线 + 两条等熵竖直线。矩形面积 = 净功 W = (Th−Tc)·ΔS——一张图讲完整个循环，是热力学课堂的「费曼图」级工具。

        
核心公式

        
W_net = (Th − Tc)·ΔS；Qh = Th·ΔS；|Qc| = Tc·ΔS

        
η = 矩形面积 / 上边长 = (Th − Tc)/Th

        
数值示例

        
Th = 600 K，Tc = 300 K，ΔS = 1.0 kJ/K → W_net = 300 kJ，Qh = 600 kJ，η = 300/600 = 50%。

        
适用边界

        
    
          
  • T-S 矩形仅对可逆循环成立；不可逆循环 T-S 图不再是矩形。
    • 
          
  • 对真实循环（Rankine/Brayton），T-S 图用于展示平均吸热温度与卡诺的差距。
    • 
        

        
常见错误

        
    
          
  • 把矩形直接套到不可逆循环上（主报告 §3.6 存疑点 ④）。
    • 
          
  • ΔS 符号约定：本脚本采用工程约定 W = ∮P dV 正号（物理课本 w = −∫PdV，跨教材对照需留意）。

      ③
      
p-V 图绘制

      m03_carnot_pv.py
      家族 1 · 可逆循环分析 · 循环可视化
    

    

      

        
定位

        
Clapeyron（1834）正是用 p-V 图把卡诺的「热质输运」论证变成可计算的几何图形；Kelvin 也是通过 Clapeyron 论文才首次了解卡诺理论。净功 W_net = ∮p dV 即闭合曲线围成的面积。

        
核心公式

        
等温：pV = const；绝热：pV^γ = const；W_net = ∮p dV = nR(Th−Tc)·ln(V₂/V₁)

        
推导关键：V₃/V₄ = V₂/V₁（绝热体积比）→ 消去体积项得 η = (Th−Tc)/Th

        
数值示例

        
n = 1 mol 单原子气体，Th = 600 K，Tc = 300 K，体积比 3：W_net = 1×8.314×300×ln 3 ≈ 2.74 kJ；Qh = 1×8.314×600×ln 3 ≈ 5.48 kJ；η = 2.74/5.48 = 50%。

        
适用边界

        
    
          
  • p-V 图适合展示功与几何；T-S 图更适合展示热与效率（见方法 ②）。
    • 
          
  • 真实循环（Rankine 等压加热、Brayton 等压燃烧）在 p-V 图上的形状差异是范式对比的基础。
    • 
        

        
常见错误

        
    
          
  • 绝热线与等温线画反（绝热线更陡：斜率 −γp/V vs −p/V）。
    • 
          
  • 忘记绝热过程 TV^(γ−1) = const 而非 pV^γ = const 的等价形式。
    •

      ④
      
任意工质效率验证（理想气体 vs Redlich-Kwong）

      m04_any_working_fluid.py
      家族 1 · 可逆循环分析 · 工质无关性
    

    

      

        
定位

        
卡诺定理最难接受的推论：效率与工质无关。本方法用两种状态方程（理想气体、Redlich-Kwong 真实气体）分别构造可逆卡诺循环，数值验证效率一致——这正是 arXiv:physics/0601173 证明的「Carnot efficiency independent of equation of state」。

        
核心公式

        
Maxwell 关系：(∂S/∂V)_T = (∂p/∂T)_V → ΔS = ∫(∂p/∂T)_V dV

        
RK：p = RT/(Vm−b) − a/(√T·Vm·(Vm+b))；η = 1 − Tc/Th 与状态方程无关

        
数值示例

        
Th = 600 K，Tc = 300 K，V 从 1e-3 → 3e-3 m³：理想气体 ΔS = 9.13 J/K → η = 50.00%；RK 气体 ΔS ≈ 8.95 J/K（分子间作用修正）→ η = 50.00%。ΔS 不同，效率相同。

        
适用边界

        
    
          
  • 证明类任务：回应「卡诺循环必须用理想气体吗」的常见误解（主报告 §6.3 误解 2）。
    • 
          
  • 真实气体工质（CO2 超临界循环）设计前的理论底线校验。
    • 
        

        
弱点

        
    
          
  • RK 常数选择影响 ΔS 数值但不影响效率（这正是要演示的点）。
    • 
          
  • 未覆盖非平衡/相干工质——「超越卡诺」宣称全部依赖此类附加资源（主报告 §5.5 裁决）。
    •

      ⑫
      
卡诺定理数值验证（多工质对比）

      m12_carnot_theorem_multi.py
      家族 1 · 可逆循环分析 · 定理检验
    

    

      

        
定位

        
卡诺定理最硬的检验：不止理想气体——对 van der Waals 与 Redlich-Kwong 真实气体也逐一构造可逆卡诺循环，三种状态方程给出的效率必须完全相同。这是「工质无关性」的多方程数值证明（主报告 §3.3、arXiv:physics/0601173）。

        
核心公式

        
Maxwell 关系：ΔS = ∫(∂p/∂T)_V dV（等温熵变，状态方程是唯一入口）

        
三状态方程：p=RT/Vm；p=RT/(Vm−b)−a/Vm²；RK 两项式 → 同一 η = 1−Tc/Th

        
数值示例

        
Th=600K/Tc=300K：理想气体 ΔS=9.134 J/K、van der Waals ≈ 8.87 J/K、RK ≈ 8.95 J/K——ΔS 各不相同，效率却都是 50.00%。

        
适用边界

        
    
          
  • 定理教学验证：回应「卡诺循环必须用理想气体」的顽固误解（主报告 §6.3 误解 2）。
    • 
          
  • 新工质、新状态方程接入时的理论底线校验。
    • 
        

        
弱点

        
    
          
  • 需要状态方程的解析导数 (∂p/∂T)_V；纯数值 EOS 需差分近似。
    • 
          
  • 未覆盖非平衡/相干工质——「超越卡诺」宣称依赖的正是此类附加资源。
    •

熵是态函数：ΔS = ∫δQ_rev/T，与路径无关、只由初末态决定。可逆卡诺循环后工质 ΔS = 0，宇宙总熵不变——这是教学实证中只有不到 30% 的学生能正确推到的结论（Smith 2015, PRSTPER）。

        
核心公式

        
等温：ΔS = Q_rev/T；等压：n·Cp·ln(T₂/T₁)；等容：n·Cv·ln(T₂/T₁)

        
任意路径：ΔS = n·Cv·ln(T₂/T₁) + n·R·ln(V₂/V₁)

        
数值示例

        
1 mol 单原子气体等压 300→600 K：ΔS = 1×2.5R×ln 2 = 14.41 J/K；可逆卡诺循环（Th=600K/Tc=300K，ΔS=1 kJ/K）宇宙熵变 = 0 − 600×1/600 + 300×1/300 = 0 J/K。

        
适用边界

        
    
          
  • 过程熵变：化学反应、换热器、透平膨胀的熵产核算。
    • 
          
  • 宇宙熵变口径是「优于卡诺」类宣称的判据：ΔS_universe < 0 即违反第二定律。
    • 
        

        
弱点

        
    
          
  • 只覆盖可逆计算路径；不可逆过程需结合熵平衡与熵产（方法 ⑥⑧）。
    • 
          
  • 符号约定：物理书 w = −∫PdV 与工程书 W = ∫PdV 相反，跨教材对照需留意（主报告 §3.6）。

克劳修斯不等式验证

      m06_clausius_inequality.py
      家族 2 · 熵与火用 · 第二定律判定
    

    

      

        
定位

        
第二定律的解析判据：任意循环 ∮δQ/T ≤ 0，等号仅对可逆循环成立。它把所有「循环设计」问题变成一次数值求和——也是检测「永动机」类宣称的第一道筛子。

        
核心公式

        
克劳修斯等式：∮δQ_rev/T = 0；不等式：∮δQ/T ≤ 0（任意循环）

        
宇宙熵变：ΔS_universe = 0（可逆）/ > 0（不可逆）

        
数值示例

        
Th=600K/Tc=300K，Qh=1000 J：可逆时 |Qc| = 500 J → ∮δQ/T = 1000/600 − 500/300 = 0；不可逆时 |Qc| = 520 J → ∮δQ/T = −0.0667 J/K < 0（多排热 20 J = 少做的功）。

        
适用边界

        
    
          
  • 任何声称「效率 > 卡诺」的方案：代入其吸放热序列，若 ∮δQ/T > 0 即违反第二定律。
    • 
          
  • 与 Shannon 信息论类比：Landauer 原理「擦除 1 bit ≥ kT·ln2」是信息版克劳修斯不等式（主报告 §2.4/§5.3）。
    • 
        

        
弱点

        
    
          
  • 需要完整的吸放热-温度序列；只有效率数字无法直接验证。
    • 
          
  • 对周期驱动/非平衡系统，δQ/T 需按广义口径重定义（主报告 §5.5 争议链）。
    •

      ⑨
      
Curzon-Ahlborn 最大功率效率

      m09_curzon_ahlborn.py
      家族 3 · 有限时间与量子 · 最优运行点
    

    

      

        
定位

        
真实热机要输出功率就必须有有限温差传热（不可逆）。CA 1975 的「内可逆」模型求最大功率点：η_CA = 1 − √(Tc/Th)。三条必须澄清：它是最大功率工况下的效率、不是上限、恒低于卡诺效率（主报告 §5.1）。

        
核心公式

        
η_CA = 1 − √(Tc/Th)；P_max = σ·(√Th − √Tc)²/2（对称热导 σ）

        
线性响应统一理论：η = η_C²/(2 − η_C)（Esposito 2009, PRL 102, 130602）

        
数值示例

        
Th=600K/Tc=300K：η_CA = 1 − √(300/600) = 29.3%（卡诺 50%，缺口 20.7 个百分点）；σ=1 W/K 时 P_max = 25.7 W。

        
适用边界

        
    
          
  • 发电机组与热泵的「设计工况」选定：效率与功率的权衡决策。
    • 
          
  • 布朗卡诺机实验（Martínez 2016）效率接近 CA 理论——实验验证。
    • 
        

        
弱点

        
    
          
  • 依赖线性响应 + 对称耦合假设；Apertet 2016 论证其并非本质普适量。
    • 
          
  • 常被误引为「卡诺效率被推翻」——必须强调运行点 vs 上限的区别。
    •

逆卡诺 COP（制冷 / 热泵）

      m10_inverse_carnot_cop.py
      家族 3 · 有限时间与量子 · 逆循环
    

    

      

        
定位

        
同一可逆循环逆向运行即制冷机/热泵——这是可逆性的直接推论，也是卡诺定理反证法的基础（主报告 §6.3 误解 5）。COP 的卡诺值给出「省电天花板」：真实冰箱 COP 1.5–3 已很接近上限，而空调 EER≈3 离卡诺 37 差得远。

        
核心公式

        
COP_R = Tc/(Th−Tc)；COP_HP = Th/(Th−Tc)；COP_HP = COP_R + 1

        
数值示例

        
冰箱 -18℃/25℃：卡诺 COP = 255/43 ≈ 5.9（实际 1.5–3）；空调 27℃/35℃：卡诺 COP = 300.15/8 ≈ 37（实际 EER≈3，仅 8%）；热泵 0℃→35℃：卡诺 COP = 308.15/35 ≈ 8.8（实际 SCOP 2.5–4）。

        
适用边界

        
    
          
  • 冰箱/空调/热泵的能效审计与「理论上限」对照。
    • 
          
  • SCOP 口径（EN 14825 季节性）与单工况 COP 的换算衔接。
    • 
        

        
弱点

        
    
          
  • 卡诺 COP 随温差急剧上升（27℃/35℃ 达 37），实际装置永远够不到——温差大时差距被放大，是逆卡诺循环对 COP 的硬约束。
    • 
          
  • 热泵温度是变工况（供水温度、环境温度），需季节性能效而非单点。
    •

      m11_two_level_quantum.py

  • 单循环准静态近似；真实量子热机有相干/耗散修正（Geva-Kosloff 1992 主方程）。

8 步 SVG 决策树：如何选择分析方法

    8-Step Decision Tree
  

  

    选择顺序遵循主报告的方法论主线：效率上限 → 温标 → 熵 → 火用 → 最大功率 → 量子。
    菱形 = 判定节点，矩形 = 方法步骤；青字为方法编号，可回跳上方对应方法卡。
    多数分析任务走到第 3 步即可收尾；只有涉及损失定量、功率优化或微观尺度时才需要继续深潜。
  

  

    
  

  

    
第 1 步 · 目标判定（菱形）
四类任务分支：效率上限 / 功率 / 损失 / 制冷或量子。一次只回答一个问题，避免混合口径；目标决定要走多深——多数报告到第 3 步即可收尾。

    
第 2 步 · 温标校验（菱形）
绝对温标是 η=1−Tc/Th 成立的隐含前提，摄氏/华氏输入必须先换算为开尔文。方法 ① 内置的 ValueError 拦截就是这一步的自动化。

    
第 3 步 · 效率上限
方法 ① 一步给出 η_C、废热占比与逆卡诺 COP；若需证明「与工质无关」，用方法 ④（理想气体 vs RK）或方法 ⑫（三状态方程对照）收尾。

    
第 4 步 · 循环可视化
T-S 图（方法 ②）看热与效率、p-V 图（方法 ③）看功与几何；方法 ⑭ 可数值验证「矩形面积 = 净功」，把几何直觉变成可复现的数字。

    
第 5 步 · 熵方法
方法 ⑤ 算过程熵变、方法 ⑥ 验克劳修斯不等式——这是第二定律的门禁：任何「优于卡诺」的宣称必须先在 ∮δQ/T ≤ 0 这关倒下。

    
第 6 步 · 火用方法
方法 ⑦ 给出达卡诺比例 η/η_Carnot（工程标尺），方法 ⑧ 把熵产按环境温度 T0 计价，逐环节定位火用毁——锅炉总是最大头。

    
第 7 步 · 最大功率
方法 ⑨ 求 η_CA 与 P_max，并输出效率-功率权衡曲线。注意：η_CA 是运行点而非上限——追求功率必然牺牲效率（Shiraishi 2016）。

    
第 8 步 · 制冷与量子
方法 ⑩ 与 ⑬ 处理逆循环 COP 及温差敏感性（ΔT 翻倍 COP 断崖）；方法 ⑪ 验证量子尺度卡诺界依然成立——「超越卡诺」皆依赖附加资源。

  

  

    决策逻辑示例：「评估某 1000 MW 超超临界机组距卡诺还有多远」→ 第 1 步目标=效率上限+损失；
    第 2 步锅炉 565℃/凝汽器 33℃ 换算开尔文；第 3 步得卡诺 η≈63.5%，实测 46% → 达卡诺比例 ≈ 72%；
    第 6 步火用审计定位锅炉为最大火用损环节 → 改造优先级：先锅炉再透平。

方法论红线（常见错误与反自欺检查）

    Methodological Red Lines
  

  

    主报告 §6.3 八大误解与本馆 14 种方法直接相关；费曼视角的反自欺原则（主报告 §7.4）
    要求我们主动声明边界。以下 8 条红线，每一条都在本馆某段代码中被强制拦截或显式标注。
  

  

    

      
⚠ 红线 1 · 摄氏温标直接代入

      
η=1−Tc/Th 仅对开尔文绝对温标成立。100℃/0℃ 直接代入得 100% 的荒谬结果——方法 ① 内置 ValueError 强制拦截。

    

    

      
⚠ 红线 2 · 卡诺效率 = 实际效率

      
卡诺效率是可逆机上限；真实机因不可逆性必低于此（主报告 §6.3 误解 1）。「达卡诺比例」才是工程进步的正确度量。

    

    

      
⚠ 红线 3 · 卡诺循环必须用理想气体

      
效率只依赖 Tc/Th，与工质无关——方法 ④ 用 Redlich-Kwong 真实气体数值验证（理想气体仅为计算方便）。

    

    

      
⚠ 红线 4 · T-S 矩形套用不可逆循环

      
T-S 图矩形仅对可逆循环成立（主报告 §3.6 存疑点 ④）。不可逆循环的 T-S 图不再是矩形，面积关系失效。

    

    

      
⚠ 红线 5 · η_CA 被误读为「推翻卡诺」

      
Curzon-Ahlborn 效率是最大功率运行点，不是上限，恒低于卡诺效率（主报告 §5.1 三条澄清）。「CA 推翻卡诺」是典型标题党。

    

    

      
⚠ 红线 6 · 「超越卡诺」宣称未查资源基准

      
压缩库、手征导体等全部依赖非平衡/相干/信息附加资源，不违反第二定律（主报告 §5.5 裁决）。引用时必须说明基准。

    

    

      
⚠ 红线 7 · 厂商口径当实测

      
62.22% 为吉尼斯实测（2016）；63% 为 Keadby 2 设计值；64% 为 9HA.02 厂商宣称（未独立证实）。三级口径不可混用。

    

    

      
⚠ 红线 8 · 符号约定混用

      
物理书 w=−∫PdV 与工程书 W=∫PdV 符号相反（主报告 §3.6 存疑点 ②）。跨教材对照时先统一约定。

常见问题 FAQ（方法学问答）

    Frequently Asked Questions
  

  

    精选 14 条方法学问答，覆盖「公式怎么用、代码怎么改、宣称怎么裁决」三层。

#问题答案（要点）对应方法/章节

      
        
Q1为什么摄氏温标不能直接代入效率公式？η=1−Tc/Th 是温度比，只有绝对温标（开尔文）的比值才有物理意义；摄氏零点是人为约定。100℃/0℃ 代入会得到 100% 的假上限。方法 ①；报告 §3.6

        
Q2卡诺效率是「实际能达到」的效率吗？不是。它是可逆机上限；真实机因摩擦、有限温差传热等不可逆性必低于此。度量进步的正确指标是达卡诺比例 η/η_Carnot。方法 ①；报告 §4.1

        
Q3必须用理想气体才能算卡诺效率吗？不需要。方法 ④ 用 Redlich-Kwong 真实气体得到同样的 50.00%——效率只由 Tc/Th 决定，选理想气体仅为计算方便。方法 ④；报告 §6.3

        
Q4T-S 图上的矩形什么时候不成立？循环不可逆时失效：有限温差传热使等温线不再水平、绝热过程不再等熵。矩形是「可逆卡诺循环」的专属几何。方法 ②；报告 §3.6

        
Q5η_CA = 1−√(Tc/Th) 是不是推翻了卡诺？没有。η_CA 是最大功率运行点的效率，恒低于卡诺效率；卡诺效率对应零功率极限。两者回答不同问题。方法 ⑨；报告 §5.1

        
Q6「超越卡诺」的量子宣称可信吗？所有已复现的宣称（压缩库、手征导体等）都依赖非平衡/相干/信息等附加资源，不违反第二定律；对平衡可逆循环，卡诺定理依然是上限。方法 ⑪；报告 §5.5

        
Q7冰箱 COP 5.9 与空调 COP 37 差这么多？COP_R=Tc/(Th−Tc)：冰箱温差 43K → 5.9；空调温差仅 8K → 37。温差越小「天花板」越高，但实际装置越难逼近（空调 EER≈3 只有 8%）。方法 ⑩；报告 §4.6

        
Q8锅炉为什么是电站最大火用损环节？燃烧（化学能→热能强不可逆）+ 燃气 1500K 到蒸汽 600K 的大温差传热，两处熵产按 T0 计价即为最大火用毁——先于透平与冷凝器。方法 ⑦⑧；报告 §4.2

        
Q962.22% 到底是谁的口径？62.22% 为 GE 9HA.01 在法国 Bouchain 的吉尼斯实测（2016）；63% 为 Keadby 2 设计值；64% 为 9HA.02 厂商宣称（未独立证实）。引用必须分级。方法 ⑦；报告 §4.3

        
Q10「宇宙熵增」能当判据用吗？能。任何方案算得 ΔS_universe < 0 即违反第二定律（方法 ⑤ 内置计算）；「优于卡诺」的引擎必然导致宇宙熵减，物理上不可能。方法 ⑤⑥；报告 §6.3

        
Q11火用效率 75% 和卡诺效率 83% 什么关系？η_ex = η/η_Carnot：联合循环 62.22%/83% ≈ 75%——意思是距离同界限卡诺理想还差约 25% 的做功能力，差距主因是材料限制透平初温。方法 ⑦；报告 §4.7

        
Q12效率与功率为什么不可兼得？卡诺效率需要无限缓慢（零功率）；有限功率必须付出效率代价。Shiraishi 2016 严格证明一般稳态热机中效率→卡诺时功率必然受限。方法 ⑨⑪；报告 §5.4

        
Q13Stirling 机真的能达到卡诺效率吗？理想 Stirling（等温吸放热 + 理想回热器）理论上等于同界限卡诺；实际因回热器压降、温差传热显著低于——「理论等于、实际低于」是常见误读点。方法 ①；报告 §4.5

        
Q14为什么教学里学生总认为可以超过卡诺？实证：只有不到 20% 的学生认识到「优于卡诺」意味着违反第二定律（Smith 2015）。方法 ⑤⑥ 把第二定律变成可算的数字，是破题工具。方法 ⑤⑥；报告 §6.2

12量子模型是否声明准静态近似方法 ⑪涨落与相干修正未含，结论限于平均量

数值手工复算示例（3 例，可与代码对照）

    Hand Calculation Walkthroughs
  

  

    三个关键数字（50%、29.3%、5.9）用手算完整推一遍，与对应代码输出逐位对照。
    目的是示范「先手算、后跑码」的验证习惯——这也是费曼「演示 > 论证」原则的落地。
  

  

    

      
H1
例 1：卡诺效率 50% 的完整手算（方法 ①）

      
Th = 600 K，Tc = 300 K，理想气体工质，可逆循环

      

        ① 等温膨胀吸热：Qh = nR·Th·ln(V₂/V₁) = 1×8.314×600×ln 3 = 5480 J

        ② 绝热膨胀：TV^(γ−1) = 常数 → V₃/V₄ = V₂/V₁（推导关键）

        ③ 等温压缩放热：|Qc| = nR·Tc·ln(V₂/V₁) = 1×8.314×300×ln 3 = 2740 J

        ④ η = (Qh − |Qc|)/Qh = (5480 − 2740)/5480 = 0.5000 = 50.0% ✓
      

    

    

      
H2
例 2：Curzon-Ahlborn 29.3% 的手算（方法 ⑨）

      
同界限 600/300 K，内可逆模型

      

        ① 温度比开方：√(Tc/Th) = √(300/600) = √0.5 = 0.7071

        ② η_CA = 1 − 0.7071 = 0.2929 ≈ 29.3% ✓

        ③ 对比卡诺 50% → 最大功率运行点牺牲了约 20.7 个百分点的效率

        ④ P_max = σ(√Th − √Tc)²/2 = 1×(24.495 − 17.321)²/2 ≈ 25.7 W ✓
      

    

    

      
H3
例 3：冰箱卡诺 COP 5.9 的手算（方法 ⑩）

      
冷端 −18℃ = 255 K，环境 25℃ = 298 K

      

        ① 温差：Th − Tc = 298 − 255 = 43 K

        ② COP_R = Tc/(Th−Tc) = 255/43 = 5.93 ≈ 5.9 ✓

        ③ 热泵模式：COP_HP = Th/(Th−Tc) = 298/43 = 6.93 = COP_R + 1 ✓

        ④ 实际冰箱 1.5–3 → 达卡诺比例 ≈ 25–50%：剩余差距来自有限温差传热与压缩损失
      

    

  

  

    三个例子覆盖了本馆三大家族的标志性数字。建议练习：把 H1–H3 的输入换成
    你自己的工况（如地源热泵 5℃→45℃），先手算再跑对应代码，数字一致即掌握了方法。
