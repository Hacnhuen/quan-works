01 · Three Families

三大家族本质差异

A 传统统计

OLS / PSM / IV / RDD。假设无混杂/强可忽略。强项：理论严谨可解释。死穴：高维失效。

B 现代机器学习

CRF / 深度因果 / CRL。数据驱动+表征学习。强项：高维非线性 CATE。死穴：可解释性差。

C 因果图

DAG / SEM / 因果发现 / 中介。结构已知或可学。强项：识别+反事实+干预。死穴：图错则全错。

+ DML 双重机器学习

Neyman 正交 + 交叉拟合，既高维又保理论。本项目形式化引擎对应 C 家族的 DAG/SEM 路径，并在识别层给出最小调整集。

# ⑥ 结构方程模型（SEM，C 家族反事实）
import numpy as np
def sem_sample(n=20000, seed=0):
    rng = np.random.default_rng(seed)
    Z = rng.normal(0,1,n); T = rng.normal(2*Z,1,n); Y = 0.5*T + 2*Z + 0.3*rng.normal(0,1,n)
    return T, Y
T, Y = sem_sample()

SEM + 因果发现

家族协作范式

C 家族定结构

先用 DAG/因果发现确定因果方向，这是后续一切识别的前提。

A/D 家族估效应

结构既定后，用 OLS/PSM/DML 在识别出的调整集上估计 ATE 或 CATE。

B 家族上高维

当变量维度爆炸且结构已知，用深度因果/CRL 捕捉非线性异质效应。

CausalGuard 形式化引擎落在"定结构+识别"这一环，补上 A/D/B 家族缺的可计算因果图基础。
