01 · Ladder

因果阶梯三层 · 数值验证

因果层级定理（Bareinboim et al., 2022）严格证明：低层级数据无法唯一确定高层级量。本项目的 SCM 引擎可在三者之间精确切换并给出数值。

RUNG 1 · 关联

Seeing

P(y | x)

仅观察共现。LLM 训练目标即此层：log P(xₜ|x<ₜ)。

RUNG 2 · 干预

Doing

P(y | do(x))

强制设定 X。do-演算找到调整集后数值估计。

RUNG 3 · 反事实

Imagining

P(yₓ | x',y')

若当时做了别的，会怎样。需 SCM + 噪声反演。

经典后门图：Z→T, Z→Y, T→Y。Z 为混杂变量，必须调整。

from causalguard import CausalGraph, StructuralCausalModel

g = CausalGraph.from_edges([("Z","T"),("Z","Y"),("T","Y")])
scm = StructuralCausalModel(graph=g, mechanisms={
    "Z": lambda pa,u: 1.0 if u>0 else 0.0,
    "T": lambda pa,u: 1.0 if (2.0*pa["Z"]+u)>0.8 else 0.0,
    "Y": lambda pa,u: 0.5*pa["T"]+2.0*pa["Z"]+0.3*u,
})
print(scm.ate("T","Y"))                       # Rung2 → 0.500
print(scm.counterfactual({"T":0.,"Y":0.},     # Rung3 → 0.496
                         {"T":1.}, "Y"))
scm.py · 三层查询出口

真因果效应 +0.500；LLM/朴素关联会给出 +1.865（放大 3.7 倍）；后门调整自动恢复 +0.507（误差 1.4%）。

02 · do-Calculus

do-演算自动识别

给定因果图与目标变量，引擎自动寻找最小充分调整集并输出可识别的 estimand。正确处理全部经典陷阱：对撞不调整、中介不调整、处理后代不调整、M-bias 空集、前门准则、bow-arc 不可识别。

from causalguard import identify_effect

r = identify_effect(g, "T", "Y")
r.strategy        # 'backdoor'
r.adjustment_set  # ['Z']  ← 自动找到最小充分调整集
r.estimand        # 'P(Y|do(T)) = Σ_{Z} P(Y|T,Z)·P(Z)'

# 前门准则示例（中介 M，无未观测混杂）
# Z 不可观测时仍能识别： P(Y|do(X)) = Σ_M P(M|X) Σ_X' P(X') P(Y|X',M)
core/scm.py · identify_effect

后门准则

阻断所有指向处理的"后门"混杂路径，保留因果链。

前门准则

当混杂不可观测，但存在完全中介 M 且无未观测混杂时仍可识别。

边界与不可识别

bow-arc、M-bias 空集、对撞开放等情形返回不可识别并解释原因。

SCM 数值验证 · 三层一致性

下方为可复现的数值验证：在同一结构上分别取关联（Rung1）、干预（Rung2）、反事实（Rung3），三者逐步逼近真实因果效应 +0.500。

import numpy as np
from causalguard import CausalGraph, StructuralCausalModel

g = CausalGraph.from_edges([("Z","T"),("Z","Y"),("T","Y")])
scm = StructuralCausalModel(graph=g, mechanisms={
    "Z": lambda pa,u: 1.0 if u>0 else 0.0,
    "T": lambda pa,u: 1.0 if (2.0*pa["Z"]+u)>0.8 else 0.0,
    "Y": lambda pa,u: 0.5*pa["T"]+2.0*pa["Z"]+0.3*u,
})
df = scm.sample(n=20000)
# Rung1 关联（朴素）：混淆了 Z → 偏高
naive = df[df.T==1].Y.mean() - df[df.T==0].Y.mean()
# Rung2 干预：后门调整 Z
ate   = scm.ate("T","Y")
# Rung3 反事实：给定 T=0,Y=0 个体在 T=1 下的 Y
cf    = scm.counterfactual({"T":0.,"Y":0.}, {"T":1.}, "Y")
print(f"naive(关联)   = {naive:.3f}   ← 被混杂放大")
print(f"ATE(干预)     = {ate:.3f}     ← 真效应 +0.500")
print(f"counterfactual = {cf:.3f}      ← Rung3 个人化")
scm.py · 三层数值验证

Rung1 关联失真

朴素差分同时捕获 Z→T 与 Z→Y 的混杂路径，数值被系统性抬高。

Rung2 干预恢复

阻断后门后 ATE 收敛到真值 +0.500，误差 <2%。

Rung3 反事实

在个体噪声上反演，给出"若当时做了别的"的个人化估计。

重要边界：本系统检测的是因果表述的合规性，不是因果结论的真伪。它能指出"你没有证据支持这个断言"，但不能告诉你"这个因果关系是否真实存在"。

08 · Limitations

局限与诚实边界

漏检风险

谬误检测基于语言模式，存在漏检；接真实 LLM 后 S5 抽取质量显著提升。

评测集规模

自建且规模小，B2/B3 不足以声称泛化能力。

识别覆盖

仅后门 + 前门，未实现完整 ID 算法（Shpitser & Pearl 2006）。

反事实效率

反事实用拒绝采样，高维证据下接受率低。
