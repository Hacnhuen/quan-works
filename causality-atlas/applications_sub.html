01 · Source Anatomy

CausalGuard 源码逐文件剖析

core/scm.py
DAG 构建、d-分离检验、后门/前门识别、SCM 三层查询（关联/干预/反事实）。形式化可信锚点。
core/fallacies.py
12 类因果谬误检测（F01–F12）+ 因果阶梯分级（Rung1→Rung2 越级等）。
core/graph_extract.py
文本 → 因果 DAG（规则 + LLM 抽取）。把自然语言变成可计算图。
llm/client.py
零依赖 OpenAI 兼容客户端，端点不可用时自动降级离线模式。
llm/prompts.py
CausalCoT / CausalPoT 思维链 + 降级重写提示词。
pipeline.py
七阶段守护管线总调度：S1 PROMPT_AUDIT → S7 REPAIR。
adapters.py
装饰器 / drop-in / HTTP 网关三种接入方式。
cli.py + demo.py
命令行与五个离线演示，无需任何 LLM 即可运行。
# 七阶段守护管线（语义层 + 形式化层分工）
S1 PROMPT_AUDIT  → 审计输入提示词
S2 CAUSAL_PROMPT → 注入因果约束
S3 GENERATE      → 生成回复
S4 CLAIM_AUDIT   → 抽取因果主张
S5 GRAPH_BUILD   → LLM 构建 DAG（擅长语义）
S6 IDENTIFY      → do-演算识别（形式化，不依赖 LLM，可信锚点）
S7 REPAIR        → 反事实修复 / 重写

03 · Integration

三种接入方式

① 装饰器

from causalguard.adapters import causal_guarded
from causalguard import Policy

@causal_guarded(policy=Policy.ANNOTATE)
def ask(q: str) -> str:
    return my_llm(q)
adapters.py

② OpenAI drop-in

from causalguard.adapters import GuardedChat
chat = GuardedChat(policy=Policy.REWRITE)
resp = chat.create(model="gpt-4", messages=[{"role":"user","content":"..."}])
resp["causalguard"]   # {'verdict':'high_risk','risk_score':0.8,'fallacies':['F01','F02']}
chat.stats()          # {'turns':2,'avg_risk':0.66,'fallacy_histogram':{'F02':2,'F01':1}}
adapters.py

③ HTTP 网关

python3 -c "from causalguard.adapters import serve; serve(port=8899)"
# POST /v1/chat/completions  OpenAI 兼容
# POST /v1/causal/audit      纯审计 {"text":"..."}
# GET  /v1/causal/stats      会话因果健康度
# 处置：annotate / rewrite / block / off
adapters.py

离线降级

端点不可用时自动降级为离线模式，审计/识别/SCM 全部功能不受影响。接真实 LLM 只需设 CAUSALGUARD_LLM_BASE 等环境变量（LM Studio / Ollama / vLLM 皆可）。

04 · Boundaries

能力边界（诚实声明）

漏检风险

谬误检测基于语言模式，存在漏检；接真实 LLM 后 S5 抽取质量显著提升。

评测集规模

自建且规模小，B2/B3 不足以声称泛化能力。

识别覆盖

仅后门 + 前门，未实现完整 ID 算法（Shpitser & Pearl 2006）。

反事实效率

反事实用拒绝采样，高维证据下接受率低。

最重要的一条

本系统检测的是因果表述的合规性，不是因果结论的真伪。它能指出"你没有证据支持这个断言"，但不能告诉你"这个因果关系是否真实存在"。
