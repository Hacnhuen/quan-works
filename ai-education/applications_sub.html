CASE 01

业务背景

  • 面向初中数学课后练习，学生量大、知识点细碎，教师难以一对一诊断。
  • 目标：实时估计每个学生对每个知识点的掌握概率，并推荐"最近发展区"题目。
  • 对标 Squirrel AI、Khan Academy 的个性化练习路径。

数据流

学生作答日志 → 预处理去重 → pyBKT 拟合四参数 → 预测掌握概率 → 薄弱点识别 → 难度匹配推荐 → 回写学习记录。

输入：(student_id, skill_id, correct, timestamp)
输出：推荐题目列表 + 掌握度画像

k12_personalized.py · pyBKT 知识追踪 + 自适应推荐
# -*- coding: utf-8 -*-
"""
K12 个性化辅导：pyBKT 知识追踪 + 自适应推荐
- BKT 四参数: knows(初始掌握) / slip(失误) / guess(瞎猜) / learn(学会) / forget(遗忘)
- 推荐: 薄弱点 + 最近发展区(目标答对率约0.55) + 前置知识约束
数据格式: student_id, skill_id, correct(0/1), timestamp
依赖: pip install pyBKT numpy pandas scikit-learn
"""
import numpy as np
import pandas as pd
from pyBKT.models import Model
from sklearn.metrics import roc_auc_score, accuracy_score

# ---------- 1. 数据加载与预处理 ----------
def load_interactions(path):
    df = pd.read_csv(path)
    df = df[['student_id', 'skill_id', 'correct', 'timestamp']].dropna()
    df = df.drop_duplicates(subset=['student_id', 'skill_id', 'timestamp'])
    df = df.sort_values(['student_id', 'timestamp']).reset_index(drop=True)
    df['correct'] = df['correct'].astype(int)
    # 过滤作答次数过少的学生(<5)以免拟合不稳定
    cnt = df.groupby('student_id').size()
    df = df[df['student_id'].isin(cnt[cnt >= 5].index)]
    return df

# ---------- 2. pyBKT 模型训练 ----------
def train_bkt(df):
    model = Model(seed=42, num_fits=6, parallel=True)
    # 对每个 skill 独立拟合 BKT 参数
    model.fit(data=df, skills='skill_id', multicls=False)
    return model

# ---------- 3. 掌握概率预测 ----------
def predict_mastery(model, df):
    preds = model.predict(data=df)
    # correct_pred 表示"在当前掌握状态下答对"的概率
    return preds[['student_id', 'skill_id', 'correct_pred']]

# ---------- 4. 评测指标 ----------
def evaluate(preds, df):
    y_true = df['correct'].values
    y_score = preds['correct_pred'].values
    auc = roc_auc_score(y_true, y_score)
    acc = accuracy_score(y_true, (y_score > 0.5).astype(int))
    print(f"[BKT] AUC={auc:.4f}  Accuracy={acc:.4f}")
    return auc

# ---------- 5. 自适应推荐引擎 ----------
class Recommender:
    """基于掌握度 + 最近发展区 + 前置关系的推荐器"""
    def __init__(self, mastery_df, item_bank, prereq_map,
                 mastery_thr=0.85, target_rate=0.55):
        self.mastery = mastery_df.set_index(['student_id', 'skill_id'])
        self.items = item_bank                 # item_id, skill_id, difficulty(IRT b)
        self.prereq = prereq_map               # skill -> [前置skill]
        self.thr = mastery_thr
        self.target = target_rate

    def weak_skills(self, sid):
        sub = self.mastery.loc[sid]
        return sub[sub['correct_pred'] < self.thr].index.tolist()

    def _ready(self, sid, skill):
        """前置知识是否都已掌握"""
        for p in self.prereq.get(skill, []):
            if (sid, p) not in self.mastery.index:
                return False
            if self.mastery.loc[(sid, p), 'correct_pred'] < self.thr:
                return False
        return True

    def recommend(self, sid, top_k=5):
        weak = self.weak_skills(sid)
        if not weak:
            # 全部掌握 → 推荐进阶题
            pool = self.items[self.items['difficulty'] > self.target]
        else:
            # 优先推荐前置已就绪的薄弱点
            ready = [s for s in weak if self._ready(sid, s)]
            target_skills = ready or weak
            pool = self.items[self.items['skill_id'].isin(target_skills)]
        # 最近发展区: 选答对概率接近 target 的题目
        pool = pool.copy()
        pool['gap'] = (pool['difficulty'] - self.target).abs()
        pick = pool.sort_values('gap').head(top_k)
        return pick[['item_id', 'skill_id', 'difficulty']].to_dict('records')

# ---------- 6. 主流程 ----------
if __name__ == '__main__':
    df = load_interactions('assistments.csv')
    print(f"交互记录: {len(df)} 条, 学生: {df['student_id'].nunique()} 人")
    model = train_bkt(df)
    preds = predict_mastery(model, df)
    evaluate(preds, df)
    # 题库与前置关系(示例)
    item_bank = pd.DataFrame({
        'item_id': np.arange(2000),
        'skill_id': np.random.choice(df['skill_id'].unique(), 2000),
        'difficulty': np.random.uniform(0.2, 0.9, 2000),
    })
    prereq = {'分数加减': ['整数加减'], '一元二次方程': ['因式分解']}
    rec = Recommender(preds, item_bank, prereq)
    sid = df['student_id'].iloc[0]
    print('薄弱知识点:', rec.weak_skills(sid))
    print('推荐题目:', rec.recommend(sid))

# -*- coding: utf-8 -*-
"""
高校 AI 助教 RAG 系统 (Harvard CS50 风格)
- 文档切块 + 向量检索 + LLM 生成, 回答必带课件引用
- 引导式 prompt: 不直接给完整代码答案, 而是给思路与最小示例
依赖: pip install langchain faiss-cpu sentence-transformers
       外部 LLM 可接 OpenAI / 本地 vLLM
"""
import os
import hashlib
from typing import List, Dict
import numpy as np
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_community.embeddings import HuggingFaceEmbeddings
from langchain_community.vectorstores import FAISS
from langchain.schema import Document
from langchain.prompts import ChatPromptTemplate
from langchain.chat_models import ChatOpenAI
from langchain.chains import LLMChain

# ---------- 1. 文档加载与切块 ----------
def load_and_split(doc_dir: str) -> List[Document]:
    docs = []
    for fn in sorted(os.listdir(doc_dir)):
        if not fn.endswith(('.md', '.txt')):
            continue
        with open(os.path.join(doc_dir, fn), encoding='utf-8') as f:
            text = f.read()
        docs.append(Document(page_content=text,
                             metadata={'source': fn, 'fid': hashlib.md5(fn.encode()).hexdigest()[:8]}))
    splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=80,
                                              separators=['\n## ', '\n### ', '\n\n', '\n', ' '])
    return splitter.split_documents(docs)

# ---------- 2. 向量索引构建 ----------
def build_index(chunks: List[Document], persist='faiss_idx'):
    embed = HuggingFaceEmbeddings(model_name='BAAI/bge-small-zh-v1.5')
    vs = FAISS.from_documents(chunks, embed)
    vs.save_local(persist)
    return vs

def load_index(persist='faiss_idx'):
    embed = HuggingFaceEmbeddings(model_name='BAAI/bge-small-zh-v1.5')
    return FAISS.load_local(persist, embed, allow_dangerous_deserialization=True)

# ---------- 3. 引导式 Prompt ----------
GUIDE_PROMPT = """你是 CS50 风格的编程助教, 必须遵守:
1. 不要直接给出完整作业代码, 只给思路、伪代码或最小示例。
2. 回答末尾必须列出引用的课件段落, 格式: [来源:文件#chunk]
3. 若检索内容不足以回答, 明确说"课件中未覆盖, 建议查阅 X"。

课件片段:
{context}

学生问题: {question}
助教回答:"""

# ---------- 4. RAG 问答 ----------
class RAGTA:
    def __init__(self, vs, llm=None, k=4, score_thr=0.35):
        self.vs = vs
        self.llm = llm or ChatOpenAI(model='gpt-4o-mini', temperature=0.2)
        self.k = k
        self.thr = score_thr
        self.chain = LLMChain(llm=self.llm,
                              prompt=ChatPromptTemplate.from_template(GUIDE_PROMPT))

    def retrieve(self, query: str) -> List[Dict]:
        docs_sim = self.vs.similarity_search_with_score(query, k=self.k)
        kept = []
        for doc, score in docs_sim:
            if score < self.thr * 10:   # FAISS L2 距离越小越相似
                kept.append({
                    'text': doc.page_content,
                    'source': doc.metadata['source'],
                    'fid': doc.metadata['fid'],
                    'score': float(score)
                })
        return kept

    def answer(self, query: str) -> Dict:
        ctx = self.retrieve(query)
        if not ctx:
            return {'answer': '课件中未覆盖该问题, 建议查阅教材或问授课教师。',
                    'refs': [], 'confidence': 0.0}
        context_text = '\n---\n'.join(
            [f"[来源:{c['source']}#{c['fid']}] {c['text']}" for c in ctx])
        resp = self.chain.run(context=context_text, question=query)
        conf = 1.0 / (1.0 + np.mean([c['score'] for c in ctx]))
        return {'answer': resp, 'refs': ctx, 'confidence': round(conf, 3)}

# ---------- 5. 主流程 ----------
if __name__ == '__main__':
    doc_dir = './course_docs'
    if not os.path.exists('faiss_idx'):
        chunks = load_and_split(doc_dir)
        print(f"切块数: {len(chunks)}")
        vs = build_index(chunks)
    else:
        vs = load_index()
    ta = RAGTA(vs)
    q = "我的 for 循环为什么越界了?"
    r = ta.answer(q)
    print('置信度:', r['confidence'])
    print('回答:', r['answer'][:300])
    print('引用数:', len(r['refs']))

vocational_skill_path.py · networkx 技能图谱与路径规划
# -*- coding: utf-8 -*-
"""
职教技能训练: 技能图谱(DAG) + 拓扑排序路径规划
- 用 networkx 构建技能依赖图, 检测环, 拓扑排序
- 根据学生已掌握技能剪枝, 输出个性化学习路径与关键路径
依赖: pip install networkx
"""
import networkx as nx
from collections import deque

# ---------- 1. 技能图谱定义 ----------
SKILLS = {
    'S1':  {'name': '安全规范',     'hours': 4,  'level': 'base'},
    'S2':  {'name': '识图基础',     'hours': 6,  'level': 'base'},
    'S3':  {'name': '量具使用',     'hours': 8,  'level': 'base'},
    'S4':  {'name': '手工刃磨',     'hours': 12, 'level': 'mid'},
    'S5':  {'name': '车床操作',     'hours': 20, 'level': 'mid'},
    'S6':  {'name': '数控编程',     'hours': 24, 'level': 'adv'},
    'S7':  {'name': 'CAM 软件',     'hours': 16, 'level': 'adv'},
    'S8':  {'name': '综合零件加工', 'hours': 30, 'level': 'adv'},
}
EDGES = [  # (前置, 后继)
    ('S1', 'S3'), ('S1', 'S4'), ('S1', 'S5'),
    ('S2', 'S5'), ('S2', 'S6'),
    ('S3', 'S4'), ('S3', 'S5'),
    ('S4', 'S5'), ('S5', 'S6'), ('S5', 'S8'),
    ('S6', 'S7'), ('S6', 'S8'), ('S7', 'S8'),
]

# ---------- 2. 构建 DAG 并校验 ----------
def build_dag(skills, edges):
    g = nx.DiGraph()
    for sid, info in skills.items():
        g.add_node(sid, **info)
    for u, v in edges:
        g.add_edge(u, v)
    if not nx.is_directed_acyclic_graph(g):
        cycles = list(nx.simple_cycles(g))
        raise ValueError(f'技能图谱存在环: {cycles[:3]}')
    return g

# ---------- 3. 拓扑排序(考虑学时优先) ----------
def topo_with_priority(g):
    """在拓扑序约束下, 优先输出学时短的技能(更快解锁后续)"""
    in_deg = dict(g.in_degree())
    queue = deque(sorted([n for n in g if in_deg[n] == 0],
                         key=lambda n: g.nodes[n]['hours']))
    order, visited = [], set()
    while queue:
        n = queue.popleft()
        if n in visited:
            continue
        visited.add(n)
        order.append(n)
        for s in sorted(g.successors(n), key=lambda x: g.nodes[x]['hours']):
            in_deg[s] -= 1
            if in_deg[s] == 0:
                queue.append(s)
    return order

# ---------- 4. 个性化路径(剪枝已掌握) ----------
def personalized_path(g, mastered):
    """返回还需学习的有序路径, 跳过已掌握节点但保留其解锁作用"""
    full = topo_with_priority(g)
    # 一个技能可学, 当且仅当其所有前置已掌握或已学
    learned = set(mastered)
    path = []
    for sid in full:
        if sid in learned:
            continue
        prereqs = list(g.predecessors(sid))
        if all(p in learned for p in prereqs):
            path.append(sid)
            learned.add(sid)   # 假设按序学完即解锁
    return path

# ---------- 5. 关键路径(最长学时链) ----------
def critical_path(g):
    """DAG 最长路径 = 关键技能链"""
    topo = list(nx.topological_sort(g))
    dist, prev = {}, {}
    for n in topo:
        dist[n] = g.nodes[n]['hours']
        prev[n] = None
    for n in topo:
        for s in g.successors(n):
            if dist[n] + g.nodes[s]['hours'] > dist.get(s, 0):
                dist[s] = dist[n] + g.nodes[s]['hours']
                prev[s] = n
    end = max(dist, key=dist.get)
    chain = []
    cur = end
    while cur is not None:
        chain.append(cur)
        cur = prev[cur]
    chain.reverse()
    return chain, dist[end]

# ---------- 6. 主流程 ----------
if __name__ == '__main__':
    g = build_dag(SKILLS, EDGES)
    print('节点:', g.number_of_nodes(), '边:', g.number_of_edges())
    cp, total = critical_path(g)
    print('关键路径:', ' -> '.join(cp), f' 总学时={total}')
    mastered = {'S1', 'S2', 'S3'}
    path = personalized_path(g, mastered)
    print('个性化路径:')
    for sid in path:
        info = SKILLS[sid]
        print(f'  {sid} {info["name"]} ({info["hours"]}h, {info["level"]})')
    print('剩余总学时:', sum(SKILLS[s]['hours'] for s in path))

# -*- coding: utf-8 -*-
"""
企业培训学习路径优化: 上下文 Bandit (LinUCB)
- 臂 = 候选课程, 上下文 = 员工特征, 奖励 = 完课率(0~1) + 测验分加权
- LinUCB 在线性奖励假设下平衡探索/利用, 适合冷启动与持续学习
依赖: pip install numpy
"""
import numpy as np

# ---------- 1. 候选课程与上下文定义 ----------
COURSES = ['C1入职导览', 'C2安全合规', 'C3产品知识', 'C4销售话术',
           'C5技术基础', 'C6沟通协作', 'C7数据分析', 'C8项目管理']
D_CONTEXT = 6   # 上下文维度: 岗位onehot3 + 工龄 + 自评基础 + 入职批次

def make_context(role_idx, tenure, self_level, cohort):
    """构造归一化上下文向量"""
    onehot = np.zeros(3)
    onehot[role_idx % 3] = 1.0
    ctx = np.concatenate([onehot, [tenure / 5.0, self_level / 5.0, cohort / 10.0]])
    return ctx

# ---------- 2. LinUCB 算法 ----------
class LinUCB:
    def __init__(self, n_arms, d, alpha=1.5):
        self.K = n_arms
        self.d = d
        self.alpha = alpha
        # 每臂维护 A( d×d ) 与 b( d×1 )
        self.A = [np.eye(d) for _ in range(n_arms)]
        self.b = [np.zeros((d, 1)) for _ in range(n_arms)]
        self.counts = np.zeros(n_arms)

    def select(self, ctx):
        ctx = ctx.reshape(-1, 1)
        best_p, best_a, explore = -1e9, 0, False
        for a in range(self.K):
            A_inv = np.linalg.inv(self.A[a])
            theta = A_inv @ self.b[a]
            mean = float(theta.T @ ctx)
            bonus = self.alpha * np.sqrt(float(ctx.T @ A_inv @ ctx))
            p = mean + bonus
            if p > best_p:
                best_p, best_a = p, a
                explore = bonus > 0.5   # 置信区间宽 = 在探索
        return best_a, explore

    def update(self, a, ctx, reward):
        ctx = ctx.reshape(-1, 1)
        self.A[a] += ctx @ ctx.T
        self.b[a] += reward * ctx
        self.counts[a] += 1

# ---------- 3. 奖励函数(模拟) ----------
def simulate_reward(ctx, course_idx):
    """真实场景从 LMS 取完课率+测验分; 此处用线性+噪声模拟"""
    true_theta = np.array([0.1, 0.05, 0.08, 0.12, 0.20, 0.10])
    base = float(true_theta @ ctx.flatten())
    course_bias = 0.15 * np.sin(course_idx)
    return float(np.clip(base + course_bias + np.random.normal(0, 0.05), 0, 1))

# ---------- 4. 训练与评估 ----------
def train(n_steps=3000):
    bandit = LinUCB(len(COURSES), D_CONTEXT, alpha=1.5)
    rewards, chosen = [], np.zeros(len(COURSES))
    for t in range(n_steps):
        ctx = make_context(np.random.randint(3), np.random.uniform(0, 5),
                           np.random.uniform(1, 5), np.random.randint(0, 10))
        a, explore = bandit.select(ctx)
        r = simulate_reward(ctx, a)
        bandit.update(a, ctx, r)
        rewards.append(r)
        chosen[a] += 1
    return bandit, rewards, chosen

# ---------- 5. 在线推荐接口 ----------
class PathRecommender:
    def __init__(self, bandit):
        self.b = bandit

    def next_course(self, ctx, mode='exploit'):
        a, explore = self.b.select(ctx)
        if mode == 'exploit' and explore:
            # 线上服务时可关闭强制探索, 只取均值最优
            ctx = ctx.reshape(-1, 1)
            means = []
            for k in range(self.b.K):
                th = np.linalg.inv(self.b.A[k]) @ self.b.b[k]
                means.append(float(th.T @ ctx))
            a = int(np.argmax(means))
        return COURSES[a], a

# ---------- 6. 主流程 ----------
if __name__ == '__main__':

    ctx = make_context(role_idx=1, tenure=2, self_level=3, cohort=3)
    print('推荐下一课:', rec.next_course(ctx, mode='exploit'))

import numpy as np
import cv2

from sklearn.metrics import classification_report

# ---------- 1. 人脸表情特征 ----------
class FaceFeature:
    def __init__(self, cascade_path=None):
        self.detector = cv2.CascadeClassifier(
            cascade_path or cv2.data.haarcascades + 'haarcascade_frontalface_default.xml')

    def extract(self, frame_bgr):
        gray = cv2.cvtColor(frame_bgr, cv2.COLOR_BGR2GRAY)
        faces = self.detector.detectMultiScale(gray, 1.3, 5)
        if len(faces) == 0:
            return np.zeros(48)
        x, y, w, h = max(faces, key=lambda f: f[2] * f[3])
        face = gray[y:y + h, x:x + w]
        face = cv2.resize(face, (48, 48))
        # HOG 简化特征 (8x8 cell 直方图)
        gx = cv2.Sobel(face, cv2.CV_32F, 1, 0)
        gy = cv2.Sobel(face, cv2.CV_32F, 0, 1)
        mag = np.sqrt(gx ** 2 + gy ** 2)
        ang = np.arctan2(gy, gx) * 180 / np.pi
        feat = []
        for i in range(0, 48, 8):
            for j in range(0, 48, 8):
                block = mag[i:i + 8, j:j + 8]
                a = ang[i:i + 8, j:j + 8]
                hist, _ = np.histogram(a, bins=8, weights=block, range=(-180, 180))
                feat.append(hist.mean())
        return np.array(feat)

# ---------- 2. 语音情感特征 ----------
def voice_extract(y, sr):
    """从音频波形提取声学特征"""
    mfcc = librosa.feature.mfcc(y=y, sr=sr, n_mfcc=13)
    pitch, _ = librosa.piptrack(y=y, sr=sr)
    pitch_mean = float(pitch[pitch > 0].mean()) if np.any(pitch > 0) else 0.0
    energy = float(np.mean(librosa.feature.rms(y=y)))
    # 取 MFCC 均值+方差拼接
    feat = np.concatenate([mfcc.mean(axis=1), mfcc.std(axis=1), [pitch_mean, energy]])
    return feat

# ---------- 3. 多模态融合分类 ----------
class MultimodalEmotion:
    def __init__(self):
        self.scaler = StandardScaler()
        self.clf = MLPClassifier(hidden_layer_sizes=(128, 64), max_iter=400,
                                 random_state=42, early_stopping=True)
        self.face = FaceFeature()

    def _fuse(self, face_feat, voice_feat):
        return np.concatenate([face_feat, voice_feat])

    def fit(self, pairs, labels):
        """pairs: list of (frame_bgr, (y, sr))"""
        X, y = [], []
        for frame, (audio, sr) in pairs:
            ff = self.face.extract(frame)
            vf = voice_extract(audio, sr)
            X.append(self._fuse(ff, vf))
            y.append(labels)
        X = self.scaler.fit_transform(X)
        self.clf.fit(X, y)
        return self

    def predict(self, frame_bgr, audio, sr):
        ff = self.face.extract(frame_bgr)
        vf = voice_extract(audio, sr)
        x = self.scaler.transform([self._fuse(ff, vf)])
        proba = self.clf.predict_proba(x)[0]
        idx = int(np.argmax(proba))
        return EMOTIONS[idx], float(proba[idx])

# -*- coding: utf-8 -*-
"""
语言学习: SM-2 间隔重复 + 2PL IRT 难度自适应
- SM-2: SuperMemo 经典算法, 按作答质量 q(0~5) 更新间隔与易度因子 EF
- IRT: 2参数模型 P(θ)=1/(1+exp(-1.7a(θ-b))), 选题使 P≈0.6 (最近发展区)
依赖: pip install numpy
"""
import numpy as np
from datetime import datetime, timedelta

# ---------- 1. SM-2 间隔重复 ----------
class SM2Card:
    def __init__(self, card_id, ef=2.5):
        self.id = card_id
        self.ef = ef          # 易度因子
        self.i = 0            # 重复轮次
        self.interval = 0     # 下次间隔(天)
        self.due = datetime.now()
        self.last_q = 3

    def review(self, q):
        """q: 0~5 作答质量, <3 视为忘记, 重新开始轮次"""
        self.last_q = q
        if q < 3:
            self.i = 0
            self.interval = 1
        else:
            self.i += 1
            if self.i == 1:
                self.interval = 1
            elif self.i == 2:
                self.interval = 6
            else:
                self.interval = round(self.interval * self.ef)
            # 更新 EF, 下限 1.3
            self.ef = max(1.3, self.ef + (0.1 - (5 - q) * (0.08 + (5 - q) * 0.02)))
        self.due = datetime.now() + timedelta(days=self.interval)
        return self.interval

# ---------- 2. IRT 能力估计与选题 ----------
def irt_prob(theta, a, b):
    """2PL 模型答对概率"""
    return 1.0 / (1.0 + np.exp(-1.7 * a * (theta - b)))

def update_theta(theta, a, b, correct, lr=0.5):
    """用梯度上升更新能力 θ"""
    p = irt_prob(theta, a, b)
    grad = 1.7 * a * (correct - p)
    return theta + lr * grad

def select_item(theta, item_bank, target_p=0.6):
    """选题使答对概率最接近目标(最近发展区)"""
    probs = irt_prob(theta, item_bank['a'], item_bank['b'])
    idx = int(np.argmin(np.abs(probs - target_p)))
    return idx, float(probs[idx])

# ---------- 3. 学习调度器 ----------
class LanguageScheduler:
    def __init__(self, item_bank):
        self.bank = item_bank            # DataFrame: id, a(区分度), b(难度), word
        self.cards = {}                  # card_id -> SM2Card
        self.theta = 0.0                 # 学生能力

    def _card(self, cid):
        if cid not in self.cards:
            self.cards[cid] = SM2Card(cid)
        return self.cards[cid]

    def due_today(self):
        now = datetime.now()
        return [c.id for c in self.cards.values() if c.due <= now]

    def step(self, cid, correct):
        # 1) IRT 更新能力
        row = self.bank[self.bank['id'] == cid].iloc[0]
        self.theta = update_theta(self.theta, row['a'], row['b'], int(correct))
        # 2) SM-2 安排复习 (correct→q=5, wrong→q=2)
        self._card(cid).review(5 if correct else 2)
        # 3) 选下一题
        idx, p = select_item(self.theta, self.bank)
        nxt = self.bank.iloc[idx]
        return {'next_id': int(nxt['id']), 'word': nxt['word'],
                'p_correct': round(p, 3), 'theta': round(self.theta, 3)}

# -*- coding: utf-8 -*-
"""
STEM 代码自动评估
- AST 结构检查: 是否定义了要求的函数/循环/异常处理
- 自动生成测试用例: 基于类型注解随机生成输入
- 沙箱执行 + 评分: 正确性60 + 结构30 + 风格10
依赖: 仅标准库 ast / inspect / unittest
"""
import ast
import inspect
import unittest
import random
import textwrap
from typing import get_type_hints

# ---------- 1. AST 结构检查 ----------
class StructureChecker(ast.NodeVisitor):
    def __init__(self, required_funcs):
        self.required = required_funcs
        self.found = set()
        self.has_loop = False
        self.has_try = False

    def visit_FunctionDef(self, node):
        self.found.add(node.name)
        self.generic_visit(node)

    def visit_For(self, node):
        self.has_loop = True
        self.generic_visit(node)

    def visit_While(self, node):
        self.has_loop = True
        self.generic_visit(node)

    def visit_Try(self, node):
        self.has_try = True
        self.generic_visit(node)

def check_structure(code, required_funcs, need_loop=True, need_try=True):
    tree = ast.parse(code)
    ck = StructureChecker(required_funcs)
    ck.visit(tree)
    issues = []
    missing = set(required_funcs) - ck.found
    if missing:
        issues.append(f'缺少函数: {missing}')
    if need_loop and not ck.has_loop:
        issues.append('未使用循环结构')
    if need_try and not ck.has_try:
        issues.append('未使用异常处理')
    return issues, ck

# ---------- 2. 基于类型注解自动生成测试用例 ----------
GEN = {
    int: lambda: random.choice([0, 1, -1, 10, 100, -5]),
    float: lambda: random.choice([0.0, 1.5, -2.3, 3.14]),
    str: lambda: random.choice(['', 'abc', 'hello', '123']),
    bool: lambda: random.choice([True, False]),
    list: lambda: random.choice([[], [1, 2, 3], ['a', 'b']]),
}

def gen_cases(func, n=8):
    hints = get_type_hints(func)
    sig = inspect.signature(func)
    params = [p for p in sig.parameters if p != 'return']
    cases = []
    for _ in range(n):
        args = []
        for p in params:
            t = hints.get(p, int)
            gen = GEN.get(t, lambda: random.randint(0, 100))
            args.append(gen())
        cases.append(tuple(args))
    return cases

# ---------- 3. 沙箱执行 ----------
def run_in_sandbox(code, func_name, cases, timeout=2):
    ns = {}
    try:
        exec(compile(code, '', 'exec'), ns)
    except Exception as e:
        return [], [f'编译失败: {e}']
    func = ns.get(func_name)
    if func is None:
        return [], [f'未找到函数 {func_name}']
    results, errors = [], []
    for c in cases:
        try:
            out = func(*c)
            results.append((c, out))
        except Exception as e:
            errors.append(f'输入{c}异常: {type(e).__name__}: {e}')
            results.append((c, None))
    return results, errors

# ---------- 4. 评分 ----------
def grade(code, spec):
    code = textwrap.dedent(code)
    issues, _ = check_structure(code, spec['funcs'], spec.get('loop', True), spec.get('try', True))
    ns = {}
    exec(code, ns)
    func = ns[spec['funcs'][0]]
    cases = gen_cases(func, n=10)
    results, errors = run_in_sandbox(code, spec['funcs'][0], cases)
    # 正确性: 与参考实现对比
    ref = spec['reference']

# -*- coding: utf-8 -*-
"""
教师课堂行为分析
- 特征: 各行为占比 + 关键行为转换率
- 聚类: KMeans 识别教学风格(讲授主导/互动主导/巡视辅导)
- 序列模式: 挖掘高频行为片段(如 提问→学生答→反馈)
依赖: pip install scikit-learn numpy
       prefixspan 可选, 下面手写简化实现 GSP
"""
import numpy as np
from collections import Counter, defaultdict
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

BEHAVIORS = ['L', 'Q', 'R', 'P', 'F']   # 讲授/提问/学生答/巡视/反馈

# ---------- 1. 特征工程 ----------
def extract_features(seq):
    """从行为序列提取特征向量"""
    n = max(len(seq), 1)
    cnt = Counter(seq)
    feat = [cnt[b] / n for b in BEHAVIORS]   # 5 个占比
    # 关键转换率: Q→R, R→F, L→Q
    trans = defaultdict(int)
    for a, b in zip(seq, seq[1:]):
        trans[(a, b)] += 1
    feat.append(trans[('Q', 'R')] / max(cnt['Q'], 1))   # 提问后学生答比例
    feat.append(trans[('R', 'F')] / max(cnt['R'], 1))   # 学生答后反馈比例
    feat.append(trans[('L', 'Q')] / max(cnt['L'], 1))   # 讲授转提问比例
    return np.array(feat)

# ---------- 2. 风格聚类 ----------
def cluster_styles(seqs, k=3):
    X = np.array([extract_features(s) for s in seqs])
    Xs = StandardScaler().fit_transform(X)
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    labels = km.fit_predict(Xs)
    centers = km.cluster_centers_
    return labels, centers, X

STYLE_NAMES = {
    0: '讲授主导型',
    1: '互动反馈型',
    2: '巡视辅导型',
}

def name_cluster(center, feat_means):
    """根据质心特征给簇命名"""
    if center[0] > feat_means[0] * 1.2:
        return '讲授主导型'
    if center[1] > feat_means[1] * 1.2 and center[6] > 0.5:
        return '互动反馈型'
    return '巡视辅导型'

# ---------- 3. 序列模式挖掘(简化 GSP) ----------
def find_frequent_patterns(seqs, min_support=0.4, max_len=4):
    """挖掘频繁行为子序列"""
    n = len(seqs)
    # 1-项集
    freq = Counter()
    for s in seqs:
        for b in set(s):
            freq[(b,)] += 1
    patterns = {k: v / n for k, v in freq.items() if v / n >= min_support}
    result = dict(patterns)
    cur = list(patterns.keys())
    for L in range(2, max_len + 1):
        candidates = set()
        for p in cur:
            for b in BEHAVIORS:
                candidates.add(p + (b,))
        new_freq = {}
        for cand in candidates:
            sup = sum(1 for s in seqs if _is_subseq(cand, s)) / n
            if sup >= min_support:
                new_freq[cand] = sup
        if not new_freq:
            break
        result.update(new_freq)
        cur = list(new_freq.keys())
    return result

def _is_subseq(pat, seq):
    it = iter(seq)
    return all(p in it for p in pat)

# ---------- 4. 教研报告 ----------
def report(seqs, k=3):
    labels, centers, X = cluster_styles(seqs, k)
    feat_means = X.mean(axis=0)
    print('=== 教学风格聚类 ===')
    for c in range(k):
        name = name_cluster(centers[c], feat_means)
        cnt = int((labels == c).sum())
        print(f'簇{c} {name}: {cnt} 节课')
    print('\n=== 高频行为模式 (支持度≥0.4) ===')
    pats = find_frequent_patterns(seqs, min_support=0.4, max_len=3)
    for p, s in sorted(pats.items(), key=lambda x: -x[1])[:8]:
        print(f'  {"→".join(p)}  支持度={s:.2f}')
    return labels

06 · PITFALLS FAQ

常见坑与排查

汇总 8 个案例在落地中最常见的故障与排查方向。

Q1 · BKT 拟合后 slip/guess 出现极端值(接近 0 或 1)？ 通常是该知识点作答样本过少或全部答对/答错，建议合并相邻知识点或加先验正则，并在 UI 限制此类点的推荐权重。
Q2 · RAG 助教出现"引用幻觉"，引用了不存在的段落？ 检查检索阈值与 LLM prompt，强制要求引用必须来自检索片段；可加后置校验：从答案中抽取引用标记并比对检索结果集合。
Q3 · 技能图谱拓扑排序后路径过长，学生反馈枯燥？ 引入学时权重与兴趣分支，在拓扑序约束下做关键路径剪枝，允许并行学习多个独立分支而非纯线性。
Q4 · LinUCB 训练奖励曲线不升反降？ 排查奖励函数符号与归一化；α 过大会过度探索、过小则锁死次优臂，建议先在离线日志上 replay 调参。
Q5 · 多模态情感识别在课堂真实光照下掉点严重？ 训练集光照需增广；FER 模型需在特殊教育场景微调；低光照时降权视觉通道、以语音通道为主。
Q6 · SM-2 间隔越来越长，学生却仍频繁忘词？ EF 被高估，检查 q 值映射是否过宽；可引入遗忘曲线校准，用实际回访正确率反向修正 EF。
Q7 · 代码自动评估被学生用"if 测试输入==... "硬编码绕过？ 启用隐藏用例集 + 输入变异；对源码做 AST 反作弊检测(常量比对输入值)；沙箱内禁止读测试文件。
Q8 · 课堂行为聚类结果不稳定，换批数据簇含义就变？ 固定随机种子并用轮廓系数选 k；簇命名用质心特征阈值而非排序；样本量不足时降级为描述统计而非强行聚类。
07 · METRICS CHEATSHEET

教育 AI 评估指标速查表

汇总本馆 8 个案例及主流教育 AI 研究中常用指标，给出含义与典型用途，便于读论文与写实验报告时统一口径。

AUC
ROC 曲线下面积，衡量排序区分能力，知识追踪主指标，>0.75 为良、>0.80 为优。
Accuracy
预测正确率，类别均衡时可用，知识追踪中因答对偏多常需配合 AUC 看。
RMSE
均方根误差，回归类任务(如预测答对概率)常用，越小越好。
MAE
平均绝对误差，对离群点不敏感，辅助 RMSE 判断预测稳定性。
F1
精确率与召回率的调和均值，情感识别、行为分类等不平衡任务主指标。
Precision / Recall
精确率与召回率，作弊检测、流失预测等需分别报告，避免单看准确率失真。
Hit@K
前 K 个推荐中命中ground truth的比例，推荐系统(案例1/4)常用 K=5/10。
NDCG
归一化折损累计增益，衡量推荐排序质量，考虑位置折损。
MRR
第一个命中项的倒数排名，路径推荐、答疑召回常用。
完课率
完成课程的学生占比，企业培训/MOOC 核心业务指标。
留存率 / 流失率
次日/周/月留存与流失，EdTech 平台运营指标，常用生存分析建模。
学习增益
后测减前测的增量，教学干预效果的核心因果指标。
Cohen's d
标准化均差效应量，>0.2 小、>0.5 中、>0.8 大，干预实验显著性补充。
保持率
间隔一段时间后仍能正确作答的比例，语言学习(案例6)主指标。
反应时
单题作答耗时，反映熟练度与题目难度，可用于 SM-2 的 q 值映射。
难度 b (IRT)
2PL/3PL 题目难度参数，与能力 θ 同尺度，b 越大越难。
区分度 a
IRT 区分参数，衡量题目区分高低能力学生的能力，一般 >0.3 可用。
猜测率 / 失误率
BKT/IRT 的 guess/slip 参数，过高说明题目质量差或建模不准。
掌握概率
BKT 估计的学生已掌握某知识点的后验概率，推荐阈值为 0.85。
遗忘率
已掌握转为未掌握的概率，BKT 扩展(含 forget)与保持模型关注。
知识覆盖率
已学/已掌握知识点占应学的比例，进度类指标。
路径长度
个性化学习路径节点数，过短可能跳级、过长可能冗余。
关键路径学时
DAG 最长路径总学时(案例3)，决定最短毕业时间。
干预触发率
触发人工/算法干预的学生比例，过高增加成本、过低可能漏判。
置信度
模型预测的概率峰值，RAG/情感识别中低于阈值须转人工。
引用命中率
RAG 答案引用的段落确实来自检索结果的比例，防引用幻觉。
语义相似度
嵌入余弦相似度，检索召回质量与答案对齐常用。
BLEU / ROUGE
生成文本与参考的 n-gram 重合，自动作文评分、内容生成评估。
代码通过率

14 · PRIVACY & COMPLIANCE

数据隐私与合规要点

教育数据涉及未成年人等敏感群体，落地须遵循最小必要、知情同意、脱敏存储、用途限定原则。

// 隐私保护要点

  • 最小必要仅采集与教学目标直接相关的字段，不囤积冗余行为。
  • 知情同意向学生与家长明示采集范围、用途与期限，取得书面/电子同意。
  • 身份脱敏student_id 一律哈希别名化，禁止明文身份证号入库。
  • 传输加密全链路 HTTPS/TLS，接口签名防重放。
  • 存储隔离原始影像/语音不落盘，仅存特征向量与标签。
  • 访问控制按角色分级授权，教师仅见本班、教研员见聚合视图。
  • 保留期限设定数据生命周期，毕业/离课后自动过期或匿名化。
  • 跨境合规数据境内存储，跨境传输须额外评估。
  • 审计日志所有查询留痕，可追溯谁在何时访问了谁的数据。
  • 差分隐私对外发布统计结果时加噪，防止成员推断。
  • 联邦学习多校联合建模可用 FL，原始数据不出校。
  • 删除权支持家长/学生行使数据删除请求，级联清理缓存与备份。

// 伦理与公平性

  • 算法偏见审计按性别/地域/ socioeconomic 分组评估指标差异。
  • 可解释性推荐与评分须给出可理解的理由，避免黑箱决策。
  • 人工兜底低置信度与高风险决策(如分流)必须转人工。
  • 教师主权教师可覆盖算法推荐，不被系统绑定。
  • 数字鸿沟确保离线/低配设备可用，避免加剧不公平。
  • 过度依赖限制 AI 直接给答案，保留学生思考空间。
  • 责任归属明确 AI 建议的最终决策人与申诉渠道。
  • 用途限定学习数据不得用于商业画像或第三方广告。
  • 持续监测上线后持续监测偏差指标，发现退化及时停用。
  • 利益相关方参与设计阶段纳入教师、家长、学生意见。

// 阶段二 · 试点扩展 (1-3 月)

  • 目标3-5 个班级/学科试点，引入在线服务与教师反馈环。

  • 注意建立模型再训练节奏与回滚机制。

// 阶段三 · 规模化 (3-12 月)

  • 目标全校/多校推广，形成可持续运营机制。
  • 产出多租户平台 + 监控告警 + 合规审计 + 效果研究论文。
  • 门槛效果稳定不退化、通过伦理审查、单位经济模型为正。
  • 注意持续监测偏差，定期与教师/学生复盘。
  • 风险规模放大后长尾问题暴露，须保留人工兜底通道。

21 · ANTIPATTERNS

常见误用与反模式

列举教育 AI 落地中高频出现的错误用法，帮助团队避坑。

  • 数据泄漏用同一学生的未来作答做特征训练，AUC 虚高。
  • 随机切分知识追踪按交互随机切而非按学生/时间，导致泛化虚高。
  • 单次结果只报一次实验数字，不报多种子方差。
  • 基线引用直接抄原文基线数字而非同协议复跑。
  • 指标单点只看 AUC 不看分组公平性。
  • 过度工程原型阶段就上微服务与多租户。
  • 黑箱决策分流/推荐无解释，教师无法干预。
  • 原始数据落盘影像/语音明文存储，违反隐私。
  • 模型不更新上线后从不重训练，分布漂移致退化。
  • 奖励错配把"点击率"当培训奖励，诱导刷课。
  • 硬编码测试评测用例被学生反推，刷分作弊。
  • 强推算法剥夺教师覆盖权，引发抵触。
  • 忽视冷启动新生无历史直接推难题，挫败退出。
  • 解释过度把可直接给答案的题也强行引导，体验差。
  • 样本不足强聚类30 课节强行分 5 簇，簇含义不稳。
  • 沙箱过宽代码评测不限网络，学生代码外传答案。
  • 用途蔓延学习数据被挪用做商业画像。
  • 无退出机制效果差也不敢下线，贻误学生。
