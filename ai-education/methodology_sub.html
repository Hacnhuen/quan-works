01 · OVERVIEW

为什么把教育AI拆成三大家族

AI在教育里的方法论不是铁板一块。有人在做"怎么教"的教学设计研究（Bloom、Gagné 那一脉）， 有人在做"学生怎么学"的学习科学研究（建构主义、同伴教学那一脉），还有人在做"用数据建模学习者"的 计算教育学研究（知识追踪、IRT、EDM 那一脉）。三大家族各有理论根基、各有数据需求、各有局限， 把它们放在一起对照，才能避免"用错方法解错问题"的常见错误。

02 · FAMILY A · 传统教学设计

家族 A · 传统教学设计四法

Bloom 掌握学习法、直接教学法、精熟学习、Gagné 九事件教学设计。它们的共同假设是：教学是可以被显性设计的事件序列，学生达成掌握阈值即可进入下一单元。

METHOD · A1

Bloom 掌握学习法

Bloom's Mastery Learning
FAMILY A
定义

Bloom (1968) 提出：只要给予足够时间与适当反馈矫正，绝大多数学生都能掌握学习内容。核心是把课程拆成小单元，每个单元配诊断测验，未达标的学生进入矫正学习，达标后进入下一单元。

核心公式 / 算法
掌握判据：mean(score_i) ≥ θ 且 cycle ≥ 2
矫正触发：if mean < θ → remediate
达标比例：M = Σ mastered / Σ skills
适用场景
  • K12 基础学科的单元教学
  • 有明确知识点的自适应练习系统
  • 形成性评价主导的课堂
数据需求
  • 每学生每技能的多次答题记录
  • 技能清单与目标映射
  • 掌握阈值 θ（通常 0.75–0.85）
局限
  • 假设学习是离散单元的累加
  • 对元认知和高阶思维难以掌握化
  • 矫正资源消耗大，规模化困难
代表论文
Bloom, B.S. (1968). Learning for Mastery. Evaluation Comment, 1(2). Guskey, T.R. (2007). Closing Achievement Gaps: Revisiting Benjamin S. Bloom's "Learning for Mastery." Journal of Advanced Academics. Block, J.H. (1971). Mastery Learning: Theory and Practice. Holt Rinehart & Winston.

# Bloom 掌握学习法：诊断 → 反馈 → 矫正 → 复测循环
import numpy as np

class BloomMasteryTracker:
    """追踪学生在各技能上的掌握状态，触发矫正学习"""
    def __init__(self, mastery_threshold=0.80, min_cycles=2):
        self.threshold = mastery_threshold
        self.min_cycles = min_cycles
        self.students = {}

    def register(self, student_id, skill_list):
        self.students[student_id] = {
            s: {'scores': [], 'mastered': False, 'cycle': 0}
            for s in skill_list
        }

    def record(self, student_id, skill, score):
        rec = self.students[student_id][skill]
        rec['scores'].append(score)
        rec['cycle'] += 1
        mean = np.mean(rec['scores'])
        if mean >= self.threshold and rec['cycle'] >= self.min_cycles:
            rec['mastered'] = True
        return self.diagnose(student_id, skill)

    def diagnose(self, student_id, skill):
        rec = self.students[student_id][skill]
        mean = np.mean(rec['scores'])
        gap = max(0, self.threshold - mean)
        return {
            'skill': skill, 'mean': round(mean, 3),
            'gap': round(gap, 3), 'mastered': rec['mastered'],
            'cycle': rec['cycle'],
            'action': 'advance' if rec['mastered'] else 'remediate'
        }

    def class_mastery_rate(self):
        all_skills = [s for stu in self.students.values() for s in stu]
        mastered = sum(1 for s in all_skills if s['mastered'])
        return round(mastered / max(len(all_skills), 1), 3)

tracker = BloomMasteryTracker(mastery_threshold=0.80)
tracker.register('S001', ['algebra', 'geometry', 'statistics'])
for skill, score in [('algebra',0.72),('algebra',0.85),('geometry',0.90)]:
    print(tracker.record('S001', skill, score))
print('class mastery:', tracker.class_mastery_rate())
METHOD · A2

直接教学法

Direct Instruction (DI)
FAMILY A
定义

Engelmann 自 1960 年代发展的脚本化、快节奏、显性教学法。教师按脚本发出信号，学生群体齐答，错误率超过阈值即重教。其核心是"无错学习"和"小步快频反馈"。

核心公式 / 算法
正确率：r = n_correct / n_total
保真度：F = Σ correct / Σ (correct+errors)
推进规则：if r ≥ 0.85 → next step
适用场景
  • 语音、识字、计算等基础技能
  • 需要高频反馈的低年级课堂
  • 特殊教育与补救教学
数据需求
  • 脚本步骤与学生响应记录
  • 每步的对错计数
  • 推进阈值（通常 0.85）
局限
  • 脚本僵化，难以处理开放探究
  • 对教师培训成本高
  • 易被批评为机械训练
代表论文
Engelmann, S. & Carnine, D. (1982). Theory of Instruction: Principles and Applications. Project Follow Through (1977). Evaluation of the Follow Through Programs. Stanford Research Institute. Stockard, J. et al. (2018). The Effectiveness of Direct Instruction Curricula. Review of Educational Research.

# 直接教学法：脚本化教学序列 + 推进规则
class DirectInstructionScript:
    """脚本化、快节奏、显性教学，按正确率推进或重教"""
    def __init__(self, advance_threshold=0.85):
        self.threshold = advance_threshold
        self.script = []
        self.current_step = 0

    def add_step(self, name, teacher_signal, expected_response, duration_s):
        self.script.append({
            'step': len(self.script) + 1,
            'name': name, 'signal': teacher_signal,
            'expected': expected_response, 'duration': duration_s,
            'errors': 0, 'correct': 0
        })

    def observe(self, step_idx, n_correct, n_total):
        s = self.script[step_idx]
        s['correct'] += n_correct
        s['errors'] += (n_total - n_correct)

    def step_rate(self, step_idx):
        s = self.script[step_idx]
        total = s['correct'] + s['errors']
        return round(s['correct'] / max(total, 1), 3)

    def fidelity(self):
        total = sum(s['correct'] + s['errors'] for s in self.script)
        correct = sum(s['correct'] for s in self.script)
        return round(correct / max(total, 1), 3)

    def next_action(self):
        if self.current_step >= len(self.script):
            return 'script_complete'
        rate = self.step_rate(self.current_step)
        if rate >= self.threshold:
            self.current_step += 1
            return f'advance_to_step_{self.current_step}'
        return f'repeat_step_{self.script[self.current_step]["step"]}'

di = DirectInstructionScript()
di.add_step('signal', 'Point to letter A', 'say /a/', 5)
di.add_step('model', 'I say /a/, you say /a/', 'echo /a/', 8)
di.add_step('test', 'Your turn: /a/', 'say /a/', 5)
di.observe(0, 18, 20); di.observe(1, 20, 20); di.observe(2, 19, 20)
print('fidelity:', di.fidelity(), 'next:', di.next_action())
METHOD · A3

精熟学习

Mastery Learning (Unit-based)
FAMILY A
定义

Bloom 提出的精熟学习是把课程拆成学习单元，每单元配两次形成性测验：A 卷诊断、矫正学习、B 卷复测。学生最终掌握状态取两次测验的最佳成绩，达到掌握标准即通过该单元。

核心公式 / 算法
best(o) = max(formA_o, formB_o)
mastered(o) = best(o) ≥ θ
需矫正集 = {o | formA_o < θ}
适用场景
  • 有清晰目标的单元教学
  • 形成性评价体系完备的学校
  • 补救教学与课后辅导
数据需求
  • 单元目标清单
  • 每目标两次形成性测验分数
  • 掌握标准 θ（通常 0.75）
局限
  • 需要双倍测验时间
  • 矫正资源依赖教师人力
  • 对高阶能力目标难以量化
代表论文
Bloom, B.S. (1976). Human Characteristics and School Learning. McGraw-Hill. Anderson, L.W. & Block, J.H. (1987). Mastery Learning Models. International Encyclopedia of Teaching and Teacher Education. Guskey, T.R. (1985). Implementing Mastery Learning. Wadsworth.

# 精熟学习单元：诊断A → 矫正 → 复测B → 最终状态
class MasteryUnit:
    """单个学习单元的精熟学习流程跟踪"""
    def __init__(self, unit_name, objectives, criterion=0.75):
        self.unit = unit_name
        self.objectives = objectives
        self.criterion = criterion
        self.formative_a = {o: None for o in objectives}
        self.formative_b = {o: None for o in objectives}

    def administer_a(self, scores):
        for o, s in scores.items():
            self.formative_a[o] = s

    def administer_b(self, scores):
        for o, s in scores.items():
            self.formative_b[o] = s

    def diagnose(self):
        return {o: (s, 'mastered' if s >= self.criterion else 'remediate')
                for o, s in self.formative_a.items() if s is not None}

    def corrective_targets(self):
        return [o for o, s in self.formative_a.items()
                if s is not None and s < self.criterion]

    def final_status(self):
        out = {}
        for o in self.objectives:
            a, b = self.formative_a[o], self.formative_b[o]
            candidates = [x for x in (a, b) if x is not None]
            best = max(candidates) if candidates else None
            out[o] = {'formA': a, 'formB': b, 'best': best,
                      'mastered': best is not None and best >= self.criterion}
        return out

    def unit_pass_rate(self):
        st = self.final_status()
        return round(sum(1 for v in st.values() if v['mastered']) / len(st), 3)

unit = MasteryUnit('quadratic_equations', ['factoring','formula','graphing'], 0.75)
unit.administer_a({'factoring':0.6, 'formula':0.9, 'graphing':0.5})
print('需矫正:', unit.corrective_targets())
unit.administer_b({'factoring':0.85, 'graphing':0.8})
print('最终:', unit.final_status())
print('单元通过率:', unit.unit_pass_rate())
METHOD · A4

Gagné 九事件教学设计

Nine Events of Instruction
FAMILY A
定义

Gagné 在《学习的条件》中提出九个教学事件，对应九个内部学习过程：唤起注意、告知目标、激活先备、呈现刺激、提供指导、引出表现、提供反馈、评估表现、促进迁移。教师按此序列设计每一节课。

核心公式 / 算法
覆盖率：C = Σ filled(events) / 9
总时长：T = Σ duration(event_i)
完整性：C = 1 → 完整教案
适用场景
  • 单节课或单次教学活动设计
  • 企业培训与微课开发
  • 教学设计评审清单
数据需求
  • 九事件的活动描述
  • 每事件的时长与素材
  • 评估结果（用于反馈与迁移）
局限
  • 线性序列假设过强
  • 对探究式学习适配较弱
  • 缺乏个性化机制
代表论文
Gagné, R.M. (1985). The Conditions of Learning and Theory of Instruction. 4th ed. Holt Rinehart. Gagné, R.M., Briggs, L.J., & Wager, W.W. (1992). Principles of Instructional Design. Harcourt Brace. Reigeluth, C.M. (1999). Instructional-Design Theories and Models. Vol. II. Lawrence Erlbaum.

# Gagné 九事件教学设计：教案规划与完整性检查
class NineEventsPlanner:
    """九事件教学设计：从唤起注意到促进迁移"""
    EVENTS = [
        ('gain_attention', '唤起注意'),
        ('inform_objectives', '告知目标'),
        ('stimulate_recall', '激活先备'),
        ('present_content', '呈现刺激'),
        ('provide_guidance', '提供指导'),
        ('elicit_performance', '引出表现'),
        ('provide_feedback', '提供反馈'),
        ('assess_performance', '评估表现'),
        ('enhance_transfer', '促进迁移'),
    ]
    def __init__(self, lesson_title):
        self.title = lesson_title
        self.plan = [{'event': k, 'label': l, 'activity': '',
                      'material': '', 'duration_min': 0}
                     for k, l in self.EVENTS]

    def set_event(self, idx, activity, material, duration_min):
        self.plan[idx].update({'activity': activity, 'material': material,
                                    'duration_min': duration_min})

    def total_duration(self):
        return sum(p['duration_min'] for p in self.plan)

    def coverage(self):
        filled = sum(1 for p in self.plan if p['activity'])
        return round(filled / len(self.plan), 3)

    def missing_events(self):
        return [p['label'] for p in self.plan if not p['activity']]

    def render(self):
        lines = [f'教案: {self.title}', '-' * 44]
        for i, p in enumerate(self.plan, 1):
            act = p['activity'] or '[未设计]'
            lines.append(f"{i}. {p['label']} [{p['duration_min']}min] {act}")
        return '\n'.join(lines)

planner = NineEventsPlanner('光合作用入门')
planner.set_event(0, '播放叶绿体动画', 'video_chloroplast.mp4', 3)
planner.set_event(1, '展示学习目标', 'slide_obj.pdf', 2)
planner.set_event(2, '提问:植物吃什么', 'oral_qa', 4)
planner.set_event(3, '讲解光反应', 'slide_light.pdf', 10)
planner.set_event(5, '小组画图', 'worksheet.docx', 8)
planner.set_event(6, '巡视反馈', 'checklist.xlsx', 6)
print(planner.render())
print('覆盖率:', planner.coverage(), '缺失:', planner.missing_events())
print('总时长:', planner.total_duration(), 'min')
03 · FAMILY B · 学习科学

家族 B · 学习科学四法

建构主义探究学习、同伴教学、自我组织学习环境 SOLE、项目式学习 PBL。它们的共同假设是：学习是学生在情境中主动建构知识，同伴互动和真实任务是关键驱动力。

METHOD · B1

建构主义探究学习

Constructivist Inquiry Learning (5E Model)
FAMILY B
定义

基于皮亚杰与维果茨基的建构主义，学习者在真实情境中通过探究主动建构知识。常用 5E 模型：Engage（投入）→ Explore（探究）→ Explain（解释）→ Elaborate（拓展）→ Evaluate（评价），由 BSCS 生物课程开发。

核心公式 / 算法
阶段覆盖：C = Σ filled(phases) / 5
探究深度：D = mean(score(artifact))
完整性：C = 1 ∧ D ≥ 0.7
适用场景
  • 科学实验与探究课
  • 跨学科主题学习
  • 概念转变教学
数据需求
  • 各阶段的驱动问题与产物
  • 学生产物的评分量规
  • 概念转变的前后测
局限
  • 耗时，课时紧张难落地
  • 评价主观性强
  • 对教师引导能力要求高
代表论文
Bybee, R.W. et al. (2006). The BSCS 5E Instructional Model. BSCS Press. Piaget, J. (1970). Genetic Epistemology. Columbia University Press. Vygotsky, L.S. (1978). Mind in Society. Harvard University Press.

# 5E 探究学习模型：投入→探究→解释→拓展→评价
class FiveEInquiry:
    """追踪5E各阶段的设计与产物，评估探究深度"""
    PHASES = ['engage', 'explore', 'explain', 'elaborate', 'evaluate']
    def __init__(self, topic):
        self.topic = topic
        self.phases = {p: {'prompt': '', 'artifact': ''} for p in self.PHASES}
        self.artifacts = []

    def set_phase(self, phase, prompt, expected_artifact):
        self.phases[phase]['prompt'] = prompt
        self.phases[phase]['artifact'] = expected_artifact

    def submit_artifact(self, phase, student_id, content):
        self.artifacts.append({'phase': phase, 'student': student_id,
                                    'content': content, 'score': None})

    def score_phase(self, phase, rubric_fn):
        for a in self.artifacts:
            if a['phase'] == phase:
                a['score'] = rubric_fn(a['content'])

    def inquiry_depth(self):
        scored = [a['score'] for a in self.artifacts if a['score'] is not None]
        return round(sum(scored) / max(len(scored), 1), 3)

    def coverage(self):
        return round(sum(1 for p in self.phases.values() if p['prompt']) / len(self.PHASES), 3)

    def report(self):
        return {'topic': self.topic, 'coverage': self.coverage(),
                'artifacts': len(self.artifacts), 'depth': self.inquiry_depth()}

inq = FiveEInquiry('水循环')
inq.set_phase('engage', '观察蒸发实验', '观察记录')
inq.set_phase('explore', '小组设计冷凝装置', '设计草图')
inq.set_phase('explain', '用自己的话解释循环', '概念图')
inq.submit_artifact('engage', 'S01', '看到水汽凝结在盖子上')
inq.submit_artifact('explain', 'S01', '蒸发→冷凝→降水')
inq.score_phase('explain', lambda c: 0.8 if '→' in c else 0.5)
print(inq.report())
METHOD · B2

同伴教学 Peer Instruction

Peer Instruction (Mazur)
FAMILY B
定义

Mazur 在哈佛物理课提出：教师抛出一个 ConcepTest 概念题，学生先独立作答（R1），再与邻座讨论 2–3 分钟后再次作答（R2），最后教师解释。讨论窗口在 R1 正确率介于 30%–70% 时效果最佳。

核心公式 / 算法
归一化增益：g = (R2 − R1) / (1 − R1)
讨论窗口：0.3 ≤ R1 ≤ 0.7
分布：p(c) = count(c) / N
适用场景
  • 大班讲座型课堂
  • 物理、化学等概念密集学科
  • 翻转课堂的课堂环节
数据需求
  • 每学生两轮作答记录
  • 题目的正确选项
  • 讨论时长记录
局限
  • 依赖高质量概念题设计
  • R1 过高或过低时讨论失效
  • 难以覆盖全部认知层级
代表论文
Mazur, E. (1997). Peer Instruction: A User's Manual. Prentice Hall. Crouch, C.H. & Mazur, E. (2001). Peer Instruction: Ten years of experience and results. American Journal of Physics. Lasry, N. (2008). Clickers or flashcards: Is there really a difference? The Physics Teacher.

import numpy as np

class PeerInstruction:
    """追踪两轮作答分布、归一化增益与讨论窗口质量"""
    def __init__(self, conceptest_id, choices=['A','B','C','D']):
        self.cid = conceptest_id
        self.choices = choices
        self.round1 = {}
        self.round2 = {}
        self.correct = None

    def set_correct(self, choice):
        self.correct = choice

    def collect_r1(self, responses):
        self.round1 = dict(responses)

    def collect_r2(self, responses):
        self.round2 = dict(responses)

    def _rate(self, d):
        return sum(1 for v in d.values() if v == self.correct) / max(len(d), 1)

    def distribution(self, which):
        d = self.round1 if which == 1 else self.round2
        n = max(len(d), 1)
        return {c: round(list(d.values()).count(c) / n, 3) for c in self.choices}

    def gain(self):
        r1, r2 = self._rate(self.round1), self._rate(self.round2)
        return round((r2 - r1) / max(1 - r1, 1e-6), 3)

    def discussion_window(self):
        r1 = self._rate(self.round1)
        if 0.3 <= r1 <= 0.7:
            return 'optimal'
        return 'redesign_question'

pi.set_correct('C')
pi.collect_r1({'S1':'A','S2':'B','S3':'C','S4':'A','S5':'C',
               'S6':'B','S7':'C','S8':'A','S9':'B','S10':'C'})

    """追踪分组、检索日志、展示成果与涌现质量"""

        self.question = big_question
        self.group_size = group_size
        self.duration = duration_min
        self.groups = {}
        self.presentations = []

    def form_groups(self, student_ids):
        for i in range(0, len(student_ids), self.group_size):
            gid = f'G{len(self.groups)+1}'
            self.groups[gid] = {'members': student_ids[i:i+self.group_size], 'log': []}

    def record_search(self, group_id, query, source_url, snippet):
        self.groups[group_id]['log'].append({'query': query, 'source': source_url,
                                           'snippet': snippet})

    def present(self, group_id, answer, evidence_count):
        self.presentations.append({'group': group_id, 'answer': answer,
                                       'evidence': evidence_count})

    def emergence_score(self):
        if not self.groups: return 0
        with_log = sum(1 for g in self.groups.values() if g['log'])
        return round(with_log / len(self.groups), 3)

    def credibility(self):
        if not self.presentations: return 0
        return round(sum(p['evidence'] for p in self.presentations) / len(self.presentations), 3)

    def report(self):
        return {'question': self.question, 'groups': len(self.groups),
                'emergence': self.emergence_score(), 'credibility': self.credibility()}

class PBLProject:
    """追踪里程碑进度与多维度量规评分"""
    def __init__(self, driving_question, duration_weeks=4):
        self.dq = driving_question
        self.weeks = duration_weeks
        self.milestones = []
        self.artifacts = []
        self.rubric = {'content':0, 'collaboration':0,
                       'craft':0, 'presentation':0}

    def add_milestone(self, name, deliverable, due_week):
        self.milestones.append({'name':name, 'deliverable':deliverable,
                                    'due':due_week, 'done':False})

    def submit_artifact(self, milestone_idx, team_id, file_path, quality_score):
        self.artifacts.append({'team':team_id, 'milestone':milestone_idx,
                                     'file':file_path, 'quality':quality_score})
        self.milestones[milestone_idx]['done'] = True

    def assess(self, scores):
        for k in self.rubric:
            if k in scores: self.rubric[k] = scores[k]

    def progress(self):
        done = sum(1 for m in self.milestones if m['done'])
        return round(done / max(len(self.milestones), 1), 3)

    def overall(self):
        w = {'content':0.35, 'collaboration':0.20,
             'craft':0.25, 'presentation':0.20}
        return round(sum(self.rubric[k] * w[k] for k in w), 3)

    def report(self):
        return {'driving_question': self.dq, 'progress': self.progress(),
                'overall': self.overall(), 'rubric': self.rubric}

知识追踪 BKT / DKT

FAMILY C
定义

知识追踪根据学生答题序列估计其对每个技能的掌握概率。BKT 用隐马尔可夫模型，参数为初始掌握、学习率、猜测、失误、遗忘；DKT（Piech 2015）用 LSTM 把答题序列映射到技能掌握概率向量，突破 BKT 的单技能独立假设。

BKT 更新：P(L_t|obs) ∝ P(obs|L_t)P(L_t)

p(k) = σ(W_k · h_t)

  • 智能辅导系统的下一题推荐

  • 大规模在线课程学习者建模

  • 学生×题目×技能×对错的时序数据
  • BKT 需技能标注；DKT 可端到端

  • BKT 假设技能独立，难处理先决关系

METHOD · C2

自适应测试 IRT

Item Response Theory & Computerized Adaptive Testing
FAMILY C
定义

项目反应理论（IRT）把学生能力 θ 和题目参数（区分度 a、难度 b、猜测 c）建模到同一量表上，3PL 模型预测答对概率。计算机化自适应测试（CAT）用 Fisher 信息量选题，用最少题目达到目标能力估计精度。

核心公式 / 算法
3PL：P(θ) = c + (1−c) / (1 + e^{−1.7a(θ−b)})
Fisher信息：I(θ) = a²·(Q/P)·(θ−b)²
CAT选题：argmax I_i(θ̂)
适用场景
  • 标准化考试（GRE、GMAT）
  • 自适应练习与诊断
  • 题库等值与链接
数据需求
  • 学生×题目对错矩阵
  • 题库规模 ≥ 100 题
  • 样本量 ≥ 500（3PL 稳定估计）
局限
  • 假设局部独立性
  • 多维能力难以单 θ 刻画
  • 题库建设与等值成本高
代表论文
Lord, F.M. (1980). Applications of Item Response Theory to Practical Testing Problems. Erlbaum. Wainer, H. et al. (2000). Computerized Adaptive Testing: A Primer. 2nd ed. Lawrence Erlbaum. vanderLinden, W.J. & Glas, C.A.W. (2010). Elements of Adaptive Testing. Springer.

# IRT 3PL 拟合 + 自适应选题(CAT) 用 Fisher 信息量
# pip install pyirt  (或 py-irt)
import numpy as np
import pandas as pd

np.random.seed(7)
n_students, n_items = 500, 40
true_theta = np.random.normal(0, 1, n_students)
true_a = np.random.uniform(0.6, 1.8, n_items)   # 区分度
true_b = np.random.normal(0, 1, n_items)        # 难度
true_c = np.random.uniform(0.1, 0.3, n_items)    # 猜测

def prob3pl(theta, a, b, c):
    return c + (1 - c) / (1 + np.exp(-1.7 * a * (theta - b)))

records = []
for sid, th in enumerate(true_theta):
    for iid in range(n_items):
        p = prob3pl(th, true_a[iid], true_b[iid], true_c[iid])
        c = int(np.random.rand() < p)
        records.append((sid, iid, c))
df = pd.DataFrame(records, columns=['user','item','correct'])

# 用 pyirt 拟合 3PL（接口因包实现而异，此处示意）
try:
    from pyirt import irt_param
    param = irt_param(df['user'].values, df['item'].values,
                       df['correct'].values, model='3pl', max_iter=200)
    items_df = pd.DataFrame(param['item_param'])
    print(items_df.head(8))
except Exception as e:
    print('pyirt 不可用，用真值演示 CAT 选题:', e)
    items_df = pd.DataFrame({'a':true_a, 'b':true_b, 'c':true_c})

def fisher_info(theta, a, b, c):
    p = prob3pl(theta, a, b, c); q = 1 - p
    return (a**2) * (q/p) * ((theta - b)**2)

def cat_next(theta, pool, administered):
    best, best_info = None, -1
    for iid, row in pool.iterrows():
        if iid in administered: continue
        info = fisher_info(theta, row['a'], row['b'], row['c'])
        if info > best_info: best_info, best = info, iid
    return best, round(best_info, 4)

pool = items_df.copy()
print('θ=0 时推荐题:', cat_next(0.0, pool, set()))
print('θ=1 时推荐题:', cat_next(1.0, pool, set()))

features['risk'] = (features['engagement'] < features['engagement'].quantile(0.2)).astype(int)
print('=== 高风险学生数 ===', features['risk'].sum())

# 协作网络分析
G = nx.Graph()
for sid in range(n_students): G.add_node(sid)
pair_counts = defaultdict(int)
for _ in range(400):
    a, b = np.random.randint(0, n_students, 2)
    if a != b: pair_counts[tuple(sorted([a,b]))] += 1
for (a,b), w in pair_counts.items(): G.add_edge(a, b, weight=w)

print('=== 协作网络指标 ===')
print('节点:', G.number_of_nodes(), '边:', G.number_of_edges())
print('平均度:', round(np.mean([d for _,d in G.degree()]), 2))
print('最大连通分量:', len(max(nx.connected_components(G), key=len)))
print('桥接中心性最高:', max(nx.betweenness_centrality(G).items(), key=lambda x:x[1])[0])

07 · COMPARISON · 三家族横向对比

三家族横向对比：何时用谁

三家族不是替代关系，而是互补关系。家族 A 回答"怎么教"，家族 B 回答"学生怎么学"，家族 C 回答"如何用数据建模学习者"。真实的教育AI系统通常是三者组合。

家族 A · 传统教学设计

擅长：显性化的教学序列设计、掌握阈值判定、基础技能训练。理论根基扎实，可解释性最强。

短板：缺乏个性化数据驱动，难以处理高维技能空间和复杂时序。

典型组合：Bloom 掌握阈值 + Gagné 九事件设计单节课，再用精熟学习双测验闭环。

▸ 当问题=怎么教 / 课时设计 / 基础技能训练 → 用家族 A

家族 B · 学习科学

擅长：激发高阶思维、协作学习、真实情境探究。关注"学"的深度而非"教"的效率。

短板：评价主观、耗时、规模化困难，难以产出可比较的量化指标。

典型组合：5E 探究 + 同伴教学激活概念转变，再用 PBL 把探究沉淀为作品。

▸ 当问题=高阶思维 / 协作 / 真实任务 → 用家族 B

家族 C · 计算教育学

擅长：大规模学习者建模、自适应推荐、风险预警。是 AI 教育的技术骨架。

短板：可解释性弱（DKT）、隐私伦理风险高、相关非因果。

典型组合：BKT/DKT 追踪掌握 → IRT/CAT 选下一题 → EDM 预警 → LA 仪表盘反馈。

▸ 当问题=规模化 / 自适应 / 预测预警 → 用家族 C
