01 / LADDER

教育AI能力阶梯

把教育AI分成L1辅助 → L2增强 → L3自主三阶段。阶段越高，AI承担的教学决策越多，教师角色从"操作者"转为"设计者与裁判"。

阶段 核心定义 AI角色 教师角色 典型技术 代表产品 风险边界
L1 辅助 AI作为效率工具，承担批改、检索、排版等机械任务，教学决策完全由人。 助手 / 工具 主导者 自动批改、检索增强(RAG)、题库推荐 作业帮、Grammarly、百度文库 低 · 主要风险是答案错误
L2 增强 AI作为协作者，提供个性化路径、实时反馈、多模态分析，教师审核并调整。 协同教练 审核者 / 设计者 知识图谱、学生建模、多模态学习分析、LLM微调 Khanmigo、Duolingo Max、Coursera Coach 中 · 依赖幻觉、算法偏见、数据隐私
自主 AI作为主导教学者，自主规划课程、生成内容、评估学习，人退居监督与伦理把关。 自主导师 监督者 / 伦理守门 Agent编排、长程记忆、自我评估、教育专用LLM 实验性教育Agent、2025教育LLM原型 高 · 责任归属、公平性、长期依赖
费曼式提醒：多数今天的产品停在L1到L2之间。L3不是"更强大的L2"，而是责任结构的改变——当AI主导教学，"错了算谁的"这个问题必须先回答。
01·深 / TRANSITION

阶段跃迁的代价

每一级跃迁不只是"能力变强"，更是责任、风险与角色的重新分配。看清代价，才不会盲目追求高阶段。

L1 → L2

从工具到协作者

能力变化：AI从"批改、检索"升级到"个性化路径、实时反馈、多模态分析"。

教师变化：从"主导者"变为"审核者与设计者"，需要学会读AI输出、调整推荐、设计教学流程。

新增风险：幻觉（AI自信地给错答案）、算法偏见（对某类学生推荐偏差）、数据隐私（多模态采集侵入性强）。

跃迁代价：教师必须具备审核AI输出的能力，否则就是"把方向盘交给一个你不懂的司机"。
L2 → L3

从协作者到主导者

能力变化：AI从"提供选项"升级到"自主规划课程、生成内容、评估学习"。

教师变化：从"审核者"变为"监督者与伦理守门人"，退到第二线但责任更重。

新增风险：责任归属（错了算谁的）、长期依赖（学生失去自主学习能力）、公平性（高阶AI是否只服务富人）。

跃迁代价：必须先建立责任归属机制与伦理框架，否则L3就是"无人驾驶的教育"——出了事无人负责。
跃迁红线

什么情况下不该跃迁

不是所有场景都该追求高阶段。三条红线：

  1. 责任不清时——错了算谁的没回答，就不该让AI主导。
  2. 效果未证时——长期迁移未被验证，就不该大规模铺开。
  3. 公平未保时——会扩大差距，就不该先到优势群体。

低阶段不是落后，是审慎。L1做好的产品，比L3做虚的产品更有价值。

阶段观的真正用途：它不是"越高越好"的排名，而是"认清你站在哪、下一步该准备什么"的地图。多数教育机构今天该做的，不是急着冲L3，而是把L1做扎实、把L2的审核机制建好。跃迁是结果，不是目标——当责任、效果、公平三件事都准备好了，跃迁自然发生。

03 / FRAMEWORK

教育AI技术框架

五大技术栈支撑今天的教育AI：RAG检索增强、知识图谱、多模态学习分析、LLM微调、学生建模。它们不是替代关系，而是层层叠加。

01

RAG 检索增强

Retrieval-Augmented Generation

把教材、课标、错题库灌入向量数据库，生成时先检索再回答，降低幻觉、提供可引用来源。

  • 向量库：教材段落 + 例题 + 课标
  • 检索：语义相似 + 知识点过滤
  • 生成：引用页码，可追溯
02

知识图谱

Knowledge Graph

把学科拆成知识点与前置关系，定位"卡在哪里"，规划"下一步学什么"。

  • 节点：知识点 / 能力 / 错因
  • 边：前置 / 包含 / 关联
  • 应用：诊断 + 路径推荐
03

多模态学习分析

Multimodal Learning Analytics

融合眼动、表情、语音、笔迹、姿态，判断"懂没懂、烦没烦、投入度"。

  • 采集：五模态同步
  • 融合：时序对齐 + 注意力
  • 输出：认知/情感状态
04

LLM 微调

Education Fine-tuning

在通用大模型上做学科微调与对齐，让模型"会教书"而不只是"会答题"。

  • 数据：教学对话 + 苏格拉底式提问
  • 对齐：不直接给答案，引导思考
  • 评测：教学有效性而非答案准确
05

学生建模

Student Modeling

构建每个学生的能力、风格、兴趣画像，驱动个性化路径与难度自适应。

  • 模型：贝叶斯知识追踪BKT/DKT
  • 维度：认知 + 情感 + 行为
  • 更新：实时增量学习
架构层次：用户界面层（Web/移动/API）→ 业务逻辑层（用户管理/内容处理/学习分析/评估系统）→ 数据层（用户库/知识库/学习记录/模型参数）。技术组件包括LLM模型(GPT/Claude/LLaMA)、向量数据库、知识图谱、推荐算法、评估引擎。
03·深 / FOUR LAYERS

四层架构拆解

把上面五大技术栈装进基础设施层 → 能力服务层 → 教学应用层 → 治理与评估层的四层骨架，看清每层的职责、组件与失守后果。

L0

基础设施层

Infrastructure

算力、存储、网络与模型权重，是整栋大楼的地基。教育场景对延迟与隐私敏感，常需混合部署。

  • GPU集群 / 边缘推理盒
  • 对象存储 + 向量数据库
  • 私有化模型权重与加密通道
  • 端侧小模型：低延迟、离线可用
失守后果：延迟超1秒学生流失，数据泄露触发合规事故。
L1

能力服务层

Capability Services

把 raw 模型能力封装成教育可调用的服务：检索、推理、评估、生成、建模，统一对外接口。

  • RAG检索服务（教材/课标/错题）
  • 知识图谱查询服务
  • 学生建模服务（BKT/DKT）
  • 多模态融合推理服务
  • 评估与反馈生成服务
失守后果：能力碎片化、重复造轮子，接口不一致导致集成成本高。
L2

教学应用层

Teaching Applications

直接面向师生的产品形态：导师、助教、批改、备课、学情看板。这层决定"用户体感"。

  • AI导师（苏格拉底式追问）
  • AI助教（答疑、代码review）
  • 智能批改与反馈
  • 教师备课与学情仪表盘
  • 个性化练习与路径推荐
失守后果：功能炫酷但教学无效，沦为费曼所说的"教育表演"。
L3

治理与评估层

Governance & Evaluation

贯穿全栈的护栏：伦理审查、公平性审计、效果评估、数据合规、责任归属。最常被忽略，也最关键。

  • 算法偏见与公平性审计
  • 数据隐私合规（GDPR/PIPL/HIPAA）
  • 教学有效性循证评估
  • 错误归因与人工复核机制
  • 责任边界与可解释性报告
失守后果：技术跑在伦理前面，出了问题无人负责，信任崩塌。
层次关键组件教育专属考量选型权衡
基础设施
L0		 算力、存储、网络、模型权重 课堂场景要求低延迟；学生数据要求本地化或加密 云vs端：弹性vs隐私；大模型vs小模型：能力vs成本
能力服务
L1		 RAG、知识图谱、学生建模、多模态融合 检索必须命中课标对齐的内容；学生模型要覆盖认知+情感 通用APIvs自研：成本vs可控；离线vs在线：稳定vs新鲜
教学应用
L2		 导师、助教、批改、备课、看板 不直接给答案的约束；教师可干预；学情可读 自动vs人工：效率vs温度；封闭vs开放：安全vs创造
治理评估
L3		 公平审计、隐私合规、效果评估、责任归属 未成年人数据最敏感；效果不只看分数；责任必须可追溯 严格vs宽松：信任vs速度；透明vs商业秘密：可解释vs竞争力
部署模式

三种部署：公有云 / 混合 / 私有化

公有云弹性大、更新快，但学生数据出校有合规风险；私有化最安全但成本高、迭代慢；混合架构把敏感信号端侧处理、推理走云端，是当下主流折中。医学生教育可参考FMRP-LEAN的HIPAA合规架构。

数据流转

从信号到决策的闭环

原始学习信号（答题、眼动、笔迹）→ 特征提取 → 学生模型更新 → 路径推荐 → 新任务呈现 → 再采集。闭环越短，个性化越快；但每多一个环节，就多一个隐私与偏见风险点。闭环必须可中断、可审计、可纠偏。

四层视角的真正价值：它强迫我们在每一层都问三个问题——"这层该用什么技术？""这层的教育专属考量是什么？""这层失守会怎样？"多数教育AI产品的失败，不在某一层做不好，而在层与层之间的脱节：能力服务很炫，但教学应用没接住；教学应用很热闹，但治理评估缺位。四层架构不是堆叠，是咬合。
04 / METHODOLOGY

三大学问家族

教育AI不是凭空而生，它站在传统教学设计、学习科学、计算教育学三大家族的肩上。理解这三家的取向，才能看清AI该插在哪一层。

家族 核心问题 代表性理论 方法取向 对AI的态度 局限
传统教学设计
Instructional Design		 如何把目标拆成可教、可测的步骤？ Bloom分类学、ADDIE模型、九大教学事件 目标—活动—评估闭环，强调结构化 把AI当作内容生产与评估工具 结构过强，难应对开放性学习
学习科学
Learning Sciences		 人到底怎么学会？情境如何影响理解？ 建构主义、情境认知、社会文化理论 探究、协作、项目式学习，关注意义建构 警惕AI削弱社会性互动与深度思考 难规模化、难量化效果
计算教育学
Computational Pedagogy		 能否用数据与模型预测并优化学习？ 知识追踪、教育数据挖掘、学习分析 数据驱动、模型预测、闭环优化 AI是核心引擎，强调可计算建模 易陷入"测得到的才被重视"
关键张力：计算教育学擅长"测得到的"（分数、时间、完成率），学习科学关心"测不到的"（好奇心、创造力、批判性思维）。真正的教育AI必须把两家放在同一张桌子上——否则就是费曼说的"教育界的货物崇拜"：有形式，没实质。
04·深 / FAMILY DEEP

三家族深潜

把上表的三家族各自摊开：源流、代表人物、核心实验、对AI的具体贡献与盲区。

家族一

传统教学设计

源流：二战军事训练 → Bloom分类学(1956) → ADDIE模型 → 九大教学事件(Gagné)。

代表人物：Bloom、Gagné、Reigeluth、Merrill。

核心贡献：把"教学"从经验变成工程——目标可拆、过程可设计、效果可测。ADDIE（分析-设计-开发-实施-评估）至今是课程开发的底层流程。

对AI的赋权：给AI提供了"可计算的教学结构"。知识图谱的"前置关系"本质是Bloom目标分解的图谱化；自适应路径是ADDIE的实时化。

盲区：假设目标可完全预设，对开放性、生成性学习束手无策；过度结构化会压抑探究。
家族二

学习科学

源流：Piaget建构主义 → Vygotsky社会文化 → 情境认知 → 具身认知。

代表人物：Piaget、Vygotsky、Brown、Collins、Sawyer。

核心贡献：把"学习"从"接收信息"重新定义为"意义建构"。强调情境、社会互动、先前经验、元认知。PBL、协作学习、翻转课堂都源于此。

对AI的警示：警惕AI把"学习"窄化为"答题"。如果AI只做知识传递，就丢掉了学习科学四十年的核心发现——理解发生在社会性互动与真实情境中。

盲区：难规模化、难量化、难评估，常被批评"理想化"；与工程化教学设计存在张力。
家族三

计算教育学

源流：智能辅导系统ITS → 教育数据挖掘EDM → 学习分析LA → 深度知识追踪。

代表人物：Anderson(ACT-R)、Koedinger、Corbett、Piech、Self。

核心贡献：把"学习"变成可建模、可预测、可优化的信号。BKT/DKT能预测下一题对错，ITS能做精细化路径，让"个性化"第一次有了工程基础。

对AI的赋能：提供了学生建模、知识追踪、效果评估的方法论，是今天教育AI"个性化"的技术母体。

盲区："测得到的才被重视"——分数、时间、完成率易测，但好奇心、创造力、批判性思维被系统性忽略。
融合实验

当三家族坐在一张桌子前

真正的教育AI需要三家族协作：教学设计提供结构与目标（学什么、怎么拆），学习科学提供机理与情境（怎么学、为什么这样学），计算教育学提供模型与反馈（学得怎样、下一步）。缺结构会散，缺机理会假，缺模型会虚。

一个具体的协作样例：教学设计师把"分数加减"拆成8个知识点 → 学习科学家指出"分数概念"是认知关键，需用实物情境 → 计算教育学者用DKT预测每个学生的掌握概率 → AI据此推荐任务，但任务形态由学习科学决定（情境题而非机械题）。

反货物崇拜清单

四个自检问题

费曼说"有形式没实质"就是货物崇拜。教育AI可对照四问自检：

  1. 它问问题还是给答案？给答案的是工具，问问题的是导师。
  2. 它测的是理解还是应试？分数提升不等于理解提升。
  3. 它让教师更强还是更闲？减负不是目的，让教师做回教师才是。
  4. 它对最弱势的学生是放大还是缩小差距？公平是底线，不是加分项。
05 / PARADIGM

四范式联表

从传统课堂 → 在线教育 → AI辅助 → AI自主，四代范式在时空、师生比、反馈延迟、个性化深度上逐级跃迁，但每一跃迁也带来新的失序。

第一代

传统课堂

同步、同地、一对多。教师是唯一信息源，反馈延迟以"天"计，个性化几乎为零，但社会性互动最强。

VS
第二代

在线教育

异步、异地、一对海量。MOOC把优质内容规模化，反馈延迟降到"分钟"，但完成率低、孤独感强。

第三代

AI辅助

人机协同、个性化路径、实时反馈。AI做"机械活"，教师做"创造活"，反馈延迟降到"秒"。

VS
第四代

AI自主

AI主导教学决策、自主生成课程与评估。人退居监督，责任归属与公平性成为核心议题。

失序与代价

每一次跃迁都伴随新失序

第一代的失序是资源不均——优质教师集中在城市；第二代的失序是孤独与放弃——MOOC完成率常低于10%；第三代的失序是依赖与偏见——学生离不开AI、算法放大偏见；第四代的失序将是责任真空——AI主导后出了错无人负责。技术解决上一代的失序，又制造下一代的失序，这是范式的辩证法。

不可逆性

哪些一旦发生就回不去

从一代到下一代，有些变化是单向的：一旦学生习惯了秒级反馈，就难以回到"等老师明天批改"；一旦习惯了个性化路径，就难以回到"一刀切进度"；一旦AI主导了教学，教师能力可能不可逆地退化。跃迁前必须问：这个变化我们愿意承担吗？还是它只是"发生了"?

范式观的清醒：四代范式不是"后浪拍死前浪"，而是叠加共存——今天的真实课堂里，传统课堂、在线资源、AI辅助、AI自主往往同时存在。问题不是"选哪一代"，而是"在什么场景、对什么学生、用什么配比"。最危险的，是用第四代的技术做第一代的事——用AI做题海战术，那只是给旧问题装了新引擎。

06·深 / THREE LAYERS

三层教育化改造

教育大模型不是通用模型套壳，而是在数据层、对齐层、评测层分别做教育化改造。三层各自摊开，看清每层"改什么、为什么、怎么验证"。

数据层

从问答对到教学对话

Data Layer

通用模型用"问题-答案"对训练，教育模型必须用"教学对话"训练——包含追问、等待、纠错、引导链。数据形态决定模型行为。

  • 教学对话：师生多轮交互，含追问与停顿
  • 错例库：学生典型错误与成因标注
  • 引导链：从提问到学生顿悟的完整路径
  • 课标对齐语料：覆盖知识点与能力维度
  • 多学段分级：小学到高校的语言风格
关键原则：数据量不如数据形态重要。一万条"问-答"不如一千条"问-追问-再问-顿悟"。
对齐层

从给答案到问问题

Alignment Layer

用RLHF/DPO把"会教书"的行为对齐进模型：不直接给答案、苏格拉底式追问、学段适配、安全边界、教师可见。

  • 苏格拉底约束：先问再答，引导推导
  • 学段适配：用语与难度匹配学生水平
  • 安全过滤：不当内容、价值观红线
  • 教师可见：对话摘要可回看、可干预
  • 不替代判断：考试时不越界给答案
关键原则：对齐的目标不是"答案正确"，而是"教学有效"。一个直接给正确答案的模型，教学上可能失败。
评测层

从答案准确到学习增益

Evaluation Layer

通用模型用准确率/ROUGE评测，教育模型必须用教学有效性评测——学生是否真的学会了，而非模型答得对不对。

  • 学习增益：前后测对比，是否真提升
  • 理解深度：能否迁移、能否解释
  • 教师满意度：是否真的减负增效
  • 安全性：是否越界、是否误导
  • 公平性：对不同群体的效果差异
关键原则：没有教学有效性评测，教育大模型就只是"会答教育题的通用模型"。

幻觉治理

教育场景的幻觉最致命

通用模型的幻觉最多闹笑话，教育模型的幻觉会误导学习者建立错误概念，且学习者往往无力甄别。治理组合拳：RAG检索约束（先查教材再答）+ 置信度标注（不确定就说不确定）+ 教师复核机制（高风险内容人工把关）+ 错误反馈闭环（学生纠错反哺模型）。

学科差异

不同学科，不同改造

数学要步骤可解释与公式渲染，语言学习要对话交互与发音评估，编程要代码执行与沙箱反馈，人文要开放讨论与多视角。没有"一个教育大模型通吃所有学科"，分层微调与学科专家协同是常态。MathGPT专注数学、Khanmigo跨学科但偏理科，都是这一规律的体现。

教育大模型的成熟度曲线：2023年是"通用模型套教育皮"的元年；2024-2025年进入"数据层教育化"阶段，教学对话语料成为核心资产；2026年起进入"对齐层与评测层教育化"阶段，谁先建立教学有效性评测体系，谁就能证明自己不只是"会答教育题"。三层改造不是选做题，是教育大模型从"工具"升级为"导师"的必经之路。
07 / FAIRNESS

教育公平与伦理

AI可能缩小也可能放大教育不平等。这一章谈数字鸿沟、算法偏见、隐私保护，以及UNESCO AI素养四级框架与EU AI Act第4条。

数字鸿沟

设备、带宽、素养三重差距

城乡、区域、家庭经济差异，决定谁能用上AI教育。COVID期间在线教育已暴露硬件鸿沟，AI时代差距可能更深——不只是"有没有"，更是"会不会用"。

算法偏见

训练数据里的历史不公

性别、地域、文化偏见会被模型继承并放大。解法：数据多样化、公平性约束、定期审计、人工复核机制。注意"测得到的公平"不等于"真实的公平"。

隐私保护

学生数据是最敏感的数据

学习行为、成绩、甚至表情笔迹都属个人信息。需加密、匿名化、最小化采集、明确知情同意、严格权限管理。HIPAA合规架构（如FMRP-LEAN）为医学教育提供了范本。

UNESCO AI素养四级框架

从"会用"到"会治"的四级能力

联合国教科文组织提出AI素养四级框架，2024年正式发布，是各国课程设计的参考蓝本。

等级能力名称核心要求
L1基础素养理解AI基本概念、能力边界与常见风险，能区分AI生成与人工内容。
L2应用能力在学习和工作中恰当使用AI工具，能提出有效问题、评估输出质量。
L3共创能力与AI协作创造新内容、新方案，能设计提示词与工作流，参与AI辅助的项目。
L4治理能力审视AI的社会影响，参与伦理讨论与规则制定，能对AI系统做公平性与安全性评估。
法规坐标 · EU AI Act 第4条：《欧盟人工智能法案》第4条关于AI素养的要求已于2025年2月2日生效，要求AI系统的提供方与部署方确保其工作人员具备足够的AI素养。这是全球首个对AI教育素养提出硬性合规要求的法律条款，对教育机构采购与使用AI工具具有直接约束力。
底线一

不伤害

这是最低也是最高的红线。AI不得以任何形式对学生造成生理、心理或发展性伤害。多模态采集不得变成监控，自动化决策不得变成标签化，个性化不得变成信息茧房。伤害不只发生在"做错了"，也发生在"过度做了"。

底线二

可解释

每一个影响学生命运的AI决策（评分、分流、推荐）都必须可追溯、可解释、可申诉。黑箱决策在教育里不可接受——学生有权知道"为什么"。可解释不是技术选项，是受教育权的延伸。

底线三

可退出

学生与教师必须保留"不用AI"的权利与通道。一旦AI成为唯一路径，教育就丧失了选择自由，也丧失了对照基线。可退出是对技术依赖的最终制衡——保留"非AI方式"的可用性，是教育AI的退路。

08 / MULTIMODAL

多模态学习分析

学习不只发生在"答题"那一刻。眼动、表情、语音、笔迹、姿态五模态融合，让AI能"看见"学生的投入、困惑与情绪，而不只看分数。

眼动

注视点、瞳孔扩张、扫视路径，判断注意力分配与认知负荷

表情

面部动作编码FACS，识别困惑、专注、疲惫等学习情绪状态

语音

语调、停顿、语速、犹豫，反映信心与理解程度

笔迹

书写压力、速度、修改轨迹，记录解题思路与犹豫点

姿态

坐姿、头部朝向、手势，判断投入度与疲劳

融合架构与时序对齐

五模态不能简单拼接，必须在时间轴上对齐，再用注意力机制加权融合。例如"皱眉+停顿+笔迹犹豫"同时出现，比任何单一信号都更能说明"卡住了"。

伦理红线：多模态采集天然侵入性强。必须做到：①最小化采集，只采教学必需信号；②知情同意，学生与家长明确授权；③本地优先，敏感信号端侧处理；④不用于惩罚，只用于支持。表情与姿态数据尤其敏感，绝不能成为"监控课堂"的工具。
眼动应用

阅读理解研究：注视时长预测难度，回视次数定位不解之处。

表情应用

在线课堂情绪仪表盘，教师实时看到集体困惑度，调整节奏。

笔迹应用

数学解题过程分析，不只看对错，更看思路链与卡点。

09 / TIMELINE

九个关键时刻

从1960年PLATO到2025年教育专用大模型，九个事件串起教育与计算技术的六十五年。每张插图由AI根据历史场景生成。

1960

伊利诺伊大学开发PLATO，首个大规模计算机辅助教学系统，奠定在线教育技术与终端形态基础。橙色等离子终端成为一代教育技术人的集体记忆。

本杰明·布鲁姆发现一对一辅导能使学生成绩比群体教学高出两个标准差。他同时指出这在当时无法规模化——这个命题正是四十年后AI导师要回答的。

2008

Khan Academy 上线

萨尔曼·可汗创立可汗学院，用免费视频与自适应练习覆盖190国1亿+用户，提供15000+免费教育视频，重新定义个性化学习的规模边界。

Thrun与Norvig的AI公开课吸引16万注册，开启MOOC浪潮，顶尖大学课程首次大规模开放。同年Koller与Ng创办Coursera。

→ MOOC浪潮兴起

11·深 / SYNTHESIS

跨维度综合

五个维度不是孤立的。看清它们之间的张力、共变与短板共振，才能避免"一维高分掩盖多维短板"的陷阱。

维度均分最强项最弱项核心张力
理论严谨性 3.8 概念清晰度 / 逻辑一致性 (4) 假设可证伪性 (3) 许多教育AI假设难做严格对照实验，可证伪性长期偏弱
实践效果 3.6 学习增益 / 教师接受度 (4) 长期迁移 (3) 短期分数易提升，长期迁移与能力留存几乎无人扎实追踪
计算效率 3.2 部署复杂度 (4) 推理延迟 / 显存占用 (3) 大模型能力强但延迟与成本高，端侧小模型能力又不足
可解释性 3.0 反馈可读性 (4) 决策透明度 / 错误归因 (3) 对学生反馈可读，但模型决策本身仍是黑箱，错误难归因
适用范围 3.4 学科覆盖 / 语言覆盖 (4) 学段覆盖 / 文化适配 (3) 跨学段与跨文化适配不足，幼教与非英语圈是洼地
张力一

效率 ↔ 可解释性

大模型效率高、能力强，但黑箱；小模型/规则系统可解释，但能力弱。教育场景尤其需要"既能讲清楚为什么，又能跟上课堂节奏"的折中——RAG+规则约束+置信度标注是当下主流解法，但仍是妥协。

张力二

短期增益 ↔ 长期迁移

多数产品在"学习增益"上能拿4分，但在"长期迁移"上只有3分。原因是长期追踪成本高、归因难，企业没有激励做。这是教育AI最大的实证空白——我们擅长证明"短期内有效"，却不擅长回答"它真的让人学会了吗"。

张力三

学科覆盖 ↔ 文化适配

主流模型在学科与语言覆盖上已较强（中英为主），但文化适配仍是短板。一个用美式课堂语料训练的模型，对东亚"面子文化"下的沉默学生可能误判"没懂"为"懂了"。本地化不只是翻译，是教学法的在地化。

短板共振

可解释性弱 × 长期迁移空白 = 信任风险

当模型决策不透明（可解释性3.0）且长期效果未被验证（长期迁移3.0）同时存在，教育AI就处于"不知道它为什么对、也不知道它长期是否还对"的双重不确定。这是教师抵触与家长焦虑的根源。补救：强制可解释报告 + 至少一学期的追踪实验。

高分陷阱

单维4分 ≠ 整体优秀

一个产品可能在"学习增益"上拿4分，但若"公平性影响"只有2分（扩大差距），它对弱势学生就是负资产。本框架的5个维度是"乘法关系"而非"加法关系"——任何一维严重短板都会拖垮整体价值。选型时看最低分，而非平均分。

如何用这份评估：采购方应先确定自己的"底线维度"（如公立校优先公平性、医院教育优先安全合规、高校优先可解释性），再用本框架逐项打分，最后看最低分是否过线，而非看均分。开发者则应找到自己产品的"短板共振区"，优先补两个同时偏弱的维度，性价比最高。评估不是为了排名，是为了定位"下一个该补哪里"。

13 / CELEB_SKILLS

六位教育思想家的思维技能

把Bloom的掌握学习、Vygotsky的最近发展区、Piaget的建构主义……拆成可操作的技能：核心定义 + 行动步骤 + 局限。

BL

Benjamin Bloom

掌握学习 Mastery Learning
几乎所有学生都能达到高水平掌握，前提是给予足够时间与正确反馈。成绩差异主要来自学习时间与反馈质量，而非天赋。
行动步骤
  1. 拆解目标为可测小单元
  2. 形成性测验定位未掌握项
  3. 针对性纠正与补充练习
  4. 再次测验直至掌握
  5. 进入下一单元
局限：时间成本高，大班难落地；AI可在此弥补——做即时纠正与差异化练习，把"掌握学习"从理想变为可执行的日常。
VG

Lev Vygotsky

最近发展区 ZPD
学生独立水平与在指导下能达到的水平之间的差距，是教学最有效的区间。教学应瞄准"跳一跳够得着"的位置。
行动步骤
  1. 诊断学生当前独立水平
  2. 识别"跳一跳够得着"的任务
  3. 提供脚手架支持
  4. 逐步撤除脚手架
  5. 迁移到独立完成
局限：ZPD难精确量化；AI可做动态诊断与脚手架适配，但"人"的引导与情感支持仍不可替代，AI是脚手架而非建造者。
PG

Jean Piaget

认知发展建构主义
儿童通过同化与顺应主动建构知识，认知发展分阶段进行。学习不是接收信息，而是重组认知结构。
行动步骤
  1. 提供与现有图式冲突的经验
  2. 引发认知失衡与思考
  3. 引导顺应建立新图式
  4. 在操作中验证
  5. 反思巩固
局限：阶段论被批评过于刚性；建构主义难规模化，AI可提供个性化探索环境，但需警惕"伪建构"——开放≠有效。
MZ

Erik Mazur

同伴教学 Peer Instruction
课前自学概念，课上用概念题引发同伴讨论与再答，把课堂从讲授转向互动。理解在讨论中重建，而非在讲授中传递。
行动步骤
  1. 课前布置概念学习
  2. 课上抛出概念题
  3. 独立作答
  4. 同伴讨论说服彼此
  5. 再答并讲解
局限：依赖学生预学与同伴质量；AI可做课前诊断与讨论引导，缓解师资压力，但同伴间的社会性互动不可由AI完全替代。
MT

Sugata Mitra

自我组织学习 SOLE
儿童在无教师直接指导下，能围绕大问题自发协作学习，教师是鼓励者而非知识源。好奇心是引擎，同伴是镜面。
行动步骤
  1. 提出一个"大问题"
  2. 分组自由探索(网络/资料)
  3. 组内自组织协作
  4. 分享发现
  5. 教师追问深化
局限：依赖资源与动机；AI可做"大问题"生成与探索引导，成为SOLE的智能陪练，但需注意数字鸿沟——并非所有孩子都有网络。
AD

John Anderson

ACT-R 认知架构
用产生式规则模拟人类认知，区分陈述性与程序性记忆，是智能辅导系统理论根基。让"因材施教"有了可计算的基础。
行动步骤
  1. 建模学生知识状态
  2. 识别程序性规则掌握度
  3. 针对性安排练习
  4. 追踪错误模式
  5. 动态调整任务
局限：模型偏理性认知，情感因素建模弱；但为Carnegie Learning等智能辅导系统提供了可计算基础，是教育AI最"硬核"的理论支撑。

四级（S/A/B/C）不是简单打分，而是一套证据强度判断框架。下面解释每级的判定标准、常见误用与交叉验证技巧。

S

最高权威

国际组织公约、生效法律、顶级同行评议期刊。证据强度最高，适合作为政策与学术论据的基石。

判定标准：有强制力或经最严格同行评议；样本与方法公开可查；无商业利益相关。

A

高权威

顶级学术组织会议论文、知名高校研究、权威预印本。时效性强，但需注意预印本未经最终评议。

判定标准：经同行评议或来自公认权威机构；方法可追溯；利益相关已声明。

B

实践权威

实践机构技术报告、企业白皮书、MOOC平台数据。实践价值高，但存在自我利益相关。

判定标准：来自一线实践者；数据真实但可能选择性呈现；需交叉验证关键数字。

C

背景参考

行业咨询报告、市场研究、社交媒体讨论。反映趋势与氛围，但非严格证据。

判定标准：统计口径不明；样本与方法不公开；仅用于背景，不宜作为结论依据。

交叉验证

三角印证法

任何一个关键数字，至少找三个独立来源印证：一个S/A级（学术或官方）、一个B级（实践机构）、一个C级（市场或舆论）。三者方向一致，可信度高；三者分歧大，说明问题复杂，需保留区间值而非取单点。本报告的"学习效率提升30%"就是Khan实验(A)、松鼠AI实践(B)、行业调查(C)三角印证后的保守估计。

利益相关识别

谁出钱，谁说话

读任何信源先问三个问题：①作者是谁？②谁资助了这项研究？③结论对资助方有利吗？Khan Academy说Khanmigo有效（有利），需打折；Reich说教育技术常"failure to disrupt"（无利益相关），可信度高。利益相关不等于不可信，但必须标注并降低权重。

本报告的承诺：所有C级信源数据均经交叉验证并标注区间值；所有B级信源的关键数字均提示"自我利益相关"；所有A级预印本均标注"未经最终评议"；所有S级法规均精确到条款与生效日期。读者可据本表自行复核任何一处引用的证据强度。信源评定不是终点，是读者独立判断的起点。
核心论点回顾

本报告的五个一句话结论

  1. AI是增强器，不是替代器——它做机械性工作，把教师解放出来做创造性工作。
  2. 问问题比给答案更重要——一个会追问的AI导师，比一个会答题的工具更有教育价值。
  3. 测得到的不是全部——分数、时间、完成率易测，但好奇心、创造力、批判性思维才是教育真正重要的。
  4. 公平是底线不是加分项——教育AI若扩大差距，技术再先进也是负资产。
  5. 责任必须先于能力——当AI能力越强，"错了算谁的"这个问题越不能回避。
