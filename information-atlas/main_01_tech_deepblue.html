01

信息论的本源

从"如何度量消息"到一门数学
背景

为什么需要信息论

在 Shannon 之前，通信工程靠经验。电报、电话、无线电各自为政。Shannon 提出一个统一问题：给定一条有噪声的信道，信息能以多快、多可靠地传输？答案不依赖语义，只依赖概率结构。

核心洞见

信息 = 消除的不确定性

一条消息的"量"不取决于它说什么，而取决于它排除了多少种可能。越出人意料，信息越多；越可预测，信息越少。这正是熵的直觉来源。

bit 的诞生

二进制的自然单位

Shannon 借用了 Tukey 的 "bit"（binary digit）。当基本符号等概率时，一个 bit 恰好把不确定性减半。bit 从此成为信息的原子单位。

语义独立性

"意义"不在公式里

Shannon 明确区分：信息论处理的是信号的统计结构，而非语义真伪。一句"胡话"和一句"真理"若同样出人意料，则携带等量信息。这一边界避免了无休止的哲学纠缠。

Shannon 的警示（1956 "Bandwagon" 社论）：他提醒学界不要盲目把信息论套用到心理学、经济学等领域——只有当变量可被明确定义为概率事件时，信息论才适用。
02

熵：不确定性的度量

自信息 · 香农熵 · 联合/条件熵
Shannon 熵I(X) = H(X) = - Σ_{x∈X} p(x) log₂ p(x)
自信息

单个事件

事件 x 的自信息 I(x) = -log₂ p(x)。概率越小，自信息越大；确定性事件（p=1）信息为 0。

期望

熵是平均

熵是自信息的期望，衡量随机变量整体的"惊讶度"。公平硬币 H=1 bit；两面相同硬币 H=0 bit。

最大熵

均匀分布最"乱"

在固定字母表上，均匀分布熵最大。约束越多（如给定均值），熵越小——这正是最大熵原理的种子。

联合熵

H(X,Y)

H(X,Y) = -Σ p(x,y) log p(x,y)，描述两变量同时的不可预测性。

条件熵

H(X|Y)

H(X|Y) = H(X,Y) - H(Y)，已知 Y 后仍对 X 剩余的不确定性。

链式法则

分解

H(X₁,…,Xₙ) = Σ H(Xᵢ | X₁,…,Xᵢ₋₁)。多变量不确定性可逐级拆解。

关键定理：熵等于无损信源编码的最佳平均码长下界。若以 L 比特/符号编码，则 L ≥ H(X)，且存在码使 L 任意接近 H(X)。
03

互信息：知道 Y 能减多少 X 的不确定

I(X;Y) · 数据处理不等式
互信息（三种等价写法）I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X) = H(X) + H(Y) - H(X,Y)
对称

I(X;Y) = I(Y;X)

互信息关于两变量对称，度量"共享信息量"。X、Y 独立时互信息为 0。

非负

I(X;Y) ≥ 0

由 KL 散度定义 I(X;Y)=D_KL(p(x,y)‖p(x)p(y)) 直接得出，恒非负。

与 KL

信息即距离

互信息是把"联合分布 vs 边缘乘积"作为距离的 KL 散度，是信息论统一两大家族的桥梁。

DPI

数据处理不等式

若 X→Y→Z 构成马尔可夫链，则 I(X;Y) ≥ I(X;Z)。任何处理都无法增加关于 X 的信息。

贯穿全图集：互信息是信息瓶颈、信息平面、信道容量、特征选择（HSIC）、因果转移熵的共同语言——它把"相关性"量化为比特。
04

信道容量与香农三定理

C = B log₂(1+S/N) · 编码定理
AWGN 信道容量（香农公式）C = B · log₂(1 + S/N)
第一定理

信源编码（无损压缩）

任何信源可压缩到平均码长任意接近其熵 H(X)，不可更低。Huffman / LZ 即逼近此极限。

第二定理

信道编码（可靠传输）

若传输速率 R < C，存在编码使错误概率趋零；若 R > C 则不可能。噪声不是障碍，只要慢一点。

第三定理

率失真（有损压缩）

允许失真 D 时，最小速率由率失真函数 R(D) 给出（详见深潜馆 methodology）。

带宽·信噪

权衡

C 随带宽 B 与信噪比 S/N 增长。加大带宽或功率都能增容；但 log 意味着边际收益递减。

逆定理

不可能性

信道编码逆定理保证：超过 C 的可靠通信在数学上不存在——给误差留了硬性天花板。

通信模型

五部件

信源→编码器→信道(含噪)→解码器→信宿。噪声用条件概率 p(y|x) 建模，与语义无关。

06

连续变量：微分熵

h(X) · 高斯分布的最大熵
微分熵h(X) = -∫ p(x) log p(x) dx
注意

可为负

与离散熵不同，微分熵可负（因密度可大于1），且依赖坐标尺度——不是不变的。

最大熵

高斯最"乱"

给定方差 σ²，高斯分布微分熵最大：h(X) ≤ ½log(2πeσ²)。这是最大熵原理在连续域的旗舰结果。

互信息不变

I(X;Y) 仍稳

连续情形互信息 I(X;Y)=h(X)+h(Y)-h(X,Y) 仍定义良好、坐标不变，是连续域的可靠度量。

相对熵

KL 仍非负

连续 KL 散度 D_KL(p‖q)=∫p log(p/q) 仍非负、坐标不变，是变分推断的核心。

07

渐进均分性 (AEP)

典型集 · 信源编码定理的几何
典型集 A_ε⁽ⁿ⁾{ xⁿ : | -1/n log p(xⁿ) - H(X) | < ε }，其体积 ≈ 2^{nH(X)}
直觉

长序列几乎等长

当 n 很大，几乎所有典型序列的概率都≈ 2^{-nH(X)}，于是只需约 nH(X) 比特描述任意一个。

编码定理

体积的威力

典型集大小 ≈ 2^{nH}，全部序列有 2^n 个。只要 R>H，典型集占比趋零却几乎包住全部概率——可忽略其余。

联合 AEP

成对典型

联合典型集给出信道编码的逆定理几何：错误来自"非典型配对"，随 n 指数衰减。

意义

熵是体积律

AEP 把"熵=平均码长"变成几何事实：信息量就是高维空间里典型球的对数体积。

08

费诺不等式

误差的信息下界
FanoH(X|Y) ≤ H(P_e) + P_e·log(|X|-1)
用途

给误差定底

若想知道 X 却只看到 Y，错误概率 P_e 被条件熵 H(X|Y) 下界约束——信息不够，错就多。

推论

信道逆定理

R>C 时 H(X|Y) 太大，P_e 无法趋零，故可靠通信不可能。费诺是逆定理的常用工具。

09

更多基本不等式

信息论的公理骨架
链律: I(X;Y,Z) = I(X;Y) + I(X;Z|Y) 互信息界: I(X;Y|Z) ≤ I(X;Y) 条件约减: I(X;Y|Z) ≤ H(X|Z) ≤ H(X) 数据处理的推广: X→Y→Z→W ⇒ I(X;W) ≤ I(X;Y)
这些不等式构成"信息不等式"系统：许多学习/通信的"不可能性"结论，本质上只是某条信息不等式的代入。

11

熵的几何直观

凸性

熵是凹函数

H(λp+(1-λ)q) ≥ λH(p)+(1-λ)H(q)。混合分布更平，熵更大；这是最大熵原理的凸分析基础。

信息投影

KL 是距离

虽非对称、非三角，D_KL 是散度，最小 KL = 最大熵（同约束下）。信息几何把分布族看成黎曼流形。

互信息曲面

双凹双凸

I(X;Y) 对 p(x) 凹、对 p(y|x) 凸；优化时交替方向必收敛，正是 BA/IB 迭代的稳定来源。

坐标不变

互信息保真

可逆变换不改变互信息，但改变熵——互信息比熵更物理，是跨域可比的度量。

编码定理的精确形式

信源: n 足够大 ∃ 码使平均长度 ≤ H(X)+ε 且译码错 → 0 信道: 若 RC, 任何码 P_e ↛ 0
随机编码技巧：定理证明靠随机选码字+典型集译码，不构造具体好码，却证明好码存在——信息论最优雅的证明范式。
