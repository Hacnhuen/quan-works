01

信息瓶颈：从变分原理到自洽方程

给定输入 X、相关变量 Y（联合分布 p(x,y)），寻找压缩表示 T 使 I(X;T) 最小、I(T;Y) 最大。引入 Lagrange 乘子 beta（权衡），得 IB 泛函：

L[p(t|x)] = I(X;T) - beta*I(T;Y) = Sigma p(x,y)p(t|x) log [ p(t|x) / (p(t) * p(y|t)^beta) ]

对 p(t|x) 变分求极值，加归一化约束，用归一化消去乘子（记 Z(x;beta)），得三条自洽方程：

编码器: p(t|x) = p(t) / Z(x;beta) * exp( -beta * D_KL[ p(y|x) || p(y|t) ] ) ... (Eq.16) 边缘: p(t) = Sigma_x p(x) p(t|x) ... (Eq.17) 解码器: p(y|t) = (1/p(t)) Sigma_x p(x,y) p(t|x) ... (Eq.27)
1
初始化：取均匀或随机 p(t)。
2
迭代：用 (16) 更新 p(t|x) -> 用 (17) 更新 p(t) -> 用 (27) 更新 p(y|t)，直至收敛。
3
扫描 beta：从大到小改变 beta，得到 IB 曲线上的各工作点 (I(X;T), I(T;Y))。
退火二阶相变（Eq.34）：当 beta 连续增大、对表征做"确定性退火"时，相关结构在临界 beta* 处突然涌现——类比 Ising 模型的有序-无序相变。
02

率失真：Blahut-Arimoto 算法

R(D) = min_{p(x_hat|x): E[d]<=D} I(X;X_hat) Lagrangian: F(beta) = min_{p(x_hat|x)} [ I(X;X_hat) + beta * E[d(X,X_hat)] ]

与 IB 同源，beta 即逆温度。最优解（自洽方程）：

p*(x_hat|x) = p(x_hat) * exp( -beta * d(x,x_hat) ) / Z(x,beta) 其中 Z(x,beta) = Sigma_{x_hat'} p(x_hat') exp( -beta * d(x,x_hat') )
E 步

编码更新

p(x_hat|x) = p(x_hat)*exp(-beta*d) / Sigma p(x_hat')*exp(-beta*d)

M 步

边缘更新

p(x_hat) = Sigma_x p(x)*p(x_hat|x)

1
选 beta，初始化 p(x_hat)（如均匀）。
2
交替 E/M 直至收敛（线性收敛，几十步即可）。
3
计算该点 R、D，扫描 beta 得完整 R(D) 曲线。
数值技巧：在对数空间算 Z（LogSumExp 防溢出）；beta 用对数尺度；以前一个 beta 的收敛解作下一 beta 的初值，加速扫描。

方法论词条 · 扩展字典

Variational

变分推导

对 p(t|x) 变分求极值，加归一化得 IB 自洽方程。

Self-Consist

自洽方程

p(t|x) 正比 p(t)exp(-beta D_KL)；迭代至收敛。

Encoder

编码器更新

用 (Eq.16) 由 p(t) 更新 p(t|x)。

Marginal

边缘更新

用 (Eq.17) 由 p(t|x) 更新 p(t)。

Decoder

解码器更新

用 (Eq.27) 由 p(t|x) 更新 p(y|t)。

BA E-step

BA E 步

p(x_hat|x) 正比 p(x_hat)exp(-beta d)。

BA M-step

BA M 步

p(x_hat)=Sigma p(x)p(x_hat|x)。

LogSumExp

数值稳定

Z 用 LogSumExp 防溢出。

Annealing

退火相变

beta 增大诱发二阶相变。

Convex

凸优化

I 双凹双凸，交替收敛。
